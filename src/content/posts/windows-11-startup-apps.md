컴퓨터를 켜고 로그인했는데 한동안 버벅인다면, 로그인과 동시에 자동으로 실행되는 **시작 프로그램(시작 앱)** 이 많을 수 있습니다. 메신저, 클라우드 동기화, 업데이트 도우미처럼 매번 켜 둘 필요가 없는 앱까지 함께 실행되면 부팅 직후가 느려집니다.

윈도우 11에서는 **설정** 이나 **작업 관리자** 에서 클릭 몇 번으로 자동 실행을 끌 수 있습니다. 이 글은 Microsoft 공식 도움말 "Windows에서 시작 응용 프로그램 구성"을 바탕으로 정리했습니다. (작성일 2026년 11월 2일)

## 방법 한눈에 보기

| 방법 | 경로 | 이럴 때 |
|---|---|---|
| 설정 앱 | **시작** → **설정** → **앱** → **시작** | 가장 간단하게 켜고 끌 때 |
| 작업 관리자 | **작업 관리자** → **시작 앱** 탭 | 어떤 앱이 부팅을 느리게 하는지 보고 끌 때 |
| 시작 폴더 | 실행 창에 `shell:startup` | 목록에 없는 앱을 자동 실행에 추가·제거할 때 |

## 방법 1. 설정에서 끄기

1. **시작** → **설정** → **앱** → **시작** 으로 이동합니다.
2. 앱 목록에서 자동 실행을 원하지 않는 앱의 토글을 꺼짐(해제)으로 바꿉니다.
3. 다음 로그인부터 그 앱은 자동으로 실행되지 않습니다.

공식 도움말에 따르면 토글을 켜 두면 로그인할 때 자동으로 시작되고, 끄면 자동으로 시작되지 않습니다. 앱에 따라 펼침 단추가 있으면 세부 설정도 바꿀 수 있습니다.

> 자동 실행을 끈다고 앱이 삭제되는 것은 아닙니다. 필요할 때 시작 메뉴에서 직접 실행하면 됩니다.

## 방법 2. 작업 관리자에서 영향 보고 끄기

작업 관리자는 각 앱이 부팅에 주는 부담(**시작 영향**)을 함께 보여 줘서, 무엇부터 끌지 판단하기 좋습니다.

1. **시작** 단추를 마우스 오른쪽 단추로 클릭하고 **작업 관리자** 를 선택합니다.
2. **시작 앱** 을 선택합니다.
3. 끌 앱을 선택한 뒤 **사용 안 함** 을 누릅니다. 다시 켜려면 **사용** 을 누릅니다.

### 시작 영향 기준 (Microsoft 도움말)

| 표시 | 의미 |
|---|---|
| **높은 영향** | CPU 사용 1초 이상 또는 디스크 사용 3MB 초과 |
| **중간 영향** | CPU 300밀리초~1초 또는 디스크 292KB~3MB |
| **낮은 영향** | CPU 300밀리초 미만, 디스크 292KB 미만 |
| **측정되지 않음** | 측정 데이터가 없음 (앱은 사용 설정 상태) |
| **없음** | 시작 앱이 사용되지 않음 |

**높은 영향** 으로 표시된 앱 중 매번 켤 필요가 없는 것부터 끄면 효과를 보기 쉽습니다.

## 무엇을 끄고 무엇을 남길까

시작 앱 목록에는 다양한 앱이 섞여 있습니다. 아래는 판단 기준의 예입니다.

| 앱 종류 | 판단 기준 |
|---|---|
| 메신저, 음악·영상 앱 | 로그인 직후 꼭 필요하지 않다면 끄고, 필요할 때 실행 |
| 게임 런처, 쇼핑·이벤트 앱 | 대부분 끄고 필요할 때 실행 |
| 클라우드 동기화 (OneDrive 등) | 자동 동기화가 필요하면 켜 두고, 아니라면 끄기 |
| 보안 프로그램, 키보드·마우스·터치패드 드라이버 도구 | 기능에 영향이 있을 수 있으니 무엇인지 모르면 그대로 두기 |

이름만 보고 무엇인지 모르겠다면 끄지 말고 그대로 두는 것이 안전합니다. 하나씩 끄고 다시 로그인해 문제가 없는지 확인하세요.

## 방법 3. 원하는 앱을 자동 실행에 추가하기 (시작 폴더)

반대로 매번 쓰는 앱이 자동으로 켜지게 하고 싶을 때, 또는 설정 목록에 나오지 않는 앱을 다룰 때는 **시작 폴더** 를 씁니다.

1. **시작** 단추를 마우스 오른쪽 단추로 클릭하고 **실행** 을 선택합니다.
2. `shell:appsfolder` 를 입력하고 Enter를 누릅니다. 설치된 앱 목록 창이 열리며, 이 창은 열어 둡니다.
3. 다시 **실행** 을 열고 `shell:startup` 을 입력해 Enter를 누릅니다. 시작 폴더 창이 열립니다.
4. 첫 번째 창에서 원하는 앱을 시작 폴더 창으로 **끌어다 놓습니다**.

자동 실행에서 빼려면 시작 폴더 창에서 그 바로 가기를 삭제하면 됩니다.

| 폴더 | 실행 창에 입력 | 적용 대상 |
|---|---|---|
| 현재 사용자 시작 폴더 | `shell:startup` | 지금 로그인한 계정 |
| 모든 사용자 시작 폴더 | `shell:common startup` | PC의 모든 계정 |

## 안 될 때: 자주 겪는 문제와 해결법

| 증상 | 원인 | 해결 |
|---|---|---|
| 끈 앱이 계속 실행됨 | 앱 자체 설정에 "Windows 시작 시 실행" 옵션이 켜져 있을 수 있음 | 해당 앱의 환경설정에서 자동 실행 옵션도 확인 |
| 시작 앱 목록에 원하는 앱이 없음 | Windows에 시작 앱으로 등록되지 않은 앱 | 방법 3의 시작 폴더 사용 |
| "이 앱을 찾을 수 없습니다" 표시 | 앱이 이동식·네트워크 드라이브에 있거나, 경로가 없거나, 제거됨 | 앱을 다시 설치 |
| 끄고 나서 특정 기능이 안 됨 | 장치 도구나 보안 앱을 끔 | 다시 **사용** 으로 바꾸고 재부팅 |
| 그래도 부팅 후 느림 | 시작 앱 외의 원인 (저장 공간 부족 등) | 저장 공간 확보 후 다시 확인 |

"이 앱을 찾을 수 없습니다" 항목은 토글 옆 아이콘을 눌러 자세한 정보를 볼 수 있습니다. 공식 도움말은 경로가 레지스트리를 가리키는 경우 레지스트리 편집기로 확인하는 방법도 안내하지만, **레지스트리를 잘못 고치면 문제가 생길 수 있으므로** 반드시 백업한 뒤 진행해야 합니다. 익숙하지 않다면 앱을 다시 설치하는 방법을 먼저 쓰세요.

저장 공간 정리는 [윈도우 11 C드라이브 용량 정리](/posts/windows-11-storage-cleanup/)에 정리했습니다.

## 정리

- **설정 → 앱 → 시작** 에서 토글을 끄면 그 앱은 로그인할 때 자동 실행되지 않습니다.
- **작업 관리자 → 시작 앱** 에서 **높은 영향** 앱부터 확인하고 **사용 안 함** 으로 바꿉니다.
- 목록에 없는 앱은 `shell:startup` 시작 폴더에서 추가하거나 지웁니다.
