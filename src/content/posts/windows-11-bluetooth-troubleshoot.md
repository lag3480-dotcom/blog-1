블루투스 이어폰이 PC에서 검색되지 않거나, 어제까지 잘 되던 마우스가 갑자기 연결되지 않으면 당황스럽습니다. 대부분은 설정 몇 가지를 순서대로 확인하면 해결됩니다.

이 글은 Microsoft 공식 도움말 "Windows에서 Bluetooth 문제 해결"을 바탕으로 **윈도우 11** 기준으로, 간단한 것부터 차례로 정리했습니다. (작성일 2026년 11월 4일)

## 확인 순서 한눈에 보기

| 순서 | 확인할 것 | 걸리는 시간 |
|---|---|---|
| 1 | 블루투스가 켜져 있는지 | 1분 |
| 2 | 비행기 모드가 꺼져 있는지 | 1분 |
| 3 | 장치 전원·배터리·거리 | 2분 |
| 4 | 장치 제거 후 다시 페어링 | 3분 |
| 5 | Bluetooth 장치 검색을 고급으로 | 1분 |
| 6 | 문제 해결사 실행 | 3분 |
| 7 | 드라이버 업데이트 | 5분 이상 |
| 8 | USB 3.0 장치 간섭 확인 | 2분 |

## 1. 블루투스가 켜져 있나

- 작업 표시줄 오른쪽의 빠른 설정을 열어 **Bluetooth** 가 켜져 있는지 확인합니다.
- 또는 **설정** → **Bluetooth & 장치** 에서 켭니다.
- 노트북에 **무선 기능 물리 스위치** 가 있다면 켜져 있는지도 확인합니다.

## 2. 비행기 모드가 꺼져 있나

빠른 설정에서 **비행기 모드** 가 켜져 있으면 블루투스가 꺼질 수 있습니다. 비행기 모드를 끄고, 그래도 안 되면 **Bluetooth를 껐다가 몇 초 뒤 다시 켜** 봅니다.

## 3. 장치 쪽 확인: 전원, 배터리, 거리

PC가 아니라 장치 쪽 문제인 경우도 많습니다.

- 이어폰·마우스의 **전원을 껐다 켭니다**.
- **충전 상태** 를 확인하거나 새 배터리로 바꿉니다.
- PC와 **가까운 곳** 에서 연결해 봅니다.

이어폰은 케이스에 넣었다 빼거나, 제조사 설명서에 나온 방법으로 **페어링 모드** 로 바꿔야 PC에서 검색됩니다. 방법은 제품마다 다르므로 설명서를 확인하세요.

## 4. 장치를 지우고 다시 연결하기

이전에 연결했던 장치가 갑자기 안 될 때 가장 효과적인 방법입니다.

1. **설정** → **Bluetooth & 장치** → **장치** 로 이동합니다.
2. 문제가 있는 장치의 **추가 옵션** 을 선택하고 **제거** 를 누릅니다.
3. 장치를 페어링 모드로 바꾼 뒤, 다시 장치 추가로 연결합니다.

## 5. 장치가 목록에 안 보이면: 검색을 고급으로

장치를 추가하려는데 목록에 나오지 않는다면, 공식 도움말은 **Bluetooth 장치 검색** 설정을 **기본값** 에서 **고급** 으로 바꾸라고 안내합니다. 이 설정은 **설정** → **Bluetooth & 장치** 안의 장치 관련 설정에서 찾을 수 있습니다.

## 6. 문제 해결사 실행

윈도우가 자동으로 원인을 찾아 고쳐 주는 기능입니다.

1. **설정** → **시스템** → **문제 해결** → **기타 문제 해결사** 로 이동합니다.
2. **Bluetooth** 옆의 **실행** 을 선택합니다.

**도움말 가져오기** 앱에서 Bluetooth 문제 해결사를 실행할 수도 있습니다.

## 7. 드라이버 업데이트

윈도우 업데이트 후 갑자기 안 된다면 드라이버 문제일 수 있습니다.

1. **시작** 단추를 마우스 오른쪽 단추로 클릭해 **장치 관리자** 를 엽니다.
2. **Bluetooth** 를 펼치고 어댑터를 마우스 오른쪽 단추로 클릭합니다.
3. **드라이버 업데이트** 를 선택하고 **드라이버 소프트웨어를 자동으로 검색** 을 고릅니다.
4. 찾지 못하면 **PC 제조업체 웹사이트** 에서 최신 블루투스 드라이버를 내려받아 설치합니다.

공식 도움말은 문제가 계속되면 장치 관리자에서 Bluetooth 어댑터를 **제거한 뒤 PC를 다시 시작** 해 드라이버가 자동으로 다시 설치되게 하는 방법도 안내합니다.

> 드라이버를 제거하기 전에 블루투스 마우스·키보드만 쓰고 있다면 유선 장치를 준비해 두세요. 재시작 전까지 입력이 안 될 수 있습니다.

## 8. USB 3.0 장치 간섭

공식 도움말에 따르면 **USB 3.0 포트에 연결된 다른 USB 장치** 가 블루투스 연결을 방해할 수 있습니다. 외장 하드, USB 허브 등이 블루투스 수신 부분 가까이 있다면 다른 포트로 옮기거나 거리를 둬 보세요.

## 증상별 빠른 해결표

| 증상 | 먼저 해 볼 것 |
|---|---|
| 블루투스 메뉴 자체가 없음 | 장치 관리자에서 드라이버 확인 (7번) |
| 장치 목록에 이어폰이 안 보임 | 페어링 모드 확인 (3번), 검색을 고급으로 (5번) |
| 예전엔 되던 장치가 갑자기 안 됨 | 장치 제거 후 다시 페어링 (4번) |
| 연결은 되는데 자주 끊김 | 배터리·거리 확인 (3번), USB 3.0 간섭 (8번) |
| 업데이트 후 안 됨 | 드라이버 업데이트 (7번) |

## 자주 묻는 질문

**Q. 휴대폰에는 잘 연결되는데 PC에만 안 돼요.**
블루투스 이어폰은 보통 한 번에 한 기기와만 연결되는 경우가 많습니다. 휴대폰의 블루투스를 잠시 끄거나 휴대폰에서 연결을 해제한 뒤 PC에서 다시 연결해 보세요.

**Q. 데스크톱 PC에 블루투스 메뉴가 아예 없어요.**
데스크톱 PC는 블루투스 기능이 없는 경우도 있습니다. 장치 관리자에 **Bluetooth** 항목이 없다면, PC 제조사 사양을 확인하고 필요하면 블루투스 어댑터를 사용해야 합니다.

**Q. 문제 해결사를 실행했는데 해결되지 않았어요.**
문제 해결사는 흔한 원인만 자동으로 점검합니다. 이후 단계인 드라이버 업데이트와 USB 3.0 간섭 확인까지 차례로 해 보세요.

## 정리

- 먼저 **Bluetooth 켜짐**, **비행기 모드 꺼짐**, 장치 **전원·배터리·거리** 를 확인합니다.
- 안 되면 **장치 제거 후 다시 페어링** 하고, 목록에 없으면 **Bluetooth 장치 검색** 을 **고급** 으로 바꿉니다.
- 그래도 안 되면 **문제 해결사** 와 **장치 관리자 드라이버 업데이트** 를 차례로 시도합니다.
