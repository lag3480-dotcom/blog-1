C드라이브 용량이 부족하면 업데이트가 설치되지 않거나 PC가 느려질 수 있습니다. 윈도우 11에는 따로 프로그램을 깔지 않아도 공간을 정리하는 기능이 **설정** 안에 들어 있습니다.

이 글은 Microsoft 공식 도움말 "Windows에서 드라이브 공간 확보"와 "Manage drive space with Storage Sense"를 바탕으로 **윈도우 11** 기준으로 정리했습니다. (작성일 2026년 11월 1일)

## 먼저 확인: 얼마나 찼나

1. **시작** → **설정** → **시스템** → **저장소** 로 이동합니다.
2. 드라이브 사용량 막대와 항목별(앱, 임시 파일 등) 사용량을 확인합니다.

공식 도움말에 따르면 이 화면의 용량 막대가 **빨간색** 으로 바뀌면 디스크 공간이 부족한 상태입니다.

## 방법별 한눈에 보기

| 방법 | 위치 | 특징 |
|---|---|---|
| 정리 권장 사항 | 설정 → 시스템 → 저장소 | 지울 만한 파일을 골라 보여 줌, 한 번에 정리 |
| 저장소 센스 | 설정 → 시스템 → 저장소 | 켜 두면 임시 파일·휴지통을 자동 정리 |
| OneDrive 온라인 전용 | 저장소 센스 설정 | 파일은 클라우드에 두고 PC 공간만 비움 |
| 외부 드라이브로 옮기기 | 파일 탐색기 | 사진·영상처럼 큰 파일을 USB·SD 카드로 |
| 새 콘텐츠 저장 위치 변경 | 고급 저장소 설정 | 앞으로 저장될 파일을 다른 드라이브로 |

## 방법 1. 정리 권장 사항으로 한 번에 지우기

가장 먼저 해 볼 방법입니다.

1. **시작** → **설정** → **시스템** → **저장소** → **정리 권장 사항** 을 엽니다.
2. 아래 범주를 차례로 펼쳐 지울 항목을 고릅니다.
3. 각 범주의 **정리** 단추를 누릅니다.

| 범주 | 내용 | 지우기 전 확인 |
|---|---|---|
| 임시 파일 | 앱과 Windows가 남긴 임시 파일 | 대부분 지워도 되지만 목록을 한 번 확인 |
| 대용량 또는 사용되지 않는 파일 | 크기가 크거나 오래 안 연 파일 | 필요한 파일인지 꼭 확인 |
| 클라우드에 동기화된 파일 | OneDrive 등에 이미 올라간 파일 | PC에서만 지워지고 클라우드엔 남는지 확인 |
| 사용되지 않는 앱 | 오래 안 쓴 앱 | 다시 설치할 수 있는 앱인지 확인 |

### Windows.old가 보인다면

윈도우를 큰 버전으로 업그레이드한 지 **10일이 지나지 않았다면** 정리 권장 사항에 이전 버전 Windows 파일(Windows.old)이 표시될 수 있습니다. 용량이 크지만, **삭제하면 이전 버전 Windows로 되돌릴 수 없습니다.** 업그레이드 후 문제가 없는지 확인한 뒤 지우세요.

## 방법 2. 저장소 센스로 자동 정리 켜기

**저장소 센스** 는 휴지통 항목과 임시 파일 같은 불필요한 파일을 자동으로 정리하는 기능입니다.

### 켜는 방법

1. **시작** → **설정** → **시스템** → **저장소** 로 이동합니다.
2. **저장소 센스** 를 **켬** 으로 바꿉니다.

### 세부 설정

**저장소 센스** 항목을 클릭하면 다음을 정할 수 있습니다.

| 설정 | 내용 |
|---|---|
| 실행 주기 | 저장소 센스를 얼마나 자주 실행할지 선택 |
| 휴지통 | 휴지통에 일정 기간 이상 있던 파일 자동 삭제 |
| 다운로드 폴더 | 일정 기간 이상 열지 않은 파일 자동 삭제 |
| 클라우드 콘텐츠 | 일정 기간 열지 않은 OneDrive 파일을 온라인 전용으로 전환 |

공식 도움말에 따르면 기본 설정으로 켜 두면 **공간이 부족할 때** 실행되어 불필요한 임시 파일을 지우고, 휴지통은 일정 기간 뒤 비워집니다. **다운로드 폴더와 클라우드 콘텐츠는 직접 설정하기 전에는 건드리지 않습니다.**

> 다운로드 폴더 자동 삭제를 켜면, 받아 두고 열지 않은 설치 파일이나 문서가 지워질 수 있습니다. 다운로드 폴더를 보관함처럼 쓴다면 이 옵션은 끈 채로 두세요.

### 알아 둘 점

- 저장소 센스는 **시스템 드라이브(보통 C:)** 만 관리합니다.
- 로그인한 상태로 **10분 넘게 온라인** 이어야 실행됩니다.
- 저장소 센스를 한 번도 설정하지 않았더라도, 공간이 부족해지면 Windows가 저장소 센스를 켜서 임시 파일을 정리한 뒤 알림을 보낼 수 있습니다.

## 방법 3. OneDrive 파일을 온라인 전용으로

OneDrive에 로그인되어 있으면 저장소 센스 설정에 클라우드 콘텐츠 항목이 나타납니다. 정한 기간 동안 열지 않은 파일을 **온라인 전용** 으로 바꿔 PC 공간을 비웁니다.

- 공식 도움말에 따르면 윈도우 11 버전 22H2부터 OneDrive 파일의 기본값은 **30일** 입니다.
- 온라인 전용으로 바뀌어도 **파일이 삭제되는 것은 아닙니다.** 다시 열면 내려받습니다.
- **항상 이 장치에 유지** 로 지정한 파일은 제외됩니다.

인터넷이 없는 곳에서 써야 하는 파일은 **항상 이 장치에 유지** 로 지정해 두세요.

## 방법 4. 큰 파일을 외부 드라이브로 옮기기

1. 파일 탐색기에서 옮길 파일(사진, 영상 등)을 선택합니다.
2. **잘라내기** 를 누릅니다.
3. USB 드라이브나 SD 카드 등 외부 저장 장치로 이동해 **붙여넣기** 합니다.

옮긴 뒤에는 외부 장치에서 파일이 잘 열리는지 확인하세요. 중요한 파일은 한 곳에만 두지 말고 백업을 함께 해 두는 것이 안전합니다.

## 방법 5. 앞으로 저장될 위치 바꾸기

D드라이브 같은 다른 드라이브가 있다면, 새로 저장되는 파일이 C드라이브에 쌓이지 않게 할 수 있습니다.

1. **시작** → **설정** → **시스템** → **저장소** → **고급 저장소 설정** 을 엽니다.
2. **새 콘텐츠가 저장되는 위치** 를 선택합니다.
3. 문서, 음악, 사진, 동영상 등 유형별로 저장할 드라이브를 고릅니다.

다른 드라이브의 사용량은 **고급 저장소 설정** 안의 다른 드라이브 사용량 항목에서 볼 수 있습니다.

## 안 될 때: 자주 겪는 문제와 해결법

| 증상 | 원인 | 해결 |
|---|---|---|
| 정리했는데 금방 다시 참 | 큰 파일이 계속 C드라이브에 저장됨 | 새 콘텐츠 저장 위치를 다른 드라이브로 변경 |
| 저장소 센스가 실행되지 않는 것 같음 | 로그인·온라인 10분 조건 미충족 | 로그인한 채 인터넷에 연결해 두기 |
| D드라이브는 정리가 안 됨 | 저장소 센스는 시스템 드라이브만 관리 | 다른 드라이브는 직접 정리 |
| 다운로드한 파일이 사라짐 | 다운로드 폴더 자동 삭제가 켜져 있음 | 저장소 센스 설정에서 다운로드 폴더 항목 끄기 |
| OneDrive 파일이 오프라인에서 안 열림 | 온라인 전용으로 전환됨 | 해당 파일을 항상 이 장치에 유지로 지정 |
| 이전 윈도우로 되돌리기가 없음 | Windows.old를 삭제했거나 10일이 지남 | 되돌리기 불가, 백업에서 복원 검토 |

## 정리

- **설정 → 시스템 → 저장소 → 정리 권장 사항** 에서 임시 파일, 대용량 파일, 안 쓰는 앱을 먼저 정리합니다.
- **저장소 센스** 를 켜 두면 임시 파일과 휴지통이 자동으로 정리되며, 다운로드 폴더 삭제는 직접 켤 때만 동작합니다.
- 큰 파일은 외부 드라이브로 옮기고, **새 콘텐츠가 저장되는 위치** 를 바꿔 C드라이브가 다시 차지 않게 합니다.
