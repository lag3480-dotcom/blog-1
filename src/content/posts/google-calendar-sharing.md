가족 일정이나 팀 회의 일정을 한곳에서 보고 싶을 때 가장 간단한 방법이 **구글 캘린더 공유** 입니다. 그런데 권한을 잘못 고르면 상대가 내 일정을 지우거나, 반대로 시간만 보이고 내용은 안 보여서 다시 설정해야 하는 경우가 많습니다.

이 글은 Google 캘린더 고객센터의 공유·권한·구독·공개 범위 도움말을 바탕으로 컴퓨터(웹) 기준으로 정리했습니다. (작성일 2026년 11월 7일)

## 한눈에 보기

| 하고 싶은 일 | 방법 |
|---|---|
| 특정 사람과 공유 | 캘린더 옆 더보기 → **설정 및 공유** → **공유 대상** → **사용자 및 그룹 추가** |
| 권한 고르기 | 한가함/바쁨만 보기 ~ **변경 및 공유 관리** 중 5가지 |
| 받은 캘린더 추가 | 공유 이메일의 링크 클릭, 또는 **다른 캘린더** **+** → **캘린더 구독** |
| 누구나 보게 공개 | **일정의 액세스 권한** → **공개 사용 설정** |
| 일정 하나만 숨기기 | 일정 수정 → 공개 범위를 **비공개** 로 |
| 공유 중지 | **공유 대상** 에서 이름 옆 삭제 아이콘 |

> 공유 설정은 **컴퓨터에서만** 바꿀 수 있습니다. Google 도움말은 모바일 앱에서는 공유 설정을 수정할 수 없다고 안내합니다.

## 1. 특정 사람과 캘린더 공유하기

1. 컴퓨터에서 Google 캘린더를 엽니다.
2. 왼쪽 **내 캘린더** 에서 공유할 캘린더에 마우스를 올리고 더보기(점 3개)를 누른 뒤 **설정 및 공유** 를 선택합니다.
3. 왼쪽에서 **공유 대상** 을 누릅니다.
4. **사용자 및 그룹 추가** 를 누릅니다.
5. 상대의 이메일 주소나 Google 그룹 주소를 입력합니다.
6. 권한을 고릅니다. (아래 표 참고)
7. **보내기** 를 누릅니다.

상대에게는 이메일이 갑니다. **상대가 이메일 속 링크를 눌러야** 내 캘린더가 상대 캘린더에 추가됩니다. 공유했는데 상대 화면에 안 보인다면 대부분 이 링크를 아직 누르지 않은 경우입니다.

다른 사람이 만든 캘린더를 내가 다시 공유하려면, 그 캘린더 주인이 나에게 **변경 및 공유 관리** 권한을 줘야 합니다.

## 2. 공유 권한 5가지 차이

| 권한 | 상대가 볼 수 있는 것·할 수 있는 일 |
|---|---|
| **한가함/바쁨 정보만 보기(세부정보는 숨김)** | 바쁜 시간대만 보임. 일정 제목·내용은 안 보임 |
| **일정 세부정보 보기** | 일정 제목, 시간, 장소, 설명 등 모든 세부정보 |
| **변경(비공개 일정을 한가함/바쁨으로 보기)** | 비공개가 아닌 일정 수정 가능. 비공개 일정은 수정 불가 |
| **변경 후 일정 세부정보 확인** | 일정 수정 가능, 일정을 누구와 공유했는지도 확인 |
| **변경 및 공유 관리** | 일정을 모두 관리하고, 캘린더를 다른 사람에게 공유 가능 |

권한별로 할 수 있는 일을 조금 더 나누면 다음과 같습니다.

| 할 수 있는 일 | 한가함/바쁨 | 세부정보 보기 | 변경 | 변경 후 세부정보 확인 | 변경 및 공유 관리 |
|---|---|---|---|---|---|
| 이메일 알림 받기 | X | O | O | O | O |
| 공유 설정 보기 | X | X | O | O | O |
| 일정 만들기·수정 | X | X | O | O | O |
| 캘린더 완전히 삭제 | X | X | X | X | O |

**변경** 권한으로는 비공개 일정을 수정할 수 없고, 비공개 일정은 '바쁨' 블록으로만 보입니다.

### 어떤 권한을 줘야 할까

- **회의 시간만 맞추면 되는 외부 사람**: 한가함/바쁨 정보만 보기
- **일정 내용을 같이 봐야 하는 가족·동료**: 일정 세부정보 보기
- **일정을 같이 넣고 고치는 공동 관리자**: 변경 또는 변경 후 일정 세부정보 확인
- **캘린더를 함께 운영할 사람**: 변경 및 공유 관리. 이 권한은 캘린더 삭제와 재공유까지 가능하므로 꼭 필요한 사람에게만 줍니다.

### 권한이 겹치면 넓은 쪽이 적용됩니다

Google 도움말에 따르면 권한 설정이 충돌하면 **더 넓은 권한이 우선** 합니다. 예를 들어 캘린더를 **일정 세부정보 보기** 로 공개해 두면, 특정 사람에게 한가함/바쁨만 줬더라도 그 사람도 세부정보를 볼 수 있습니다.

## 3. 공유받은 사람: 캘린더 추가·구독하기

공유 이메일을 받았다면 이메일 속 링크를 누르는 것이 가장 쉽습니다. 링크 없이 직접 추가하거나, 아직 공유받지 않은 캘린더를 요청할 수도 있습니다.

1. 컴퓨터에서 Google 캘린더를 엽니다.
2. 왼쪽 **다른 캘린더** 옆 **+** (다른 캘린더 추가)를 누르고 **캘린더 구독** 을 선택합니다.
3. **캘린더 추가** 칸에 상대의 이메일 주소를 넣고 목록에서 캘린더를 고릅니다.
4. 이미 공유받은 캘린더라면 **다른 캘린더** 아래에 바로 나타납니다. 공유받지 않았다면 주인에게 액세스 요청 이메일이 갑니다.

요청을 받은 주인은 이메일의 링크를 눌러 **설정** 화면에서 사용자와 권한을 고르고 **보내기** 를 누르면 됩니다.

> 새 캘린더 구독은 **컴퓨터 웹브라우저** 에서만 됩니다. 다만 한 번 추가되면 휴대폰 Google 캘린더 앱에도 자동으로 나타납니다.

공유받은 캘린더를 잠시 안 보이게 하려면 **다른 캘린더** 에서 체크를 해제합니다. 체크 해제는 숨기기일 뿐 구독 취소가 아닙니다.

## 4. 캘린더 공개하기와 공유 링크

동아리 행사표처럼 많은 사람이 봐야 하는 캘린더는 공개할 수 있습니다.

1. 오른쪽 위 **설정**(톱니바퀴) → **설정** 을 누릅니다.
2. 왼쪽 **내 캘린더의 설정** 에서 캘린더 이름을 누릅니다.
3. **일정의 액세스 권한** 에서 **공개 사용 설정** 을 체크합니다.
4. **확인** 을 누릅니다.

공개하면서 일정 내용은 숨기고 싶다면 권한을 **한가함/바쁨 정보만 보기(세부정보 숨김)** 으로 고릅니다.

공개한 뒤에는 다음 방법으로 링크를 나눠 줄 수 있습니다.

| 방법 | 위치 | 용도 |
|---|---|---|
| 공유 가능한 링크 | **일정의 액세스 권한** → **공유 가능한 링크 받기** → **링크 복사** | 상대가 구글 캘린더에 추가 |
| 공개 URL | **캘린더 통합** → **이 캘린더의 공개 URL** | 로그인 없이 웹에서 보기 |
| iCal 형식 공개 주소 | **캘린더 통합** → **iCal 형식의 공개 주소** | 아이폰 등 다른 캘린더 앱 |

상대가 공개 URL을 받았다면 **다른 캘린더** **+** → **URL로 추가** 에 붙여 넣고 **캘린더 추가** 를 누르면 됩니다.

### 공개할 때 주의할 점

- 공개 캘린더는 웹에서 검색될 수 있습니다.
- 일정의 기본 공개 범위가 '공개'라면 **앞으로 만드는 새 일정도 모두에게 보입니다.** 개인 일정을 같은 캘린더에 넣지 마세요.
- 공개를 끄려면 **설정 및 공유** → **일정의 액세스 권한** 에서 **공개 사용 설정** 체크를 해제합니다. 보통 몇 분이면 반영되지만 **최대 4시간** 까지 걸릴 수 있습니다.

## 5. 일정 하나만 숨기기: 일정 공개 범위

캘린더는 공유하되 병원 예약 같은 일정 하나만 숨기고 싶을 때는 일정의 공개 범위를 바꿉니다.

1. 일정을 열고 수정(연필) 아이콘을 누릅니다.
2. **기본 공개 상태** 를 누르고 아래 세 가지 중 하나를 고릅니다.
3. **저장** 을 누릅니다.

| 공개 범위 | 다른 사람에게 보이는 모습 |
|---|---|
| **기본 공개 상태** | 캘린더 공유 권한을 그대로 따름 |
| **공개** | 캘린더를 볼 수 있는 사람은 이 일정의 세부정보를 모두 봄 (캘린더가 한가함/바쁨 공유여도) |
| **비공개** | 나와 '변경 후 일정 세부정보 확인' 이상 권한자만 내용을 봄. 나머지는 '바쁨'으로만 보임 |

알아 두면 좋은 점이 있습니다.

- **비공개** 일정이라도 참석자를 초대하거나 회의실을 예약하면 시작·종료 시간과 주최자가 드러날 수 있습니다.
- 반복 일정은 공개 범위가 **반복 전체** 에 적용됩니다. 한 회만 바꿔도 전체가 바뀝니다.

## 6. 공유 중지하기

| 대상 | 방법 |
|---|---|
| 특정 사람·그룹 | **설정 및 공유** → **공유 대상** → 이름 옆 삭제 아이콘 |
| 공개 공유 | **일정의 액세스 권한** → **공개 사용 설정** 체크 해제 |
| 회사 전체 공유 | **일정의 액세스 권한** → **{회사 이름}에서 사용할 수 있도록 설정** 체크 해제 |

## 안 될 때: 자주 겪는 문제와 해결법

| 증상 | 원인 | 해결 |
|---|---|---|
| 상대 캘린더에 내 일정이 안 보임 | 상대가 이메일 링크를 누르지 않음 | 링크를 누르게 하거나 **캘린더 구독** 으로 직접 추가 |
| 상대가 공유 이메일을 못 받음 | 주소 오류, 스팸함 | 주소 확인, 스팸·휴지통 확인, 공유 목록에서 지웠다가 다시 추가 |
| 휴대폰에서 공유 메뉴가 없음 | 공유 설정은 컴퓨터 전용 | 컴퓨터 웹브라우저에서 설정 |
| 시간만 보이고 일정 내용이 안 보임 | 권한이 **한가함/바쁨** | 권한을 **일정 세부정보 보기** 이상으로 변경 |
| 상대가 일정을 고칠 수 없음 | 권한이 보기 전용 | **변경** 이상으로 변경 |
| 공유받은 사람이 내 일정을 지움 | **변경** 이상 권한을 줌 | 보기 권한으로 낮추기 |
| 회사 계정에서 외부 공유가 안 됨 | 관리자가 공유를 제한 | 회사 관리자에게 문의 |
| 공개를 껐는데 아직 보임 | 반영 지연 | 최대 4시간 기다리기 |
| 아웃룩 등 다른 캘린더를 구독하려 함 | Google 캘린더만 구독 가능 | 상대가 공개 URL·iCal 주소를 제공해야 함 |

회사·학교 계정은 관리자가 공유 가능 여부를 정하고, 공유하지 않은 캘린더라도 관리자가 접근할 수 있다는 점도 알아 두세요.

## 자주 묻는 질문

**Q. 가족 모두 같은 일정을 보게 하려면?**
캘린더 하나를 '가족'용으로 만들고 가족 구성원의 이메일을 **공유 대상** 에 추가하면 됩니다. 일정을 같이 넣으려면 **변경** 이상 권한을 줍니다.

**Q. 구글 계정이 없는 사람에게도 보여 줄 수 있나요?**
**공유 대상** 은 이메일 주소로 추가하는 방식이고, Google 도움말에서 계정 없는 사용자 추가는 따로 설명하지 않습니다. 로그인 없이 보여 주려면 캘린더를 공개한 뒤 **캘린더 통합** 의 공개 URL을 보내는 방법이 안내되어 있습니다. 이때 공개 캘린더는 누구나 찾을 수 있다는 점에 주의하세요.

**Q. 휴대폰 앱에서 공유받은 캘린더가 안 보여요.**
Google 도움말에 따르면 주인이 공유를 승인하면 캘린더가 앱에 자동으로 나타납니다. 컴퓨터에서 이메일 링크를 눌러 추가했는지, 또는 **캘린더 구독** 요청이 승인되었는지 먼저 확인하세요.

**Q. 드라이브 파일 공유와 같은 방식인가요?**
비슷하지만 권한 이름과 범위가 다릅니다. 드라이브 공유는 [구글 드라이브 공유 방법과 권한 정리](/posts/google-drive-sharing-permissions/)에 따로 정리했습니다.

## 정리

- 공유는 컴퓨터에서 **설정 및 공유** → **공유 대상** → **사용자 및 그룹 추가** 로 하며, 상대는 이메일 링크를 눌러야 추가됩니다.
- 권한은 **한가함/바쁨 → 세부정보 보기 → 변경 → 변경 후 세부정보 확인 → 변경 및 공유 관리** 순으로 넓어지고, 겹치면 넓은 쪽이 적용됩니다.
- 공개 캘린더는 새 일정까지 보일 수 있으니, 개인 일정은 **비공개** 로 두거나 다른 캘린더에 넣습니다.
