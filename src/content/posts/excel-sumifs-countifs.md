"영업팀 김민준 사원의 10월 매출 합계", "서울 지점에서 반품된 건수"처럼 **조건이 두 개 이상** 붙은 합계와 개수는 SUMIFS와 COUNTIFS로 구합니다. 필터를 걸고 하나씩 더하는 것보다 빠르고, 데이터가 바뀌어도 결과가 자동으로 갱신됩니다.

## 예제 데이터

아래 매출 표를 기준으로 설명합니다. (A1:E9)

| | A | B | C | D | E |
|---|---|---|---|---|---|
| 1 | 날짜 | 지점 | 담당자 | 상품 | 금액 |
| 2 | 2026-09-28 | 서울 | 김민준 | 노트북 | 1,200,000 |
| 3 | 2026-10-02 | 서울 | 이서연 | 모니터 | 350,000 |
| 4 | 2026-10-05 | 부산 | 박지호 | 노트북 | 1,150,000 |
| 5 | 2026-10-11 | 서울 | 김민준 | 키보드 | 80,000 |
| 6 | 2026-10-15 | 대구 | 최유나 | 노트북 | 1,180,000 |
| 7 | 2026-10-19 | 서울 | 김민준 | 노트북 | 1,250,000 |
| 8 | 2026-10-24 | 부산 | 박지호 | 모니터 | 320,000 |
| 9 | 2026-11-01 | 서울 | 이서연 | 마우스 | 45,000 |

## SUMIFS: 조건에 맞는 값의 합계

```text
=SUMIFS(합계범위, 조건범위1, 조건1, [조건범위2, 조건2], ...)
```

**합계를 낼 범위가 맨 앞** 에 오고, 그 뒤로 '조건을 볼 범위, 조건'이 짝지어 이어집니다. 짝은 최대 127개까지 넣을 수 있습니다.

### 예제 1. 서울 지점 매출 합계 (조건 1개)

```text
=SUMIFS(E2:E9, B2:B9, "서울")
→ 2,925,000
```

### 예제 2. 서울 지점 김민준 사원의 매출 (조건 2개)

```text
=SUMIFS(E2:E9, B2:B9, "서울", C2:C9, "김민준")
→ 2,530,000
```

### 예제 3. 10월 한 달 매출 (날짜 구간)

날짜 구간은 **같은 날짜 열에 조건을 두 번** 거는 방식으로 만듭니다.

```text
=SUMIFS(E2:E9, A2:A9, ">=2026-10-01", A2:A9, "<=2026-10-31")
→ 4,330,000
```

시작일과 종료일을 셀(예: H1, H2)에 적어 두고 참조하면 기간을 바꾸기 편합니다. 이때는 부등호와 셀을 `&`로 이어 붙입니다.

```text
=SUMIFS(E2:E9, A2:A9, ">="&H1, A2:A9, "<="&H2)
```

`">=H1"`처럼 셀 주소를 따옴표 안에 넣으면 'H1'이라는 글자로 인식해서 결과가 0이 됩니다. 가장 흔한 실수 중 하나입니다.

### 예제 4. 노트북을 제외한 매출 (같지 않음)

```text
=SUMIFS(E2:E9, D2:D9, "<>노트북")
→ 795,000
```

## COUNTIFS: 조건에 맞는 개수

```text
=COUNTIFS(조건범위1, 조건1, [조건범위2, 조건2], ...)
```

합계 범위가 없다는 점만 빼면 SUMIFS와 같습니다.

### 예제 5. 서울 지점의 노트북 판매 건수

```text
=COUNTIFS(B2:B9, "서울", D2:D9, "노트북")
→ 2
```

### 예제 6. 100만 원 이상 거래 건수

```text
=COUNTIFS(E2:E9, ">=1000000")
→ 4
```

## 조건 쓰는 법 정리

| 원하는 조건 | 쓰는 법 | 예 |
|---|---|---|
| 같음 | 값 그대로 | `"서울"`, `100` |
| 같지 않음 | `<>` | `"<>노트북"` |
| 크다·작다 | `>`, `<`, `>=`, `<=` | `">=1000000"` |
| 셀 값과 비교 | 부등호 & 셀 | `">="&H1` |
| ~로 시작 | `*` (여러 글자) | `"김*"` |
| 글자 수 지정 | `?` (한 글자) | `"김??"` → 김으로 시작하는 세 글자 |
| 빈 셀 | `""` | `""` |
| 비어 있지 않은 셀 | `"<>"` | `"<>"` |

`*`나 `?` 문자 자체를 찾아야 한다면 앞에 물결표(`~`)를 붙입니다. 예: `"~*"`

## SUMIF와 헷갈리지 마세요

조건이 하나인 SUMIF 함수는 **인수 순서가 다릅니다.**

| 함수 | 순서 |
|---|---|
| SUMIF | `=SUMIF(조건범위, 조건, 합계범위)` → 합계범위가 **마지막** |
| SUMIFS | `=SUMIFS(합계범위, 조건범위, 조건)` → 합계범위가 **처음** |

Microsoft도 두 함수를 오가며 수식을 고칠 때 이 순서 차이로 오류가 자주 난다고 안내합니다. 조건이 하나여도 **SUMIFS만 쓰는 습관** 을 들이면 헷갈릴 일이 없습니다.

## 결과가 이상할 때 점검표

| 증상 | 원인 | 해결 |
|---|---|---|
| 결과가 0 | 텍스트 조건에 따옴표가 없음 | `서울` → `"서울"` |
| 결과가 0 | 셀 주소를 따옴표 안에 넣음 | `">=H1"` → `">="&H1` |
| `#VALUE!` | 합계범위와 조건범위의 크기가 다름 | 모든 범위의 행 수를 똑같이 (예: 모두 2~9행) |
| 숫자가 안 더해짐 | 금액이 텍스트로 저장됨 | 셀 서식을 숫자로 바꾸고 '숫자로 변환' |
| 이름이 있는데 안 잡힘 | 앞뒤 공백 | TRIM 함수로 정리 |
| 날짜 조건이 안 맞음 | 날짜가 텍스트로 입력됨 | 셀을 선택했을 때 오른쪽 정렬이면 날짜, 왼쪽이면 텍스트 |

## 범위는 표로 만들어 두면 편합니다

데이터 범위를 선택하고 **Ctrl + T** 로 '표'를 만들어 두면, 아래에 행을 추가해도 범위가 자동으로 늘어납니다. 수식도 `=SUMIFS(매출[금액], 매출[지점], "서울")`처럼 열 이름으로 쓸 수 있어서 읽기 쉬워집니다.

## 정리

- **SUMIFS** 는 조건에 맞는 합계, **COUNTIFS** 는 조건에 맞는 개수. 조건은 '범위, 조건' 짝으로 계속 추가합니다.
- **날짜 구간** 은 같은 날짜 열에 `>=`와 `<=` 조건을 두 번.
- **셀 값과 비교** 할 때는 `">="&H1`처럼 `&`로 이어 붙이기.
- 모든 범위의 **크기를 똑같이** 맞추는 것이 오류를 막는 핵심입니다.
