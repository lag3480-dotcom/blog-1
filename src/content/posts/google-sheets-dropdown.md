여러 사람이 함께 쓰는 구글 시트에서 "상태" 칸에 `완료`, `끝`, `done`이 뒤섞이면 필터나 집계가 맞지 않습니다. **드롭다운** 을 만들어 두면 정해진 항목 중에서 클릭으로 고르게 할 수 있고, 항목마다 색을 지정해 한눈에 구분할 수도 있습니다.

이 글은 Google Docs 편집기 고객센터의 공식 도움말을 바탕으로 **컴퓨터(웹 브라우저)** 기준으로 정리했습니다. 엑셀에서 같은 작업을 하는 방법은 [엑셀 드롭다운 목록 만들기](/posts/excel-drop-down-list/)에 정리했습니다.

## 드롭다운을 만드는 4가지 방법

먼저 드롭다운을 넣을 셀(또는 범위)을 선택한 뒤, 아래 중 편한 방법을 고릅니다.

| 방법 | 방법 |
|---|---|
| 메뉴 | **삽입** → **드롭다운** |
| 데이터 메뉴 | **데이터** → **데이터 확인** → **규칙 추가** |
| 오른쪽 클릭 | 셀을 오른쪽 클릭 → **드롭다운** |
| @ 입력 | 셀에 `@` 를 입력하고 구성요소 섹션에서 **드롭다운** 선택 (프로젝트 상태, 우선순위 같은 미리 만든 항목 제공) |

어느 방법이든 오른쪽에 **데이터 확인 규칙** 패널이 열리고, 여기서 나머지를 설정합니다.

## 항목을 정하는 2가지 방식

패널의 **기준** 에서 둘 중 하나를 고릅니다.

| 기준 | 설명 | 좋은 경우 |
|---|---|---|
| **드롭다운** | 항목을 직접 입력. **다른 항목 추가** 로 칸을 늘림 | 대기·진행·완료처럼 항목이 적고 고정된 경우 |
| **드롭다운(범위)** | 시트의 셀 범위를 항목으로 사용 | 부서·담당자 목록처럼 자주 바뀌는 경우 |

**드롭다운(범위)** 를 쓰면 원본 범위의 값을 고칠 때 드롭다운 목록도 자동으로 바뀝니다. 항목 목록은 별도 시트(예: `목록` 시트)에 모아 두면 관리하기 쉽습니다.

### 단계별: 상태 드롭다운 만들기

1. 상태 열(예: D2:D100)을 선택합니다.
2. **삽입** → **드롭다운** 을 클릭합니다.
3. **기준** 이 **드롭다운** 인지 확인하고 첫 칸에 `대기` 를 입력합니다.
4. **다른 항목 추가** 를 눌러 `진행`, `완료` 를 차례로 입력합니다.
5. 각 항목 왼쪽의 색 버튼으로 색을 고릅니다. 예: 대기 회색, 진행 노랑, 완료 초록.
6. **완료** 를 누릅니다.

## 고급 옵션

패널 아래 **고급 옵션** 을 펼치면 다음을 정할 수 있습니다.

### 목록에 없는 값 입력을 막을지

기본 설정은 **목록에 없는 값 입력을 거부** 하는 것입니다. 다른 값도 입력할 수 있게 하려면 **데이터가 잘못된 경우:** 에서 **경고 표시** 를 고릅니다. 이 경우 입력은 되지만 셀에 경고 표시가 붙습니다.

| 설정 | 목록에 없는 값을 입력하면 |
|---|---|
| 기본값 (입력 거부) | 입력되지 않음 |
| **경고 표시** | 입력되고 경고 표시 |

값을 반드시 통일해야 하는 집계용 칸이라면 기본값을 그대로 두세요.

### 표시 스타일

**표시 스타일** 에서 드롭다운 모양을 바꿀 수 있습니다.

| 스타일 | 모양 |
|---|---|
| **칩** | 색깔 있는 둥근 버튼 모양 |
| **화살표** | 셀 오른쪽에 화살표 |
| **일반 텍스트** | 평범한 글자로 보임 |

## 여러 항목을 함께 고르기: 복수 선택 허용

한 셀에 "기획, 디자인"처럼 여러 항목을 고르게 하려면 **기준** 아래 **복수 선택 허용** 에 체크합니다. 주의할 점이 있습니다.

- **칩** 스타일 드롭다운에서만 동작합니다.
- 항목 앞뒤에 공백이 없도록 정리해야 합니다.
- **모바일에서는 복수 선택이 지원되지 않습니다.**

## 이미 값이 들어 있는 칸에 드롭다운 만들기

이미 값이 입력된 범위를 선택하고 오른쪽 클릭 → **드롭다운** 을 고르면, 들어 있던 값들이 드롭다운 항목으로 들어갑니다. 항목 순서는 열 방향(위에서 아래)으로 먼저, 그다음 행 방향으로 정해집니다. 기존 데이터를 정리하면서 드롭다운으로 바꿀 때 편리합니다.

## 드롭다운 수정·삭제하기

1. 드롭다운이 있는 셀을 선택합니다.
2. **데이터** → **데이터 확인** 을 열거나, 드롭다운의 수정 버튼을 클릭합니다.
3. 항목을 바꾸려면 **기준** 아래 항목을 고칩니다.
4. 드롭다운을 없애려면 **규칙 삭제** 를 클릭합니다.
5. **완료** 를 누릅니다.

## 셀을 고를 때 뜨는 추천 칩 끄기

데이터를 입력할 때 구글 시트가 드롭다운 칩을 제안하는 기능이 거슬린다면 **도구** → **추천 컨트롤** → **드롭다운 칩 제안 사용 설정** 에서 켜고 끌 수 있습니다.

## 안 될 때: 자주 나는 문제와 해결법

| 증상 | 원인 | 해결 |
|---|---|---|
| 다른 값이 입력되지 않음 | 기본값이 입력 거부 | 필요하면 **고급 옵션** 에서 **경고 표시** |
| 복수 선택 체크가 안 됨 / 안 보임 | 표시 스타일이 칩이 아님 | **표시 스타일** 을 **칩** 으로 |
| 휴대폰에서 여러 개를 못 고름 | 모바일은 복수 선택 미지원 | 컴퓨터에서 선택 |
| 원본 범위를 고쳤는데 항목이 그대로 | 기준이 **드롭다운**(직접 입력) | **드롭다운(범위)** 로 바꾸기 |
| 범위에서 지운 항목이 기준 목록에 남아 수정 안 됨 | 색이 지정된 값은 원본에서 지워도 남음 | 원본 범위를 바꾸거나 다른 항목 색을 변경 |
| 빈 셀의 드롭다운을 지우고 싶음 | 규칙이 남아 있음 | **규칙 삭제**, 또는 빈 셀에서 **Backspace** |

## 활용 팁: 값이 통일되면 집계가 쉬워집니다

드롭다운으로 값이 `대기`, `진행`, `완료` 세 가지로 통일되면, 상태별 건수를 세는 수식이 정확해집니다.

```text
=COUNTIF(D2:D100, "완료")
```

위 수식은 D2:D100에서 `완료`인 칸의 개수를 셉니다. 손으로 입력하던 때처럼 `완료됨`, `끝` 같은 변형이 섞이지 않으므로 숫자가 맞습니다.

## 정리

- **삽입 → 드롭다운** 이 가장 빠르고, 항목이 자주 바뀌면 **드롭다운(범위)** 를 고릅니다.
- 다른 값 입력은 기본적으로 막혀 있고, 허용하려면 **고급 옵션 → 경고 표시** 입니다.
- 여러 항목 선택은 **칩** 스타일에서 **복수 선택 허용** 으로 켜며, 모바일에서는 지원되지 않습니다.
