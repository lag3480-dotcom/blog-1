모임 참석 조사, 고객 만족도 설문, 행사 신청서처럼 여러 사람에게 같은 질문을 받을 때는 **구글 설문지(Google Forms)** 가 가장 간단합니다. 무료이고, 응답이 구글 스프레드시트에 자동으로 쌓여 정리하기도 쉽습니다.

이 글은 Google Docs 편집기 고객센터와 Google Workspace 학습 센터의 공식 도움말을 바탕으로 **컴퓨터(웹 브라우저)** 기준으로 정리했습니다. (작성일 2026년 10월 29일)

## 전체 흐름

| 단계 | 하는 일 |
|---|---|
| 1. 만들기 | forms.google.com → **빈 양식** → 제목 입력 |
| 2. 질문 추가 | 질문 유형 선택, **필수** 설정, 섹션 나누기 |
| 3. 게시 | 오른쪽 위 **게시** → 링크 복사 |
| 4. 응답 확인 | **응답** 탭에서 요약·개별 보기, 시트로 연결 |

## 1단계: 설문지 만들기

1. **forms.google.com** 에 접속합니다.
2. **빈 양식** 을 클릭합니다.
3. 맨 위 "제목 없는 양식"을 클릭해 설문 제목을 입력하고, 아래에 설명을 적습니다.

구글 드라이브에서는 **신규** 를 눌러 Google Forms를 선택해도 됩니다. 구글 시트에서 설문지를 만들면 응답이 그 파일의 새 시트에 저장됩니다.

## 2단계: 질문 추가하기

질문 추가 버튼을 누르고, 질문 제목 오른쪽에서 **질문 유형** 을 고릅니다.

| 질문 유형 | 쓰임 | 예 |
|---|---|---|
| **단답형** | 짧은 한 줄 답 | 이름, 연락처 |
| **장문형** | 여러 문장의 긴 답 | 건의 사항 |
| **객관식 질문** | 하나만 선택 ('기타' 추가 가능) | 참석 여부 |
| **체크박스** | 여러 개 선택 ('기타' 추가 가능) | 관심 분야 |
| **드롭다운** | 목록에서 하나 선택 | 소속 지역 |
| **파일 업로드** | 응답자가 파일 첨부 | 사진, 서류 |
| **직선 단계** | 숫자 범위로 평가 | 1~5점 만족도 |
| **평점** | 별·하트·엄지 모양으로 평가 | 강의 평점 |
| **객관식 그리드** | 행마다 하나씩 선택 | 항목별 만족도 |
| **체크박스 그리드** | 행·열 표에서 체크 | 요일별 가능 시간 |
| **날짜** / **시간** | 날짜, 시각 또는 기간 입력 | 희망 방문일 |

### 꼭 받아야 하는 질문은 '필수'로

질문 아래의 **필수** 를 켜면 그 질문에 답하지 않고는 제출할 수 없습니다. 이름이나 연락처처럼 빠지면 안 되는 질문에 켜 두세요.

### 질문마다 세부 조건 걸기

| 유형 | 정할 수 있는 조건 |
|---|---|
| 단답형 | 최대 글자 수 등 데이터 검증 |
| 장문형 | 최대·최소 글자 수 |
| 직선 단계 | 0 또는 1에서 시작, 2~10 사이 정수로 끝, 양 끝 라벨 |
| 평점 | 3~10 범위 |
| 파일 업로드 | 허용 파일 형식, 최대 파일 수, 최대 파일 크기 |

### 섹션으로 나누고, 답에 따라 다른 페이지로

질문이 많으면 **섹션** 을 추가해 나눕니다. 섹션마다 새 페이지로 시작해 응답자가 읽기 편해집니다.

**객관식 질문**, **체크박스**, **드롭다운** 은 답변에 따라 다른 섹션으로 보낼 수 있습니다. 질문 오른쪽 아래 **더보기** 에서 **답변을 기준으로 섹션 이동** 을 켜고, 선택지마다 이동할 섹션을 정합니다. 특정 답을 고르면 바로 끝내려면 **양식 제출** 을 선택합니다.

예: "참석하시나요?"에서 **예** → 식사 메뉴 섹션, **아니요** → **양식 제출**.

### 디자인과 미리보기

**테마 맞춤설정** 에서 색과 글꼴을 바꿀 수 있고, 오른쪽 위 **미리보기** 로 응답자 화면을 언제든 확인할 수 있습니다.

## 3단계: 게시하고 보내기

1. 오른쪽 위 **게시** 를 클릭합니다. 게시되면 **게시됨** 으로 표시됩니다.
2. **응답자 링크 복사** 를 클릭합니다. 링크가 길다면 **URL 축소** 체크박스를 선택합니다.
3. 복사한 링크를 메신저나 문자로 보냅니다.

| 보내는 방법 | 메뉴 |
|---|---|
| 링크 | **응답자 링크 복사** (필요하면 **URL 축소**) |
| 홈페이지에 넣기 | **HTML 삽입** |
| 응답할 수 있는 사람 지정 | **게시됨** → **관리** |

## 4단계: 응답 확인하고 시트로 받기

### 응답 탭에서 보기

| 보기 | 내용 |
|---|---|
| **요약** | 질문별 차트로 한눈에 (응답이 1개 이상 있어야 표시) |
| **개별 보기** | 응답자 한 명씩 앞뒤 화살표로 넘겨 보기 |

### 구글 스프레드시트로 자동 저장

1. 설문지에서 **응답** → **요약** 을 클릭합니다.
2. 오른쪽 위 **더보기** → **응답 저장 위치 선택** 을 클릭합니다.
3. **새 스프레드시트 만들기** 또는 **기존 스프레드시트 선택** 을 고릅니다.
4. **만들기** 또는 **선택** 을 클릭합니다.

이후 새 응답은 한 줄씩 시트에 자동으로 추가됩니다. 시트는 드라이브에 별도 파일로 만들어지며, 설문지 공동작업자에게 자동으로 접근 권한이 주어집니다. 다만 그 뒤 설문지 권한을 바꿔도 시트 권한은 **자동으로 동기화되지 않으므로** 둘 다 따로 바꿔야 합니다.

시트로 받은 응답은 [구글 스프레드시트 드롭다운](/posts/google-sheets-dropdown/)이나 필터로 정리하면 집계가 쉬워집니다.

### 그 밖의 응답 관리

| 하고 싶은 일 | 방법 |
|---|---|
| 새 응답마다 메일 받기 | **응답** → **더보기** → **새로운 응답에 대한 이메일 알림 받기** |
| CSV 파일로 내려받기 | **응답** → **더보기** → **응답 다운로드(.csv)** |
| 응답 마감 | **응답받기** 를 사용 중지로 전환 |
| 시트 연결 끊기 | **더보기** → **양식 연결 해제** → **연결 해제** (기존 시트 데이터는 유지) |

## 안 될 때: 자주 나는 문제와 해결법

| 증상 | 원인 | 해결 |
|---|---|---|
| **요약** 탭이 안 보임 | 아직 응답이 없음 | 응답이 1개 이상 들어오면 표시 |
| 응답자가 파일을 못 올림 | 파일 업로드는 구글 계정 로그인이 필요 | 응답자에게 로그인 안내, 또는 다른 질문 유형 사용 |
| 파일 업로드 질문을 추가할 수 없음 | 설문지가 공유 드라이브에 있거나 관리자가 데이터 손실 방지를 사용 | 내 드라이브에서 만들거나 관리자에게 문의 |
| 링크를 열면 응답할 수 없다고 나옴 | 응답받기가 꺼져 있음 | **응답받기** 다시 사용 |
| 다른 사람이 시트를 못 엶 | 설문지와 시트 권한이 따로 관리됨 | 시트에서 별도로 공유 |
| 응답을 실수로 지움 | 설문지 응답 삭제는 취소 불가 | 지우기 전에 CSV로 내려받아 두기 |
| 설문지를 메일 본문에 넣을 수 없음 | 파일 업로드, 채점 질문, 질문 속 이미지 등이 포함됨 | 링크로 보내기 |

참고로 설문지 하나의 저장용량은 양식 파일과 응답 데이터를 합쳐 **최대 1GB** 입니다. (응답자가 올린 파일은 제외)

## 정리

- **forms.google.com → 빈 양식** 으로 만들고, 질문 유형과 **필수** 를 정합니다.
- 오른쪽 위 **게시** 후 **응답자 링크 복사** 로 보냅니다.
- **응답 → 더보기 → 응답 저장 위치 선택** 으로 시트에 연결하면 응답이 자동으로 쌓입니다.
