업무 목록에서 "완료"된 줄은 회색으로, 마감이 지난 줄은 빨간색으로 표시해 두면 한눈에 상황이 보입니다. 그런데 조건부 서식의 기본 메뉴(**셀 강조 규칙**)로 하면 조건이 걸린 **셀 하나만** 색이 바뀝니다.

**행 전체** 를 칠하려면 **수식을 사용하는 규칙** 을 만들어야 하고, 핵심은 수식 안의 `$` 기호 하나입니다. 이 글은 Microsoft 공식 도움말을 바탕으로 Windows용 Excel 기준으로 정리했습니다.

## 예제 데이터

아래 업무 목록이 A1:E20에 있다고 하겠습니다. (1행은 제목)

| A 업무 | B 담당 | C 마감일 | D 상태 | E 금액 |
|---|---|---|---|---|
| 견적서 작성 | 김민수 | 2026-10-20 | 완료 | 1,200,000 |
| 계약 검토 | 이서연 | 2026-10-25 | 진행 | 800,000 |
| 납품 일정 확인 | 박지훈 | 2026-11-05 | 대기 | 300,000 |

## 기본 순서: 수식으로 규칙 만들기

1. 색을 칠할 **데이터 범위 전체** 를 선택합니다. 예: **A2:E20** (제목 행 제외)
2. **홈** 탭 → **조건부 서식** → **새 규칙** 을 클릭합니다.
3. **수식을 사용하여 서식을 지정할 셀 결정** 을 고릅니다.
4. 수식 칸에 `=` 로 시작하는 조건을 입력합니다. 예: `=$D2="완료"`
5. **서식** 버튼을 눌러 **채우기** 색 등을 고르고 **확인** 합니다.
6. **확인** 을 눌러 규칙을 저장합니다.

수식은 결과가 **참(TRUE) 또는 거짓(FALSE)** 이 되어야 합니다. 참이 되는 셀에만 서식이 적용됩니다.

## 핵심: 왜 `$D2` 일까

수식은 **선택한 범위의 첫 셀(A2)** 기준으로 씁니다. 엑셀은 이 수식을 범위의 나머지 셀에 맞게 자동으로 옮겨 가며 계산합니다.

| 수식 | B3 셀에서 계산될 때 | 결과 |
|---|---|---|
| `=$D2="완료"` | `=$D3="완료"` | 열은 D로 **고정**, 행만 바뀜 → 3행의 모든 칸이 D3을 봄 → **행 전체 색칠** |
| `=D2="완료"` | `=E3="완료"` | 열도 함께 밀림 → 각 칸이 다른 열을 봄 → **엉뚱한 칸만 색칠** |
| `=$D$2="완료"` | `=$D$2="완료"` | 행도 고정 → 모든 행이 D2만 봄 → **전부 칠하거나 전부 안 칠함** |

정리하면 **열 앞에만 `$`** 를 붙입니다. Microsoft 도움말도 범위 안에서 참조가 행·열에 맞게 바뀌어야 할 때는 상대 참조를, 고정해야 할 때는 `$`를 쓰라고 안내합니다.

> 수식 칸에서 시트의 셀을 마우스로 클릭하면 `$D$2` 같은 **절대 참조** 가 들어갑니다. 클릭으로 넣었다면 `$D2` 형태로 직접 고쳐 쓰세요.

## 예제 1. 완료된 업무를 회색으로

- 범위: A2:E20
- 수식: `=$D2="완료"`
- 서식: 회색 채우기, 회색 글꼴

## 예제 2. 마감이 지났는데 완료되지 않은 업무를 빨간색으로

- 범위: A2:E20
- 수식: `=AND($C2<TODAY(), $D2<>"완료")`
- 서식: 연한 빨간 채우기

마감일(C열)이 오늘보다 이전이고 상태(D열)가 "완료"가 아닌 행만 칠해집니다. TODAY를 쓰므로 날짜가 지나면 자동으로 색이 바뀝니다. [엑셀 날짜 함수](/posts/excel-date-functions/) 글도 함께 참고하세요.

## 예제 3. 금액이 100만원 이상인 행 강조

- 범위: A2:E20
- 수식: `=$E2>=1000000`

## 예제 4. 한 줄씩 번갈아 색칠하기

- 범위: A2:E20
- 수식: `=MOD(ROW(),2)=1`

ROW는 행 번호, MOD는 나머지를 구합니다. 행 번호를 2로 나눈 나머지가 1인 **홀수 행** 만 칠해집니다. 짝수 행을 칠하려면 `=1`을 `=0`으로 바꿉니다. 이 수식은 Microsoft 도움말의 예제와 같습니다.

## 규칙이 여러 개일 때: 규칙 관리

예제 1과 2를 함께 쓰면 한 행이 두 조건에 동시에 해당할 수 있습니다. 이때는 **규칙 순서** 가 중요합니다.

1. **홈** → **조건부 서식** → **규칙 관리** 를 엽니다.
2. **위로 이동** / **아래로 이동** 버튼으로 순서를 바꿉니다. **위에 있는 규칙이 우선** 합니다.
3. 위 규칙이 참일 때 아래 규칙을 보지 않게 하려면 **True일 경우 중지** 에 체크합니다.
4. **적용 대상** 칸에서 규칙이 적용되는 범위를 고칠 수 있습니다. 행이 늘어났다면 여기서 범위를 넓힙니다.

## 규칙 지우기

| 하고 싶은 일 | 메뉴 |
|---|---|
| 시트의 모든 조건부 서식 삭제 | **조건부 서식** → **규칙 지우기** → **시트 전체에서 규칙 지우기** |
| 선택한 칸의 규칙만 삭제 | 셀 선택 → **규칙 지우기** → **선택한 셀의 규칙 지우기** |
| 규칙 하나만 삭제 | **규칙 관리** 에서 해당 규칙 선택 → **규칙 삭제** |

## 안 될 때: 자주 나는 문제와 해결법

| 증상 | 원인 | 해결 |
|---|---|---|
| 조건 셀 하나만 칠해짐 | 수식 대신 **셀 강조 규칙** 을 썼거나 범위를 한 열만 선택 | 범위를 A2:E20처럼 전체 선택하고 수식 규칙으로 |
| 한 칸씩 밀려서 칠해짐 | 수식 행 번호가 범위 첫 행과 다름 (예: 범위 A2부터인데 `$D1`) | 범위 첫 행 번호와 수식의 행 번호를 맞추기 |
| 모든 행이 칠해지거나 아무것도 안 칠해짐 | `$D$2`처럼 행까지 고정 | `$D2`로 고치기 |
| 색이 전혀 안 보임 | 수식에 오류가 있음 (오류가 나는 셀은 서식이 적용되지 않음) | 수식을 빈 셀에 입력해 결과가 TRUE/FALSE인지 확인 |
| "완료"인데 안 칠해짐 | 셀에 공백이 섞여 있음 (`완료 `) | 공백 제거, 또는 [드롭다운 목록](/posts/excel-drop-down-list/)으로 값 통일 |
| 직접 칠한 색이 사라짐 | 조건부 서식이 수동 서식보다 우선 | 의도한 동작. 수동 색은 조건부 서식이 없는 칸에만 |
| 다른 파일 셀을 조건으로 쓰려 함 | 다른 통합 문서 참조는 지원 안 됨 | 같은 파일로 값을 가져온 뒤 그 셀을 참조 |

## 정리

- 행 전체를 칠하려면 **범위 전체 선택** → **수식을 사용하여 서식을 지정할 셀 결정** 을 씁니다.
- 수식은 범위 첫 행 기준으로, **열 앞에만 `$`** 를 붙입니다. 예: `=$D2="완료"`
- 규칙이 여러 개면 **규칙 관리** 에서 순서와 **True일 경우 중지** 를 정합니다.
