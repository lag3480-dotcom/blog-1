보고서나 논문의 목차를 손으로 입력하면, 본문을 조금만 고쳐도 쪽 번호가 밀려서 목차를 처음부터 다시 맞춰야 합니다. 워드의 **자동 목차** 를 쓰면 클릭 한 번으로 제목과 쪽 번호를 다시 맞출 수 있습니다.

핵심은 하나입니다. 워드는 **제목 스타일이 지정된 문단** 을 모아 목차를 만듭니다. 이 글은 Microsoft 공식 도움말을 바탕으로 Windows용 Word 기준으로 정리했습니다.

## 전체 흐름 한눈에 보기

| 단계 | 할 일 | 메뉴 |
|---|---|---|
| 1 | 장·절 제목에 제목 스타일 지정 | **홈** 탭 → **스타일** → **제목 1**, **제목 2**, **제목 3** |
| 2 | 목차 넣기 | **참조** 탭 → **목차** → **자동 목차 1** 또는 **자동 목차 2** |
| 3 | 본문 수정 후 목차 맞추기 | **참조** 탭 → **목차 업데이트** |

## 1단계. 제목에 스타일 지정하기

목차에 나올 제목마다 스타일을 지정합니다.

1. 장 제목(예: `1. 사업 개요`)의 글자를 선택합니다.
2. **홈** 탭의 **스타일** 에서 **제목 1** 을 클릭합니다.
3. 그 아래 절 제목(예: `1.1 추진 배경`)은 **제목 2**, 더 작은 항목은 **제목 3** 으로 지정합니다.
4. 문서 전체의 제목에 같은 방식으로 반복합니다.

| 문서 구조 | 지정할 스타일 | 목차에서 |
|---|---|---|
| 장 (1. 사업 개요) | **제목 1** | 가장 바깥 수준 |
| 절 (1.1 추진 배경) | **제목 2** | 한 칸 들여쓰기 |
| 항 (1.1.1 현황) | **제목 3** | 두 칸 들여쓰기 |

> 글자를 크게, 굵게 만든 것만으로는 목차에 들어가지 않습니다. 반드시 **제목** 스타일이 지정되어야 합니다.

스타일의 글꼴이나 크기가 마음에 들지 않으면, 스타일 목록에서 **제목 1** 을 오른쪽 클릭 → **수정** 으로 모양을 바꿀 수 있습니다. 이렇게 하면 같은 스타일을 쓴 제목이 한꺼번에 바뀝니다.

## 2단계. 목차 넣기

1. 목차가 들어갈 위치(보통 표지 다음 쪽)를 클릭합니다.
2. **참조** 탭에서 **목차** 를 클릭합니다.
3. **자동 목차 1** 또는 **자동 목차 2** 를 고릅니다.

바로 제목과 쪽 번호가 정리된 목차가 들어갑니다. 목차 위치를 따로 한 쪽으로 쓰고 싶다면 목차 뒤에 **페이지 나누기** 를 넣어 두면 본문이 다음 쪽에서 시작합니다.

### 예시: 이렇게 지정하면 이렇게 나옵니다

본문에서 아래처럼 스타일을 지정했다면

```text
1. 사업 개요            ← 제목 1
1.1 추진 배경           ← 제목 2
1.2 추진 목표           ← 제목 2
2. 세부 계획            ← 제목 1
2.1 일정                ← 제목 2
```

자동 목차는 대략 이런 모양이 됩니다. (쪽 번호는 예시)

```text
1. 사업 개요 ........................ 2
   1.1 추진 배경 .................... 2
   1.2 추진 목표 .................... 3
2. 세부 계획 ........................ 4
   2.1 일정 ......................... 4
```

목차에는 본문 제목에 붙은 번호(`1.`, `1.1`)가 그대로 나옵니다. 제목에 번호가 없다면 목차에도 번호 없이 제목만 나옵니다.

## 3단계. 본문을 고친 뒤 목차 업데이트하기

목차는 자동으로 계속 바뀌지 않습니다. 본문을 고친 뒤에는 직접 업데이트해야 합니다.

1. **참조** 탭에서 **목차 업데이트** 를 클릭합니다. (목차를 오른쪽 클릭 → **필드 업데이트** 도 같습니다.)
2. 둘 중 하나를 고릅니다.
3. **확인** 을 누릅니다.

| 선택지 | 반영되는 것 | 이럴 때 |
|---|---|---|
| **쪽 번호만 업데이트** | 쪽 번호만 | 본문 분량만 바뀌었을 때 |
| **목차 전체 업데이트** | 제목 글자, 새로 추가된 제목, 쪽 번호 모두 | 제목을 고치거나 새 장을 추가했을 때 |

헷갈리면 **목차 전체 업데이트** 를 고르면 됩니다. 다만 목차 안의 글자를 직접 고쳐 두었다면 전체 업데이트 때 그 수정이 사라지니, 제목은 본문에서 고치세요.

### 인쇄 전에 자동으로 업데이트하기

인쇄할 때마다 업데이트를 잊는다면 **파일** → **옵션** → **표시** 의 **인쇄 옵션** 에서 **인쇄 전에 필드 업데이트** 를 켜 두세요. 문서 전체의 필드를 한 번에 업데이트하려면 **Ctrl+A** 로 전체 선택한 뒤 **F9** 를 누릅니다.

## 목차 모양 바꾸기: 사용자 지정 목차

**참조** → **목차** → **사용자 지정 목차** 를 열면 다음을 바꿀 수 있습니다.

| 설정 | 하는 일 | 예 |
|---|---|---|
| **수준 표시** | 목차에 몇 단계 제목까지 넣을지 | 2로 하면 제목 1·제목 2만 표시 |
| **탭 채움선** | 제목과 쪽 번호 사이 선 모양 | 점선, 실선, 없음 |
| **쪽 번호 표시** / **오른쪽 맞춤** | 쪽 번호 표시 여부와 정렬 | 쪽 번호 없이 목록만 필요할 때 끄기 |
| **서식** | 목차 전체 디자인 | 서식 목록에서 선택 |
| **수정** | 목차 수준별 글꼴·간격 | 장 제목만 굵게 |

**수정** 버튼이 회색이라면 **서식** 을 **서식 파일에서** 로 바꾸면 활성화됩니다. 수정 화면에서 바꾸고 싶은 수준(목차 1, 목차 2 …)을 골라 **수정** 을 누르고, 글꼴이나 간격을 바꾼 뒤 **확인** 합니다.

## 안 될 때: 자주 나는 문제와 해결법

| 증상 | 원인 | 해결 |
|---|---|---|
| 목차에 특정 제목이 없음 | 그 제목에 제목 스타일이 없음 (굵게만 했음) | 제목에 **제목 1/2/3** 지정 → **목차 전체 업데이트** |
| 본문 문장이 목차에 들어감 | 일반 문단에 제목 스타일이 잘못 적용됨 | 그 문단을 **표준** 스타일로 바꾸고 전체 업데이트 |
| 쪽 번호가 실제와 다름 | 본문 수정 후 업데이트를 안 함 | **목차 업데이트** → **쪽 번호만 업데이트** |
| 제목 3이 목차에 안 나옴 | **수준 표시** 가 2로 설정됨 | **사용자 지정 목차** 에서 수준 표시를 3으로 |
| 업데이트 메뉴가 없음 | 손으로 입력한 목차 | 자동 목차로 다시 넣기 (손으로 쓴 목차는 업데이트되지 않음) |
| 목차 디자인 **수정** 버튼이 회색 | 서식이 서식 파일이 아님 | **서식** 을 **서식 파일에서** 로 |

## 정리

- 목차는 **제목 스타일** 로 만듭니다. 장은 **제목 1**, 절은 **제목 2** 로 지정하세요.
- **참조 → 목차 → 자동 목차** 로 넣고, 본문을 고친 뒤에는 **목차 업데이트** 를 누릅니다.
- 단계 수와 점선 모양은 **사용자 지정 목차** 에서 바꿉니다.
