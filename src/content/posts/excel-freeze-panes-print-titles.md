데이터가 수백 행인 엑셀 표를 아래로 내리다 보면 맨 위의 머리글이 사라져서 "이 열이 금액이었나, 수량이었나"를 다시 올라가 확인하게 됩니다. 인쇄할 때도 마찬가지입니다. 첫 장에만 제목 행이 찍히고 두 번째 장부터는 숫자만 나와서 읽기 어렵습니다.

이 두 문제는 각각 **틀 고정** 과 **인쇄 제목** 으로 해결합니다. 이름은 비슷해 보여도 하나는 화면, 하나는 인쇄용이라 따로 설정해야 합니다. 이 글은 Microsoft 공식 도움말을 바탕으로 Windows용 Excel 기준으로 정리했습니다.

## 먼저 구분하기: 화면용과 인쇄용

| 기능 | 효과 | 메뉴 위치 |
|---|---|---|
| **틀 고정** | 화면에서 스크롤해도 지정한 행·열이 계속 보임 | **보기** 탭 → **틀 고정** |
| **인쇄 제목** | 인쇄할 때 모든 페이지에 지정한 행·열이 반복 | **페이지 레이아웃** 탭 → **페이지 설정** 그룹 |

틀 고정을 해 두어도 인쇄 결과에는 영향이 없습니다. 인쇄물에 머리글을 반복하려면 반드시 인쇄 제목을 따로 설정해야 합니다.

## 틀 고정 1. 첫 행이나 첫 열만 고정하기

가장 많이 쓰는 경우입니다. 셀을 따로 선택할 필요가 없습니다.

1. **보기** 탭을 클릭합니다.
2. **틀 고정** 을 클릭해 목록을 엽니다.
3. 필요한 항목을 고릅니다.
   - **첫 행 고정**: 1행만 고정합니다. 1행 아래에 조금 진한 선이 생깁니다.
   - **첫 열 고정**: A열만 고정합니다. A열 오른쪽에 진한 선이 생깁니다.

첫 행 고정과 첫 열 고정은 동시에 적용되지 않습니다. 둘 다 고정하려면 다음 방법을 씁니다.

## 틀 고정 2. 여러 행과 열을 함께 고정하기

핵심 규칙은 하나입니다. Microsoft 도움말 표현으로는 **"틀 고정은 선택한 셀의 위쪽 행과 왼쪽 열을 고정"** 합니다. 그래서 고정하고 싶은 영역의 **바로 아래, 바로 오른쪽 셀** 을 선택한 뒤 틀 고정을 누르면 됩니다.

1. 기준 셀을 선택합니다. (아래 표 참고)
2. **보기** → **틀 고정** → **틀 고정** 을 클릭합니다.

| 고정하고 싶은 범위 | 선택할 셀 | 이유 |
|---|---|---|
| 1행 + A열 | **B2** | B2의 위쪽은 1행, 왼쪽은 A열 |
| 1~2행 (열은 고정 안 함) | **A3** | A3의 위쪽은 1~2행, 왼쪽에는 열이 없음 |
| A~B열 (행은 고정 안 함) | **C1** | C1의 위쪽에는 행이 없고, 왼쪽은 A~B열 |
| 1~4행 + A~C열 | **D5** | D5의 위쪽은 1~4행, 왼쪽은 A~C열 |

> 표 제목이 1~3행에 걸쳐 있고 실제 머리글이 3행에 있다면, A4를 선택하고 틀 고정을 하면 됩니다.

고정은 항상 시트의 맨 위 행과 맨 왼쪽 열부터 시작합니다. 중간의 10~12행만 골라서 고정하는 기능은 없습니다. 이런 경우에는 창을 **나누기** 로 분할해 같은 시트의 다른 부분을 함께 보는 방법을 고려할 수 있습니다.

### 고정 풀기

**보기** 탭에서 **틀 고정** 을 열고 **틀 고정 취소** 를 클릭합니다. 기준 셀을 바꾸고 싶을 때도 먼저 취소한 뒤 새 셀을 선택해 다시 고정합니다.

## 인쇄 제목: 모든 페이지에 머리글 반복하기

1. 인쇄할 시트를 엽니다. 이때 셀을 편집 중이면(커서가 셀 안에서 깜박이면) **Esc** 를 눌러 빠져나옵니다.
2. **페이지 레이아웃** 탭의 **페이지 설정** 그룹에서 **인쇄 제목** 을 클릭합니다. (도움말 번역본에서는 '제목 인쇄'로 표기되기도 합니다.)
3. **페이지 설정** 창의 **시트** 탭이 열립니다.
4. **맨 위에 반복할 행** 칸에 반복할 행을 입력합니다. 1행이면 `$1:$1`, 1~2행이면 `$1:$2` 입니다.
5. 열을 반복하려면 **왼쪽에서 반복할 열** 칸에 입력합니다. A열이면 `$A:$A` 입니다.
6. **확인** 을 누릅니다.

직접 입력하기 어렵다면 칸 오른쪽 끝의 작은 버튼을 누른 뒤 시트에서 행 머리글(1, 2 같은 숫자)을 드래그해 선택해도 됩니다. 주소가 자동으로 들어갑니다.

### 제대로 되었는지 확인하기

**파일** → **인쇄** (단축키 **Ctrl+P**) 화면의 미리 보기에서 페이지를 넘겨 보세요. 두 번째 페이지부터도 맨 위에 머리글 행이 보이면 성공입니다.

### 인쇄 제목 입력 예시

| 원하는 결과 | 맨 위에 반복할 행 | 왼쪽에서 반복할 열 |
|---|---|---|
| 1행 머리글만 반복 | `$1:$1` | (비움) |
| 제목 줄 + 머리글 (1~3행) 반복 | `$1:$3` | (비움) |
| 이름이 든 A열만 반복 (가로로 긴 표) | (비움) | `$A:$A` |
| 머리글 1행과 A열 모두 반복 | `$1:$1` | `$A:$A` |

인쇄 제목은 **시트마다 따로** 저장됩니다. 시트가 여러 개라면 시트별로 설정해야 합니다.

## 틀 고정과 인쇄 제목 함께 쓰는 순서

보고서용 표라면 두 가지를 모두 해 두는 편이 좋습니다.

1. 머리글 바로 아래 셀(예: A2)을 선택하고 **틀 고정** 을 합니다. 작업하는 동안 화면에서 머리글이 보입니다.
2. **인쇄 제목** 에서 같은 머리글 행(`$1:$1`)을 지정합니다. 인쇄물에도 머리글이 반복됩니다.
3. 인쇄 미리 보기로 마지막 페이지까지 확인합니다.

## 안 될 때: 자주 나는 문제와 해결법

| 증상 | 원인 | 해결 |
|---|---|---|
| **보기** 탭이 없음 | Excel Starter 사용 (Microsoft 도움말 안내) | 일부 기능이 지원되지 않는 버전이므로 다른 Excel 버전에서 작업 |
| 틀 고정 버튼이 회색 | 셀 편집 중이거나 페이지 레이아웃 보기 상태 | **Esc** 로 편집을 끝내고 **보기** 탭에서 **기본** 보기로 바꾼 뒤 다시 시도 |
| 원하는 것보다 많이 고정됨 | 기준 셀을 잘못 선택 | **틀 고정 취소** 후 "고정할 영역의 바로 아래·오른쪽 셀"을 선택해 다시 고정 |
| **인쇄 제목** 버튼이 회색 | 셀 편집 중, 차트 선택, 또는 프린터가 설치되지 않음 | 편집 종료·차트 선택 해제, 프린터(또는 PDF 프린터) 설치 확인 |
| 반복할 행 칸이 회색이라 입력 안 됨 | 시트가 2개 이상 선택된 그룹 상태 | 선택되지 않은 시트 탭을 클릭하거나, 시트 탭을 오른쪽 클릭 → **시트 그룹 해제** |
| 인쇄하면 2쪽부터 머리글이 없음 | 틀 고정만 하고 인쇄 제목은 안 함 | 위의 **인쇄 제목** 설정 진행 |

Mac용 Excel 도움말은 틀 고정 버튼이 회색일 때 **보기** 탭에서 **기본** 을 먼저 고르라고 안내합니다. Windows에서도 페이지 레이아웃 보기 상태라면 기본 보기로 바꿔 보세요.

## 정리

- 화면에서 머리글을 붙잡아 두려면 **보기 → 틀 고정** 입니다. 1행만이면 **첫 행 고정**, 여러 행·열이면 고정할 영역의 **바로 아래·오른쪽 셀** 을 선택하고 **틀 고정** 을 누릅니다.
- 인쇄물 모든 페이지에 머리글을 넣으려면 **페이지 레이아웃 → 인쇄 제목 → 맨 위에 반복할 행** 에 `$1:$1` 처럼 입력합니다.
- 두 설정은 서로 별개입니다. 보고서라면 둘 다 해 두고 인쇄 미리 보기로 확인하세요.
