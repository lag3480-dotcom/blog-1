보고서를 쓰면서 자료를 보거나, 엑셀과 메일을 나란히 띄우고 싶을 때 창 크기를 일일이 맞추는 것은 번거롭습니다. 윈도우 11의 **창 스냅** 기능을 쓰면 창을 화면 절반이나 4분의 1 크기로 한 번에 맞출 수 있습니다.

이 글은 Microsoft 공식 도움말 "창 스냅"을 바탕으로 **윈도우 11** 기준으로 정리했습니다. (작성일 2026년 11월 3일)

## 방법 한눈에 보기

| 방법 | 조작 | 결과 |
|---|---|---|
| 끌어서 스냅 | 창 제목 표시줄을 화면 왼쪽·오른쪽 가장자리로 끌기 | 화면 절반 |
| 모서리로 끌기 | 창을 화면 모서리로 끌기 | 화면 4분의 1 |
| 단축키 | **Windows 키 + 방향 화살표** | 현재 창을 원하는 쪽에 스냅 |
| 스냅 레이아웃 | 최대화 단추에 마우스 올리기 또는 **Windows 키 + Z** | 여러 배치 중 선택 |
| 스냅 바 | 창을 화면 맨 위로 끌기 | 레이아웃 막대에서 선택 |

## 방법 1. 마우스로 끌어서 나누기

1. 창의 제목 표시줄(맨 위 줄)을 클릭한 채로 끕니다.
2. 화면 **왼쪽 또는 오른쪽 가장자리** 로 끌면 그쪽 절반에 맞춰집니다.
3. 화면 **모서리** 로 끌면 4분의 1 영역에 맞춰집니다.

화면 **맨 위** 로 끌면 현재 너비를 유지한 채 세로로 화면 높이를 꽉 채우는 동작도 있습니다.

### 끌기 도우미: 반대쪽 창 고르기

창 하나를 한쪽 가장자리에 스냅하면, 열려 있는 다른 창들의 **축소판 그림** 이 나머지 영역에 나타납니다. 이 가운데 하나를 클릭하면 반대편에 바로 맞춰져, 두 창이 화면을 반씩 나눠 씁니다.

## 방법 2. 단축키로 빠르게

1. 나눌 창을 클릭해 선택합니다.
2. **Windows 키 + 왼쪽 화살표** 또는 **오른쪽 화살표** 를 누릅니다.
3. Windows 키를 누른 채로 화살표를 더 눌러 위치를 바꾸고, 원하는 위치에서 키를 놓으면 확정됩니다.

키를 떼는 순간 위치가 정해지므로, 원하는 칸이 표시될 때까지 화살표를 눌러 보며 조정하면 됩니다.

## 방법 3. 스냅 레이아웃으로 3~4개 배치하기

여러 창을 정해진 모양으로 배치하려면 **스냅 레이아웃** 이 편합니다.

1. 창 오른쪽 위 **최대화 단추** 위에 마우스를 올리거나 **Windows 키 + Z** 를 누릅니다.
2. 나타나는 레이아웃 목록에서 원하는 배치와 그 안의 칸을 선택합니다.
3. 현재 창이 그 칸에 들어가고, 나머지 칸에는 끌기 도우미로 다른 창을 고릅니다.

창을 **화면 맨 위로 끌어도** 레이아웃 막대(스냅 바)가 나타나 같은 방식으로 고를 수 있습니다. 공식 도움말에 따르면 보이는 레이아웃은 **디스플레이 크기에 따라 달라질 수 있습니다**. 큰 모니터일수록 더 많은 배치가 나옵니다.

### 상황별 추천 배치

| 작업 | 배치 |
|---|---|
| 자료 보며 문서 작성 | 반반 2분할 |
| 엑셀 + 메일 + 메신저 | 왼쪽 큰 칸 + 오른쪽 위아래 2칸 |
| 여러 자료 비교 | 4분할 |

## 스냅한 창 크기 조절과 스냅 그룹

- 스냅된 두 창 사이의 **구분선** 에 마우스를 올리고 끌면 두 창 크기가 함께 바뀝니다.
- 함께 스냅한 창들은 자동으로 하나의 **그룹** 이 됩니다. 작업 표시줄에서 그룹에 속한 앱 아이콘에 마우스를 올리면 그룹 전체를 한 번에 다시 불러오거나 개별 앱만 열 수 있습니다.
- 그룹은 **작업 보기** 와 **Alt + Tab** 화면에도 표시됩니다.

다른 일을 하다가 원래의 분할 화면으로 돌아갈 때 그룹 기능이 특히 편합니다.

## 설정에서 켜고 끄기

1. **설정** → **시스템** → **멀티태스킹** 으로 이동합니다.
2. **창 스냅** 을 켜거나 끕니다.
3. 펼치면 다음과 같은 세부 옵션을 고를 수 있습니다.

| 옵션 | 설명 |
|---|---|
| 끌기 도우미 표시 | 스냅 후 반대쪽에 다른 창 축소판 표시 |
| 스냅 플라이아웃 | 최대화 단추에 마우스를 올리면 레이아웃 표시 |
| 스냅 바 | 창을 위로 끌 때 레이아웃 막대 표시 |
| 그룹 스냅 표시 | 작업 표시줄 등에서 스냅 그룹 표시 |
| 가장자리까지 끌지 않고 스냅 | 화면 끝까지 끌지 않아도 스냅 |

> 메뉴에 표시되는 문구는 윈도우 버전에 따라 조금 다를 수 있습니다.

## 안 될 때: 자주 겪는 문제와 해결법

| 증상 | 원인 | 해결 |
|---|---|---|
| 가장자리로 끌어도 반으로 안 나뉨 | **창 스냅** 이 꺼져 있음 | 설정 → 시스템 → 멀티태스킹에서 켜기 |
| 최대화 단추에 레이아웃이 안 나옴 | 스냅 플라이아웃 옵션 꺼짐, 또는 앱이 지원하지 않음 | 옵션 켜기, 다른 앱에서 시험 |
| 반대쪽에 다른 창 목록이 안 나옴 | 끌기 도우미 옵션 꺼짐 | 창 스냅 세부 옵션에서 켜기 |
| 4분할 레이아웃이 안 보임 | 화면 크기에 따라 레이아웃이 다름 | 모서리로 끌기나 단축키로 4분할 |
| 작게 줄일 수 없는 창이 있음 | 앱의 최소 크기 제한 | 그 앱은 큰 칸에 배치 |

## 정리

- 창을 **가장자리로 끌면 반**, **모서리로 끌면 4분의 1** 로 나뉩니다.
- 단축키 **Windows 키 + 방향 화살표**, 레이아웃 목록은 **Windows 키 + Z** 입니다.
- 기능이 안 되면 **설정 → 시스템 → 멀티태스킹 → 창 스냅** 을 확인합니다.
