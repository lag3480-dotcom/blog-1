윈도우 단축키는 수백 개가 있지만, 실제로 매일 쓰는 것은 20~30개 정도입니다. Microsoft 공식 단축키 목록에서 **업무에 바로 도움이 되는 것만** 골라 상황별로 묶었습니다. 아래에서 **Win** 은 키보드의 윈도우 로고 키입니다.

## 가장 먼저 외울 5가지

| 단축키 | 동작 |
|---|---|
| **Win + D** | 바탕 화면 보기 / 다시 누르면 원래대로 |
| **Win + E** | 파일 탐색기 열기 |
| **Win + L** | 화면 잠금 (자리 비울 때) |
| **Alt + Tab** | 열린 창 사이 전환 (Alt를 누른 채 Tab을 반복) |
| **Win + V** | 클립보드 기록 열기 |

특히 **Win + L** 은 사무실에서 자리를 비울 때 꼭 쓰는 습관을 들이면 좋습니다.

## 창 정리하기

| 단축키 | 동작 |
|---|---|
| **Win + ←** / **Win + →** | 현재 창을 화면 왼쪽 / 오른쪽 절반에 붙이기 |
| **Win + ↑** | 창 최대화 |
| **Win + ↓** | 창 최소화 |
| **Win + Z** | 스냅 레이아웃 열기 (화면을 2~4칸으로 나누는 배치 고르기) |
| **Win + Home** | 지금 창만 남기고 나머지 모두 최소화 / 다시 누르면 복원 |
| **Win + Shift + ←** / **→** | 현재 창을 왼쪽 / 오른쪽 모니터로 옮기기 |

문서를 보면서 다른 문서를 작성할 때는 **Win + ←**, **Win + →** 로 화면을 반씩 나누면 편합니다. 모니터가 크다면 **Win + Z** 로 3칸, 4칸 배치를 고를 수 있습니다.

## 가상 데스크톱: 업무용과 개인용 화면 나누기

| 단축키 | 동작 |
|---|---|
| **Win + Tab** | 작업 보기 (열린 창과 데스크톱 전체 보기) |
| **Win + Ctrl + D** | 새 데스크톱 만들기 |
| **Win + Ctrl + ←** / **→** | 데스크톱 사이 이동 |
| **Win + Ctrl + F4** | 지금 쓰는 데스크톱 닫기 |

가상 데스크톱은 모니터를 여러 개 가진 것처럼 쓰는 기능입니다. 예를 들어 '보고서 작업' 데스크톱과 '메신저·메일' 데스크톱을 나누면 집중하기 좋습니다. 데스크톱을 닫아도 그 안의 창은 옆 데스크톱으로 옮겨질 뿐 닫히지 않습니다.

## 입력을 빠르게

| 단축키 | 동작 |
|---|---|
| **Win + V** | 클립보드 기록 (최근에 복사한 항목 여러 개 중 골라 붙여넣기) |
| **Win + .** (마침표) | 이모지·특수문자 패널 |
| **Win + H** | 음성 입력 (말하면 글자로 입력) |
| **Win + Shift + S** | 화면 일부 캡처 |

**Win + V** 는 처음 누르면 '켜기' 버튼이 나옵니다. Microsoft 안내대로 클립보드 기록은 **기본적으로 꺼져 있어서** 한 번 켜 줘야 합니다. 켜 두면 여러 내용을 연달아 복사한 뒤 하나씩 골라 붙여넣을 수 있어서, 이 단축키 하나로 작업 속도가 크게 달라집니다.

**Win + .** 은 이모지뿐 아니라 화살표, 수학 기호 같은 특수문자도 찾을 수 있어서 문서 작업에 유용합니다.

## 설정과 시스템

| 단축키 | 동작 |
|---|---|
| **Win + I** | 설정 열기 |
| **Win + X** | 빠른 링크 메뉴 (장치 관리자, 디스크 관리, 터미널 등) |
| **Win + A** | 빠른 설정 (와이파이, 블루투스, 밝기, 소리) |
| **Win + N** | 알림 센터와 달력 |
| **Ctrl + Shift + Esc** | 작업 관리자 바로 열기 |
| **Win + 숫자(1~9)** | 작업 표시줄에 고정된 앱을 순서대로 실행 / 전환 |

**Win + 숫자** 는 의외로 모르는 분이 많습니다. 작업 표시줄 왼쪽부터 첫 번째 앱이 Win + 1, 두 번째가 Win + 2입니다. 크롬을 첫 번째에 고정해 두면 **Win + 1** 로 바로 열 수 있습니다.

프로그램이 멈췄을 때는 **Ctrl + Shift + Esc** 로 작업 관리자를 바로 열어 해당 프로그램을 종료하세요.

## 파일 탐색기

| 단축키 | 동작 |
|---|---|
| **Ctrl + Shift + N** | 새 폴더 만들기 |
| **F2** | 선택한 파일 이름 바꾸기 |
| **Alt + Enter** | 선택한 파일의 속성 보기 |
| **Ctrl + T** | 새 탭 열기 |

윈도우 11 파일 탐색기는 브라우저처럼 **탭** 을 지원합니다. 폴더 여러 개를 오가며 파일을 옮길 때 창을 여러 개 띄우는 대신 **Ctrl + T** 로 탭을 열어 보세요.

여러 파일을 한꺼번에 선택하고 **F2** 를 누르면 `사진 (1)`, `사진 (2)`처럼 번호를 붙여 이름을 한 번에 바꿀 수 있습니다.

## 단축키가 안 먹힐 때

- **노트북**: 일부 키는 **Fn** 키와 함께 눌러야 합니다.
- **게이밍 키보드**: 게임 모드에서는 윈도우 키가 잠기는 경우가 있습니다. 키보드의 잠금 표시등이나 Fn + 윈도우 키 조합을 확인하세요.
- **원격 데스크톱·가상 머신**: 일부 단축키는 내 PC가 아니라 원격 PC에 전달되거나 막힐 수 있습니다.
- **회사 PC**: 보안 정책으로 일부 기능(클립보드 기록 등)이 꺼져 있을 수 있습니다.

## 정리

처음부터 25개를 다 외울 필요는 없습니다. 이번 주에는 **Win + D, Win + E, Win + L, Win + V, Win + ←/→** 다섯 개만 의식적으로 써 보세요. 손에 익으면 다음 묶음을 하나씩 늘려 가면 됩니다.
