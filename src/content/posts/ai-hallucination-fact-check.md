AI 챗봇은 모르는 내용도 자신 있는 말투로 답할 때가 있습니다. 존재하지 않는 책 제목, 틀린 날짜, 없는 법 조항을 그럴듯하게 만들어 내는 현상을 **환각(hallucination, 할루시네이션)** 이라고 부릅니다.

환각을 완전히 없앨 수는 없지만, 질문하는 방식을 바꾸면 크게 줄일 수 있습니다. 이 글은 Claude를 만든 Anthropic의 공식 문서 "Reduce hallucinations"에 나온 기법을 중심으로, 어떤 AI에서든 쓸 수 있는 프롬프트와 확인 순서를 정리했습니다. (작성일 2026년 11월 1일)

## 환각이 잘 생기는 질문

| 질문 유형 | 왜 위험한가 | 예 |
|---|---|---|
| 아주 구체적인 숫자·날짜 | 기억이 흐릿해도 숫자를 만들어 냄 | "그 법이 시행된 날짜는?" |
| 출처·논문·책 제목 요청 | 실제처럼 보이는 가짜 제목이 나올 수 있음 | "관련 논문 5개 알려줘" |
| 최신 정보 | 학습 이후 바뀐 내용을 모를 수 있음 | "올해 요금제 가격은?" |
| 긴 문서 요약 | 문서에 없는 내용을 섞을 수 있음 | "이 계약서 핵심 정리해 줘" |
| 답이 없는 질문 | 답이 없다고 말하는 대신 지어냄 | "이 회사의 비공개 매출은?" |

## 기본 기법 1. "모르면 모른다고 말해"를 허락하기

Anthropic 문서가 가장 먼저 소개하는 방법입니다. AI에게 **불확실할 때 모른다고 말해도 된다** 고 명시적으로 허락하면 거짓 정보가 크게 줄어들 수 있다고 설명합니다.

```text
확실하지 않거나 자료에 없는 내용이면 추측하지 말고
"확인할 수 있는 정보가 부족합니다"라고 답해 줘.
```

AI는 기본적으로 "도움이 되는 답"을 하려는 경향이 있어서, 이렇게 빠져나갈 길을 열어 주는 것이 효과적입니다.

## 기본 기법 2. 원문 인용부터 뽑게 하기

긴 문서를 다룰 때는 바로 요약시키지 말고, 먼저 **관련 문장을 그대로 인용** 하게 한 뒤 그 인용만으로 답하게 합니다. 공식 문서는 이 방법을 특히 긴 문서(2만 토큰 이상)에 권합니다.

```text
1단계: 첨부한 약관에서 환불과 관련된 문장을 원문 그대로 인용해 줘.
관련 문장이 없으면 "관련 문장 없음"이라고 써.
2단계: 위에서 뽑은 인용문만 근거로 환불 조건을 정리해 줘.
```

## 기본 기법 3. 주장마다 근거를 달게 하기

답을 쓴 뒤 **각 주장에 근거가 되는 인용을 찾게 하고, 근거가 없는 주장은 지우게** 하는 방법입니다.

```text
방금 쓴 요약의 각 문장마다 근거가 되는 원문 인용을 붙여 줘.
근거 인용을 찾을 수 없는 문장은 삭제하고 그 자리에 [ ]로 표시해 줘.
```

[ ] 표시가 많이 나온다면 AI가 문서 밖 내용을 섞었다는 신호입니다.

## 고급 기법 4~7

| 기법 | 방법 | 일반 사용자 활용 |
|---|---|---|
| 4. 사고 과정 확인 | AI가 추론 과정을 보여 주는 기능이 있으면, 답이 이상할 때 어느 단계에서 잘못됐는지 살펴봄 | "답을 내기 전에 단계별로 생각을 보여 줘" |
| 5. 여러 번 물어 비교 (Best-of-N) | 같은 질문을 여러 번 해서 답을 비교. 답이 서로 다르면 환각 가능성 | 새 대화에서 같은 질문을 2~3번 반복 |
| 6. 반복 검증 | AI의 답을 다시 넣고 검증·보완을 요청 | "방금 답에서 틀렸을 수 있는 부분을 찾아 줘" |
| 7. 외부 지식 제한 | 일반 지식 말고 **제공한 자료만** 쓰게 함 | "내가 준 자료 안에서만 답해 줘" |

5번은 특히 숫자 확인에 유용합니다. 같은 질문에 날짜나 금액이 매번 다르게 나온다면, 그 숫자는 믿지 말고 원래 출처에서 확인해야 합니다.

## 출처 버튼 확인하기 (Gemini 예시)

Gemini 앱 도움말에 따르면 컴퓨터에서 답변 아래나 본문 중간에 **Sources(출처)** 버튼이 보이면, 클릭했을 때 오른쪽 패널에 관련 링크가 열립니다. 링크는 공개 웹사이트, 업로드한 파일, 연결한 Google Workspace 문서·이메일 등이 될 수 있습니다. 출처 버튼이 없는 답변은 Gemini가 링크를 제공하지 않은 답변입니다.

출처 링크가 있더라도 **링크를 직접 열어 그 내용이 실제로 쓰여 있는지** 확인해야 합니다. 링크가 주장과 관계없는 페이지일 수도 있습니다.

## 답변 검증 체크리스트

중요한 결정에 AI 답을 쓰기 전에 아래 순서로 확인하세요. Anthropic 문서도 이 기법들이 환각을 "크게 줄이지만 없애지는 못한다"며, 중요한 정보는 반드시 검증하라고 안내합니다.

1. **숫자·날짜·고유명사에 표시** 합니다. 틀리기 쉬운 부분입니다.
2. **공식 출처에서 확인** 합니다. 법·세금은 정부 사이트, 제품 기능은 제조사 도움말, 요금은 공식 요금 페이지를 봅니다.
3. **출처 링크를 직접 열어** 인용된 내용이 실제로 있는지 봅니다.
4. **기준 날짜** 를 확인합니다. 요금·제도는 자주 바뀝니다.
5. 의료·법률·금융처럼 결과가 큰 문제는 **전문가에게 최종 확인** 합니다.

## 바로 쓰는 프롬프트 템플릿

```text
아래 질문에 답해 줘.
- 확실하지 않은 내용은 "확실하지 않음"이라고 표시해.
- 숫자, 날짜, 법·제도 이름에는 확인할 수 있는 공식 출처를 함께 적어.
- 출처를 모르면 지어내지 말고 "출처 확인 필요"라고 써.
- 마지막에 내가 직접 확인해야 할 항목을 목록으로 정리해.

질문: (여기에 질문)
```

프롬프트 기본 원칙은 [AI 프롬프트 잘 쓰는 법](/posts/ai-prompt-writing-guide/)에 더 정리했습니다.

## 안 될 때: 자주 겪는 문제와 해결법

| 증상 | 원인 | 해결 |
|---|---|---|
| "모른다고 말해"라고 해도 지어냄 | 지시가 한 번뿐이거나 질문이 모호함 | 지시를 질문 바로 앞에 다시 쓰고, 질문 범위를 좁힘 |
| 출처로 준 링크가 열리지 않음 | 존재하지 않는 주소를 만들었을 수 있음 | 그 정보는 사용하지 말고 직접 검색 |
| 요약에 문서에 없는 내용이 있음 | 일반 지식을 섞음 | "내가 준 자료 안에서만" + 인용 먼저 뽑기 |
| 같은 질문인데 숫자가 매번 다름 | 근거 없이 생성한 숫자 | 공식 출처에서 직접 확인 |
| 최신 정보가 틀림 | 학습 이후 바뀐 내용 | 웹 검색 기능을 켜고 출처를 확인하거나 공식 사이트 확인 |

## 정리

- 환각은 없앨 수 없지만 **"모르면 모른다고 말해", 인용 먼저, 주장마다 근거** 세 가지로 크게 줄일 수 있습니다.
- 같은 질문을 여러 번 해서 답이 달라지면 그 부분은 의심하세요.
- 숫자·날짜·법·요금은 반드시 **공식 출처에서 직접** 확인합니다.
