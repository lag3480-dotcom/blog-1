Gmail에는 구글의 AI인 **Gemini** 가 들어가 있어, 메일함 안에서 바로 긴 대화를 요약하거나 이메일 초안을 쓸 수 있습니다. 별도 챗봇 창에 메일 내용을 복사해 붙일 필요가 없다는 것이 장점입니다.

다만 모든 계정에서 쓸 수 있는 기능은 아니어서, 먼저 사용 조건을 확인해야 합니다. 이 글은 Gmail 고객센터 공식 도움말을 바탕으로 **컴퓨터(웹)** 기준으로 정리했습니다. 구글 AI 기능은 자주 바뀌므로 도움말 내용은 작성일 기준입니다. (작성일 2026년 10월 31일)

## 먼저 확인: 누가 쓸 수 있나

| 계정 | 조건 (공식 도움말 기준) |
|---|---|
| 회사·학교 계정 (Google Workspace) | 자격 요건을 충족하는 **Google Workspace 요금제** |
| 개인 계정 | 자격 요건을 충족하는 **Google AI 요금제** 구독 |
| 개인 계정 (무료) | 일부 기능을 신뢰할 수 있는 테스터 프로그램인 **Google Workspace Experiments** 로 제공 |

글쓰기 도우미 도움말에 따르면 Workspace 또는 Google AI 요금제 사용자는 지원되는 여러 언어로 쓸 수 있지만, Workspace Experiments를 통한 **개인 계정 이용은 미국에서만** 가능합니다. 내 계정에서 아래 아이콘이나 버튼이 보이지 않는다면 요금제와 지역 조건을 먼저 확인하세요.

## 기능 1. 사이드 패널: 요약하고 묻기

### 여는 방법

1. 컴퓨터에서 Gmail을 엽니다.
2. 오른쪽 위 **Gemini에게 물어보기** 아이콘을 클릭합니다.
3. 오른쪽에 열린 패널에 요청을 입력합니다.

### 할 수 있는 일

| 기능 | 예시 요청 |
|---|---|
| 긴 대화 요약 | "이 메일 대화를 글머리 기호 5개로 요약해 줘" |
| 메일에서 정보 찾기 | "다음 주 항공편 출발 시간 알려줘", "택배 도착 예정일 메일 찾아줘" |
| 초안 작성 | "프로젝트 진행 상황을 요약해서 팀장님께 보낼 이메일 초안 써 줘" |
| 어조 개선 | 기존 초안의 어조와 명확성 다듬기 |
| 일정 | 회의 시간 제안, 회의 만들기 요청 |
| 정리 | 메일에 기존 라벨 붙이기 |

공식 도움말은 긴 이메일 대화목록을 **간결한 글머리 기호로 요약** 하는 것을 대표 기능으로 소개합니다. 회의 참석자가 여러 번 주고받은 긴 메일을 읽기 전에 요약부터 보면 시간을 줄일 수 있습니다.

### 요청을 잘 쓰는 법

일반 챗봇과 마찬가지로 구체적일수록 결과가 좋습니다.

| 막연한 요청 | 구체적인 요청 |
|---|---|
| "요약해 줘" | "이 대화에서 결정된 사항과 내가 해야 할 일을 나눠서 요약해 줘" |
| "답장 써 줘" | "일정 변경을 수락하고, 자료는 금요일까지 보내겠다고 답장 초안 써 줘. 정중하게 3문장" |

상황별 이메일 프롬프트는 [AI로 업무 이메일 쓰기](/posts/ai-email-writing-prompts/)에서 더 볼 수 있습니다.

## 기능 2. 글쓰기 도우미로 초안 쓰기

### 순서

1. 컴퓨터에서 Gmail을 열고 **편지쓰기** 를 누릅니다. 기존 메일에 답장하거나 초안을 열어도 됩니다.
2. 프롬프트 입력 표시줄에 원하는 내용을 적습니다. 표시줄이 보이지 않으면 **글쓰기 도우미** 아이콘을 클릭합니다.
3. **만들기** 를 누르면 초안이 생성됩니다.
4. 초안을 확인하고 필요하면 다듬기 옵션을 쓴 뒤 본문에 넣습니다.

### 다듬기 옵션

| 옵션 | 쓰임 |
|---|---|
| **격식체로 변경** | 거래처·상사에게 보내는 메일 |
| **친근하게** | 동료, 가까운 사이 |
| **간략하게** | 길어진 초안을 줄일 때 |

### 프롬프트 예시

```text
다음 주 화요일 회의를 목요일 오후 2시로 바꿔 달라고 요청하는 메일.
이유는 고객사 방문 일정이 겹쳐서. 정중하게, 4문장 이내.
```

## 어떤 기능을 쓸까: 사이드 패널과 글쓰기 도우미 비교

| 하고 싶은 일 | 알맞은 기능 |
|---|---|
| 긴 대화를 읽기 전에 요점만 보기 | 사이드 패널 |
| 메일함에서 특정 정보 찾기 | 사이드 패널 |
| 지금 쓰는 메일의 초안 만들기 | 글쓰기 도우미 |
| 써 둔 초안의 말투만 바꾸기 | 글쓰기 도우미 다듬기 옵션 |

두 기능 모두 결과를 바로 보내지 않고 내가 확인한 뒤 쓰는 구조입니다. 보내기 전에 받는 사람, 날짜, 첨부 파일을 직접 확인하는 습관을 들이세요.

## 제한 사항: 공식 도움말 기준

| 제한 | 내용 |
|---|---|
| 스팸 처리 | 여러 이메일을 스팸으로 표시해 달라고 요청할 수 없음 |
| 대량 처리 | 조건에 맞는 대화목록이 **10,000개** 를 넘으면 요청을 처리하지 않음 |
| 라벨 | 계정에 **이미 있는 라벨만** 붙일 수 있음 |
| 캘린더 | **기본 캘린더** 의 일정 정보만 제공 |
| 정확성 | 부정확하거나 부적절한 정보를 제안할 수 있음 |
| 전문 조언 | 의료·법률·금융 등 전문가 조언으로 신뢰하면 안 됨 |

특히 요약에 나온 날짜, 금액, 이름은 원래 메일과 한 번 더 비교하세요. AI 요약이 틀릴 수 있다는 점은 구글도 명시하고 있습니다.

## 안 될 때: 자주 겪는 문제와 해결법

| 증상 | 원인 | 해결 |
|---|---|---|
| Gemini 아이콘이 없음 | 요금제·계정 조건 미충족 | Google AI 요금제 또는 Workspace 요금제 확인 |
| 개인 무료 계정인데 안 보임 | Workspace Experiments 개인 계정은 미국에서만 | 요금제 구독 여부 확인 |
| 회사 계정에서 안 보임 | 회사 요금제에 미포함 또는 관리자 설정 | 회사 IT 관리자에게 문의 |
| 프롬프트 표시줄이 안 보임 | 표시줄이 닫혀 있음 | 편지쓰기 창의 **글쓰기 도우미** 아이콘 클릭 |
| 라벨을 붙여 달라고 했는데 안 됨 | 없는 라벨 | 먼저 라벨을 만든 뒤 요청 ([지메일 필터와 라벨](/posts/gmail-filters-labels/) 참고) |
| 일정 정보가 빠짐 | 기본 캘린더 외 캘린더 | 기본 캘린더의 일정만 조회됨 |

## 정리

- Gmail의 Gemini는 **유료 Google AI·Workspace 요금제** 가 기본 조건이며, 무료 개인 계정은 테스터 프로그램으로 일부 지역에서만 제공됩니다.
- 오른쪽 위 **Gemini에게 물어보기** 로 요약·검색·초안을, 편지쓰기 창의 **글쓰기 도우미** 로 초안과 다듬기를 합니다.
- 요약과 초안의 날짜·금액·이름은 반드시 원래 메일과 비교해 확인합니다.
