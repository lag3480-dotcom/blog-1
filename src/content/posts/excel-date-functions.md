근속 연수, 계약 만료일, 마감까지 남은 날, 이번 달 영업일 수처럼 날짜 계산은 업무에서 자주 나오지만, 달력을 세다 보면 하루씩 틀리기 쉽습니다. 엑셀의 날짜 함수 몇 개만 알면 이런 계산을 정확하게 자동으로 할 수 있습니다.

이 글은 가장 많이 쓰는 **TODAY, DATEDIF, EDATE, NETWORKDAYS** 네 함수를 Microsoft 공식 도움말 기준으로 정리했습니다. 예제 결과는 모두 직접 검산했습니다.

## 먼저 알아 둘 것: 엑셀에서 날짜는 숫자입니다

엑셀은 날짜를 **일련번호** 로 저장합니다. 1900년 1월 1일이 1이고, 하루가 지날 때마다 1씩 커집니다. 그래서 날짜끼리 빼면 바로 일수가 나옵니다.

| 셀 | 값 |
|---|---|
| A2 (입사일) | 2021-03-15 |
| B2 (기준일) | 2026-10-24 |
| `=B2-A2` | **2049** (일) |

날짜 계산 결과가 `46319`처럼 이상한 숫자로 보인다면 계산이 틀린 것이 아니라 **셀 서식** 문제입니다. 결과가 날짜여야 하면 **홈** 탭의 표시 형식에서 **간단한 날짜** 를, 일수여야 하면 **일반** 이나 **숫자** 를 고르면 됩니다.

> 날짜는 `2026-10-24`처럼 하이픈으로 입력하거나 `=DATE(2026,10,24)` 함수로 넣는 것이 안전합니다. Microsoft 도움말도 날짜를 텍스트로 넣으면 문제가 생길 수 있다며 DATE 함수 사용을 권합니다.

## 네 함수 한눈에 보기

| 함수 | 하는 일 | 대표 용도 |
|---|---|---|
| `TODAY()` | 오늘 날짜 | D-day, 만 나이, 경과일 |
| `DATEDIF(시작일, 종료일, 단위)` | 두 날짜 사이의 년·월·일 수 | 근속 기간, 만 나이 |
| `EDATE(시작일, 개월수)` | 몇 개월 뒤(전) 같은 날짜 | 계약 만료일, 수습 종료일 |
| `NETWORKDAYS(시작일, 종료일, [휴일])` | 주말·휴일을 뺀 근무일 수 | 영업일, 처리 기간 |

## 1. TODAY: 오늘 날짜

```text
=TODAY()
```

괄호 안에 아무것도 넣지 않습니다. 파일을 열거나 시트가 다시 계산될 때마다 컴퓨터 시계 기준의 오늘 날짜로 바뀝니다.

### 예제: 연말까지 남은 날 (D-day)

```text
=DATE(2026,12,31)-TODAY()
```

오늘이 2026년 10월 24일이라면 결과는 **68** 입니다. 결과 셀은 **일반** 이나 **숫자** 서식이어야 날짜가 아닌 일수로 보입니다.

### 날짜가 바뀌면 안 될 때: Ctrl+;

작성일, 접수일처럼 **입력한 날 그대로 남아야 하는 날짜** 에 TODAY를 쓰면 다음 날 파일을 열 때 날짜가 바뀌어 버립니다. 이럴 때는 함수 대신 단축키를 씁니다.

| 단축키 (Windows) | 입력되는 값 |
|---|---|
| **Ctrl+;** | 오늘 날짜 (고정) |
| **Ctrl+Shift+;** | 현재 시각 (고정) |

## 2. DATEDIF: 근속 기간·만 나이

```text
=DATEDIF(시작일, 종료일, "단위")
```

| 단위 | 결과 | A2=2021-03-15, B2=2026-10-24 결과 |
|---|---|---|
| `"Y"` | 꽉 찬 년 수 | 5 |
| `"M"` | 꽉 찬 개월 수 | 67 |
| `"D"` | 일 수 | 2049 |
| `"YM"` | 년을 뺀 나머지 개월 수 | 7 |
| `"YD"` | 년을 무시한 일 수 | 223 |
| `"MD"` | 년·월을 무시한 일 수 | 사용 비권장 (아래 참고) |

검산해 보면, 2021-03-15부터 5년이 지나 2026-03-15가 되고, 거기서 7개월 뒤가 2026-10-15이므로 **5년 7개월** 입니다. 꽉 찬 개월 수는 5×12+7 = **67개월** 입니다.

### 예제: "5년 7개월" 형태로 근속 표시

```text
=DATEDIF(A2,B2,"Y")&"년 "&DATEDIF(A2,B2,"YM")&"개월"
```

결과는 `5년 7개월` 입니다. 기준일을 항상 오늘로 하려면 B2 대신 `TODAY()`를 넣습니다.

### 예제: 만 나이

```text
=DATEDIF(생년월일, TODAY(), "Y")
```

2026년 10월 24일 기준으로 생년월일이 1990-05-20이면 **36**, 1990-11-20이면 아직 생일이 지나지 않아 **35** 가 나옵니다. 연도만 빼는 `=YEAR(TODAY())-1990`은 생일이 지났는지 따지지 않으므로 만 나이가 필요할 때는 DATEDIF를 씁니다.

### DATEDIF 주의사항 3가지

- **오래된 호환용 함수입니다.** Microsoft는 DATEDIF가 예전 Lotus 1-2-3 통합 문서를 지원하려고 남아 있는 함수이며 일부 상황에서 결과가 틀릴 수 있다고 안내합니다. 중요한 계산은 한 번 검산하세요.
- **시작일이 종료일보다 늦으면 `#NUM!`** 이 납니다. 인수 순서를 확인하세요.
- **`"MD"`는 쓰지 않는 것이 좋습니다.** Microsoft 도움말은 MD가 음수, 0, 부정확한 결과를 낼 수 있다고 경고합니다.

## 3. EDATE: 몇 개월 뒤 날짜

```text
=EDATE(시작일, 개월수)
```

개월수가 양수면 미래, 음수면 과거 날짜를 돌려줍니다. 소수를 넣으면 소수점 아래는 버려집니다.

| 수식 (A2=2021-03-15) | 결과 | 용도 |
|---|---|---|
| `=EDATE(A2,3)` | 2021-06-15 | 수습 3개월 종료일 |
| `=EDATE(A2,12)` | 2022-03-15 | 1년 계약 기준일 |
| `=EDATE(A2,-1)` | 2021-02-15 | 한 달 전 |

EDATE는 결과를 **일련번호** 로 돌려주므로, 숫자로 보이면 셀 서식을 **간단한 날짜** 로 바꿉니다. 단순히 `A2+30`을 하면 달마다 일수가 달라 날짜가 어긋나므로, "몇 개월 뒤"는 EDATE로 계산하는 것이 정확합니다.

## 4. NETWORKDAYS: 영업일(근무일) 수

```text
=NETWORKDAYS(시작일, 종료일, [휴일])
```

주말과 휴일 목록을 빼고 **근무일 수** 를 셉니다. 시작일과 종료일도 근무일이면 개수에 들어갑니다.

### 예제: 2026년 12월 영업일

| 셀 | 값 |
|---|---|
| A2 | 2026-12-01 |
| B2 | 2026-12-31 |
| D2 | 2026-12-25 (성탄절, 금요일) |

| 수식 | 결과 |
|---|---|
| `=NETWORKDAYS(A2,B2)` | 23 |
| `=NETWORKDAYS(A2,B2,D2)` | 22 |

12월 1일~31일 중 토·일요일을 뺀 평일은 23일이고, 평일인 성탄절을 빼면 22일입니다. 휴일이 여러 개라면 D2:D10처럼 **범위** 로 넣으면 됩니다. 휴일 목록은 시트 한쪽에 따로 만들어 두고 매년 날짜만 바꾸는 방식이 관리하기 쉽습니다.

### 주말이 토·일이 아닐 때: NETWORKDAYS.INTL

일요일만 쉬는 사업장처럼 주말이 다르다면 NETWORKDAYS.INTL을 씁니다.

```text
=NETWORKDAYS.INTL(시작일, 종료일, [주말], [휴일])
```

| 주말 값 | 쉬는 날 |
|---|---|
| 1 (생략) | 토, 일 |
| 11 | 일요일만 |
| 17 | 토요일만 |
| `"0000011"` | 토, 일 (월요일부터 7자리, 1=쉬는 날) |

예를 들어 `=NETWORKDAYS.INTL(A2,B2,11,D2)`는 일요일과 성탄절을 뺀 근무일 수를 셉니다.

## 안 될 때: 자주 나는 문제와 해결법

| 증상 | 원인 | 해결 |
|---|---|---|
| 결과가 `46319` 같은 숫자 | 날짜 서식이 아님 | 셀 서식을 **간단한 날짜** 로 |
| 일수가 날짜(1905-08-10 등)로 보임 | 결과 셀이 날짜 서식 | 셀 서식을 **일반** 또는 **숫자** 로 |
| `#NUM!` (DATEDIF) | 시작일이 종료일보다 늦음 | 인수 순서 바꾸기 |
| `#VALUE!` | 날짜가 텍스트로 저장됨 | `=DATE(년,월,일)`로 다시 입력하거나 날짜로 변환 |
| `#NAME?` | 함수 이름 오타, 단위에 따옴표 누락 | `"Y"`처럼 단위를 큰따옴표로 감싸기 |
| TODAY가 어제 날짜에 멈춤 | 계산 옵션이 수동 | **파일** → **옵션** → **수식** 에서 계산 옵션을 **자동** 으로 |
| 작성일이 매일 바뀜 | TODAY 함수를 씀 | **Ctrl+;** 로 고정 날짜 입력 |

## 정리

- 날짜는 숫자라서 **빼기만 해도 일수** 가 나옵니다. 이상한 숫자가 보이면 서식부터 확인합니다.
- 근속·만 나이는 **DATEDIF** (`"Y"`, `"YM"`), "몇 개월 뒤"는 **EDATE**, 영업일은 **NETWORKDAYS** 입니다.
- 매일 바뀌는 날짜는 `TODAY()`, 고정해야 하는 날짜는 **Ctrl+;** 로 넣습니다.
