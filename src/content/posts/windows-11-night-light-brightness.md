밤에 모니터가 너무 밝아 눈이 부시거나, 노트북 밝기가 저절로 바뀌어 불편할 때가 있습니다. 윈도우 11에서는 **빠른 설정** 과 **디스플레이 설정** 에서 밝기를 바꾸고, **야간 모드** 로 저녁 시간대 화면의 청색광을 줄일 수 있습니다.

이 글은 Microsoft 공식 도움말 "Windows에서 디스플레이 밝기 및 색 변경"을 바탕으로 **윈도우 11** 기준으로 정리했습니다. (작성일 2026년 11월 4일)

## 한눈에 보기

| 하고 싶은 일 | 위치 |
|---|---|
| 밝기 빠르게 조절 | 작업 표시줄 오른쪽 **네트워크** 아이콘 → **밝기** 슬라이더 |
| 밝기 세부 설정 | **설정** → **시스템** → **디스플레이** → **밝기** |
| 야간 모드 켜기·끄기 | 작업 표시줄 네트워크 또는 스피커 아이콘 → **야간 모드** |
| 야간 모드 강도·예약 | **설정** → **시스템** → **디스플레이** → **야간 모드** |

## 1. 밝기 조절하기

### 빠른 설정에서

1. 작업 표시줄 오른쪽의 **네트워크** 아이콘을 선택합니다.
2. 열린 빠른 설정 창의 **밝기** 슬라이더를 움직입니다.

### 설정에서

1. **설정** → **시스템** → **디스플레이** 로 이동합니다.
2. **밝기** 에서 슬라이더를 조절합니다.

### 밝기 슬라이더가 안 보인다면

공식 도움말에 따르면 **외부 모니터를 연결한 데스크톱 PC** 에서는 밝기 슬라이더가 표시되지 않을 수 있습니다. 이때는 **모니터 본체의 버튼** 으로 밝기를 바꿔야 합니다.

## 2. 밝기가 저절로 바뀔 때: 자동 밝기 설정

밝기가 혼자 바뀐다면 아래 두 가지 기능 중 하나가 켜져 있을 수 있습니다. 모두 **설정** → **시스템** → **디스플레이** → **밝기** 에 있습니다.

| 기능 | 하는 일 | 바꾸는 법 |
|---|---|---|
| 조명이 변경될 때 자동으로 밝기 조정 | 주변 밝기에 따라 화면 밝기 조정 (센서가 있는 PC) | 옵션을 켜거나 끔 |
| **콘텐츠에 따라 밝기 변경** | 화면 내용에 따라 밝기 조정 (일부 PC) | 드롭다운에서 선택 |

**콘텐츠에 따라 밝기 변경** 드롭다운의 선택지는 다음과 같습니다.

| 선택 | 동작 |
|---|---|
| **끄기** | 조정하지 않음 (도움말은 배터리 수명이 짧아질 수 있다고 안내) |
| **항상** | 전원 연결 여부와 관계없이 동작 |
| **배터리 전용** | 배터리로 쓸 때만 동작 |

노트북을 배터리로 오래 써야 한다면 **배터리 전용** 이 무난하고, 밝기가 바뀌는 것이 거슬린다면 **끄기** 를 고르면 됩니다. HDR 디스플레이는 조명 변화에 반응하는 데 시간이 더 걸릴 수 있습니다.

## 3. 야간 모드 켜기

**야간 모드** 는 화면의 청색광을 줄여 따뜻한 색으로 바꿔 주는 기능입니다.

### 바로 켜기

작업 표시줄의 **네트워크** 또는 **스피커** 아이콘을 눌러 빠른 설정을 열고 **야간 모드** 를 선택합니다.

### 강도 조절

1. **설정** → **시스템** → **디스플레이** → **야간 모드** 로 이동합니다.
2. **강도** 슬라이더로 청색광을 얼마나 줄일지 정합니다.

### 시간 맞춰 자동으로 켜기 (예약)

1. 같은 화면에서 **야간 모드 예약** 을 켭니다.
2. 다음 중 하나를 고릅니다.

| 예약 방식 | 동작 |
|---|---|
| **일몰부터 일출까지** | 해 지는 시각부터 해 뜨는 시각까지 자동 적용 |
| **시간 설정** | 켜고 끌 시각을 직접 지정 (예: 21:00~07:00) |

> 사진 보정이나 디자인처럼 **정확한 색** 이 중요한 작업을 할 때는 야간 모드를 잠시 끄세요. 색이 따뜻하게 바뀌어 보이기 때문입니다.

## 4. 색이 이상할 때: 색상 프로필

**설정** → **시스템** → **디스플레이** → **색상 프로필** 에서 디스플레이별 색 프로필을 추가·제거하거나 기본 프로필을 정할 수 있습니다. **디스플레이 보정** 으로 새 프로필을 만들 수도 있습니다. 앱마다 색이 다르게 보인다면 **앱 색상 자동 관리** 를 켜 시스템 수준에서 색을 맞추는 방법도 있습니다.

## 안 될 때: 자주 겪는 문제와 해결법

| 증상 | 원인 | 해결 |
|---|---|---|
| 밝기 슬라이더가 없음 | 외부 모니터를 쓰는 데스크톱 | 모니터 본체 버튼으로 조절 |
| 밝기가 혼자 바뀜 | 자동 밝기·콘텐츠 기반 밝기 켜짐 | 디스플레이 → 밝기에서 끄기 |
| 야간 모드 토글이 회색으로 안 눌림 | 디스플레이 드라이버 문제 | 디스플레이 드라이버 업데이트 |
| 야간 모드가 아예 안 됨 | DisplayLink나 기본 디스플레이 드라이버 사용 | 도움말에 따르면 이 경우 야간 모드 사용 불가, 그래픽 드라이버 설치 확인 |
| 야간 모드가 정해진 시간에 안 켜짐 | 예약이 꺼져 있거나 시간 설정 오류 | 야간 모드 예약과 시각 확인 |
| 화면이 너무 누렇게 보임 | 강도가 높음 | 강도 슬라이더를 낮춤 |

## 자주 묻는 질문

**Q. 야간 모드와 다크 모드는 다른가요?**
다릅니다. 야간 모드는 화면 전체의 **색감** 을 따뜻하게 바꿔 청색광을 줄이는 기능이고, 다크 모드는 창과 메뉴의 **배경색** 을 어둡게 바꾸는 기능입니다. 둘은 따로 켜고 끌 수 있습니다.

**Q. 듀얼 모니터인데 한쪽만 밝기가 안 바뀌어요.**
노트북 화면은 윈도우 설정으로 바뀌지만, 외부 모니터는 공식 도움말 안내처럼 모니터 본체 버튼으로 조절해야 하는 경우가 있습니다.

**Q. 야간 모드를 켜면 스크린샷 색도 바뀌나요?**
야간 모드는 화면에 보이는 색을 바꾸는 기능입니다. 색이 중요한 작업 결과물은 야간 모드를 끈 상태에서 확인하는 것이 안전합니다.

## 정리

- 밝기는 **네트워크 아이콘 → 밝기 슬라이더** 또는 **설정 → 시스템 → 디스플레이** 에서 조절하며, 외부 모니터는 본체 버튼을 씁니다.
- 밝기가 저절로 바뀌면 **콘텐츠에 따라 밝기 변경** 과 자동 밝기 옵션을 확인합니다.
- **야간 모드** 는 강도를 조절하고 **일몰부터 일출까지** 또는 원하는 시간으로 예약할 수 있습니다.
