윈도우에서 파일을 두 번 클릭하거나 링크를 누르면 정해진 앱이 열립니다. 이것을 **기본 앱** 이라고 합니다. 새 브라우저나 PDF 프로그램을 설치했는데 여전히 예전 앱이 열린다면 기본 앱을 직접 바꿔야 합니다.

이 글은 Microsoft 공식 도움말 "Windows에서 기본 앱 변경"을 바탕으로 **윈도우 11** 기준으로 정리했습니다. (작성일 2026년 11월 2일)

## 기본 앱을 바꾸는 두 가지 방식

| 방식 | 하는 일 | 이럴 때 |
|---|---|---|
| **파일 형식·링크 형식별** | .pdf, .txt 같은 확장자나 HTTP 같은 링크 형식마다 앱 지정 | 특정 파일 하나의 형식만 바꿀 때 |
| **앱별** | 한 앱을 골라, 그 앱이 열 수 있는 형식들을 지정 | 새로 설치한 앱을 여러 형식의 기본으로 쓸 때 |

두 방식 모두 **시작** → **설정** → **앱** → **기본 앱** 에서 시작합니다.

## 방법 1. 파일 형식별로 바꾸기 (예: PDF)

1. **시작** → **설정** → **앱** → **기본 앱** 으로 이동합니다.
2. 검색 상자에 바꿀 파일 확장자를 입력합니다. 예: `.pdf`
3. 검색 결과에서 해당 형식을 선택합니다.
4. 표시되는 목록에서 원하는 앱을 고릅니다.

이후 그 확장자의 파일을 두 번 클릭하면 선택한 앱으로 열립니다.

### 자주 바꾸는 형식 예

| 확장자 | 파일 종류 | 흔히 바꾸는 이유 |
|---|---|---|
| `.pdf` | PDF 문서 | 브라우저 대신 PDF 전용 프로그램으로 열기 |
| `.txt` | 텍스트 | 메모장 대신 다른 편집기로 열기 |
| `.jpg`, `.png` | 사진 | 다른 사진 뷰어로 열기 |
| `.mp4` | 동영상 | 다른 동영상 플레이어로 열기 |

> 원하는 앱이 목록에 없다면 그 앱이 해당 형식을 지원하지 않거나 아직 설치되지 않은 것입니다. 먼저 앱을 설치하세요.

## 방법 2. 링크 형식별로 바꾸기 (브라우저)

웹 링크를 누를 때 열리는 브라우저도 같은 화면에서 바꿀 수 있습니다. 공식 도움말에 따르면 검색 상자에는 파일 확장자뿐 아니라 **링크 형식(프로토콜)** 도 입력할 수 있습니다.

1. **설정** → **앱** → **기본 앱** 에서 검색 상자에 `HTTP` 를 입력하고 결과를 선택합니다.
2. 원하는 브라우저를 고릅니다.
3. 같은 방법으로 `HTTPS` 도 바꿉니다.

대부분의 웹사이트 주소는 HTTPS로 시작하므로 HTTP만 바꾸면 여전히 다른 브라우저가 열릴 수 있습니다. 둘 다 확인하세요. 웹페이지 파일(`.htm`, `.html`)을 열 때의 브라우저도 따로 지정되어 있을 수 있습니다.

## 방법 3. 앱별로 한꺼번에 지정하기

새 프로그램을 여러 형식의 기본 앱으로 쓰고 싶다면 앱 단위로 설정하는 편이 빠릅니다.

1. **설정** → **앱** → **기본 앱** 의 앱 목록에서 원하는 앱을 선택합니다.
2. 그 앱이 열 수 있는 파일 형식과 링크 형식 목록이 나옵니다.
3. 바꿀 형식을 하나씩 선택하고 원하는 앱을 고릅니다.

### 예: Microsoft Edge를 기본 브라우저로

공식 도움말은 Edge를 예로 다음 순서를 안내합니다.

1. **앱** → **기본 앱** 에서 **응용 프로그램 기본값 설정** 아래의 **Microsoft Edge** 를 선택합니다.
2. Edge를 기본 브라우저로 만드는 항목 옆의 **기본값 설정** 단추를 누릅니다.

다른 브라우저를 쓴다면 같은 화면에서 그 브라우저를 선택하고, 방법 2처럼 HTTP·HTTPS 등 형식별 지정이 원하는 브라우저로 되어 있는지 확인하세요.

## 어떤 기본 앱을 바꿔 두면 좋을까

| 상황 | 바꿀 항목 |
|---|---|
| 메일·메신저 링크가 원치 않는 브라우저로 열림 | HTTP, HTTPS |
| 내려받은 PDF가 브라우저로 열림 | .pdf |
| 사진을 두 번 클릭하면 편집 앱이 열림 | .jpg, .png 등 사진 형식 |
| 업무용 문서가 다른 오피스 프로그램으로 열림 | .docx, .xlsx 등 문서 형식 |

## 안 될 때: 자주 겪는 문제와 해결법

| 증상 | 원인 | 해결 |
|---|---|---|
| 원하는 앱이 목록에 없음 | 앱이 그 형식을 지원하지 않거나 미설치 | 앱 설치 후 다시 시도 |
| 브라우저를 바꿨는데 일부 링크는 예전 브라우저로 열림 | HTTP만 바꾸고 HTTPS나 .html은 그대로 | HTTPS, .htm, .html도 확인 |
| PDF만 바꿨는데 다른 문서는 그대로 | 형식별로 따로 지정됨 | 바꿀 확장자를 하나씩 지정 |
| 앱 업데이트 후 기본 앱이 바뀐 것 같음 | 앱 설치·업데이트 과정에서 변경 요청이 있었을 수 있음 | 기본 앱 화면에서 다시 확인 |
| 회사 PC에서 바뀌지 않음 | 관리자 정책 | 회사 IT 담당자에게 문의 |

## 자주 묻는 질문

**Q. 기본 앱을 바꾸면 원래 앱이 삭제되나요?**
아닙니다. 파일이나 링크를 열 때 먼저 실행되는 앱만 바뀝니다. 원래 앱은 그대로 남아 있어 시작 메뉴에서 직접 실행할 수 있고, 같은 화면에서 언제든 다시 기본 앱으로 되돌릴 수 있습니다.

**Q. 확장자를 모르겠어요.**
파일 이름 끝의 점(.) 뒤 글자가 확장자입니다. 예를 들어 "계약서.pdf"는 `.pdf`, "사진.jpg"는 `.jpg` 입니다. 앱별 화면(방법 3)에서 앱을 선택하면 그 앱이 열 수 있는 형식 목록이 나오므로, 확장자를 몰라도 목록에서 고를 수 있습니다.

**Q. 형식마다 하나씩 바꾸기 번거로워요.**
새 앱을 여러 형식에 쓰려면 방법 3처럼 앱을 먼저 고르고, 그 앱이 지원하는 형식 목록에서 차례로 지정하는 편이 빠릅니다.

## 정리

- 기본 앱은 **설정 → 앱 → 기본 앱** 에서 바꿉니다.
- PDF처럼 파일 하나의 형식은 검색 상자에 **확장자** 를 입력해 바꾸고, 브라우저는 **HTTP와 HTTPS** 를 모두 확인합니다.
- 새 앱을 여러 형식에 쓰려면 **앱별** 화면에서 한꺼번에 지정합니다.
