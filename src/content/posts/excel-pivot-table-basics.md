"지점별 매출 합계를 내 주세요", "담당자별로 월별 실적을 정리해 주세요" 같은 요청을 받으면 SUMIFS 함수를 잔뜩 쓰거나 필터를 바꿔 가며 계산기를 두드리게 됩니다. **피벗 테이블** 을 쓰면 수식 하나 없이 마우스로 끌어다 놓는 것만으로 이런 요약표가 만들어집니다.

## 피벗 테이블이 하는 일

긴 목록을 **기준별로 묶어서 합계·개수·평균을 내는 표** 를 자동으로 만들어 줍니다.

**원본 데이터 (수백~수천 줄)**

| 날짜 | 지점 | 담당자 | 상품 | 금액 |
|---|---|---|---|---|
| 2026-10-02 | 서울 | 이서연 | 모니터 | 350,000 |
| 2026-10-05 | 부산 | 박지호 | 노트북 | 1,150,000 |
| … | … | … | … | … |

**피벗 테이블 결과**

| 지점 | 노트북 | 모니터 | 키보드 | 총합계 |
|---|---|---|---|---|
| 대구 | 1,180,000 | | | 1,180,000 |
| 부산 | 1,150,000 | 320,000 | | 1,470,000 |
| 서울 | 2,450,000 | 350,000 | 80,000 | 2,880,000 |
| 총합계 | 4,780,000 | 670,000 | 80,000 | 5,530,000 |

## 1단계. 데이터 준비 (가장 중요)

피벗 테이블이 이상하게 나오는 이유의 대부분은 원본 데이터 모양 때문입니다. Microsoft가 안내하는 조건은 이렇습니다.

- **머리글(제목 행)은 딱 한 줄**: 두 줄짜리 제목이나 병합된 셀이 있으면 안 됩니다.
- **한 열에는 한 종류의 데이터만**: '금액' 열에 숫자와 글자(예: "미정")가 섞이면 합계 대신 개수로 계산됩니다.
- **중간에 빈 행·빈 열 없이**: 빈 행이 있으면 그 아래 데이터가 빠질 수 있습니다.
- **표로 만들어 두기**: 데이터를 선택하고 **Ctrl + T** 로 '표'를 만들어 두면, 나중에 행을 추가해도 범위가 자동으로 늘어납니다.

> 보고서처럼 보기 좋게 꾸민 표(소계 행, 병합 셀이 있는 표)는 피벗 테이블의 원본으로 맞지 않습니다. **한 행에 한 건씩** 쌓인 목록 형태가 가장 좋습니다.

## 2단계. 피벗 테이블 만들기

1. 데이터 안의 아무 셀이나 클릭합니다.
2. **삽입** 탭 → **피벗 테이블** 을 누릅니다.
3. 범위가 맞는지 확인하고, 놓을 위치는 **새 워크시트** 를 고릅니다.
4. **확인** 을 누르면 새 시트에 빈 피벗 테이블과 오른쪽에 **필드 목록** 이 나타납니다.

## 3단계. 필드 배치하기

필드 목록 아래에는 네 개의 칸이 있습니다. 여기에 위쪽 필드(원본의 열 이름)를 끌어다 놓으면 표가 만들어집니다.

| 칸 | 역할 | 예 |
|---|---|---|
| **행** | 표의 왼쪽 세로 기준 | 지점 |
| **열** | 표의 위쪽 가로 기준 | 상품 |
| **값** | 계산할 숫자 | 금액 |
| **필터** | 전체 표를 걸러 볼 기준 | 담당자 |

위 결과 표는 **행 = 지점, 열 = 상품, 값 = 금액** 으로 놓은 것입니다.

필드 이름 옆의 체크 상자를 누르기만 해도 엑셀이 알아서 배치합니다. 글자 필드는 '행'으로, 숫자 필드는 '값'으로 들어갑니다. 원하는 칸이 아니면 끌어서 옮기면 됩니다.

**자주 쓰는 배치 예**

| 알고 싶은 것 | 행 | 열 | 값 |
|---|---|---|---|
| 지점별 매출 합계 | 지점 | | 금액 |
| 담당자별 월별 실적 | 담당자 | 날짜(월) | 금액 |
| 상품별 판매 건수 | 상품 | | 금액 (개수로 변경) |
| 지점·담당자별 매출 | 지점, 담당자 | | 금액 |

날짜 필드를 넣으면 엑셀이 연·분기·월로 자동 그룹화하는 경우가 많습니다. 그룹화가 안 되었다면 날짜 셀 하나를 오른쪽 클릭해서 **그룹** 을 고르고 '월'을 선택하세요.

## 4단계. 합계를 개수·평균·비율로 바꾸기

'값'에 넣은 숫자는 기본적으로 **합계** 로 계산됩니다. 바꾸려면:

1. 값 영역의 숫자를 오른쪽 클릭합니다.
2. **값 요약 기준** 에서 개수, 평균, 최댓값, 최솟값 중 하나를 고릅니다.

전체에서 차지하는 **비율(%)** 로 보고 싶다면 같은 메뉴의 **값 표시 형식** → **총합계 비율** 을 고릅니다. "서울 지점이 전체 매출의 몇 %인가"를 바로 볼 수 있습니다.

> '금액' 열에 글자가 섞여 있으면 엑셀이 기본값을 '개수'로 잡습니다. 합계가 안 나온다면 원본 데이터부터 확인하세요.

## 5단계. 원본이 바뀌면 새로 고침

피벗 테이블은 원본을 수정해도 **자동으로 바뀌지 않습니다.**

- 피벗 테이블 하나: 표 안을 오른쪽 클릭 → **새로 고침**
- 여러 개를 한 번에: 피벗 테이블 안을 클릭 → **피벗 테이블 분석** 탭 → **모두 새로 고침**

원본을 '표'(Ctrl + T)로 만들어 두었다면 새로 추가한 행도 새로 고침만 하면 반영됩니다. 표로 만들지 않았다면 **피벗 테이블 분석 → 데이터 원본 변경** 에서 범위를 다시 지정해야 합니다.

## 알아 두면 좋은 기능

- **더블클릭으로 상세 보기**: 피벗 테이블의 숫자를 더블클릭하면 그 숫자를 만든 원본 행들만 새 시트에 뽑아 줍니다. "서울 노트북 245만 원은 어떤 거래들이지?"를 바로 확인할 수 있습니다.
- **정렬**: 값 영역의 숫자를 오른쪽 클릭 → 정렬 → '숫자 내림차순'으로 매출이 큰 순서로 볼 수 있습니다.
- **슬라이서**: 피벗 테이블 분석 탭의 **슬라이서 삽입** 을 쓰면 버튼을 눌러 지점·담당자별로 걸러 보는 필터를 만들 수 있습니다. 보고용 화면에 좋습니다.

## 정리

| 단계 | 핵심 |
|---|---|
| 데이터 준비 | 머리글 한 줄, 병합·빈 행 없이, 표(Ctrl + T)로 |
| 만들기 | 삽입 → 피벗 테이블 → 새 워크시트 |
| 배치 | 행 = 묶을 기준, 열 = 가로 기준, 값 = 계산할 숫자 |
| 계산 바꾸기 | 값 요약 기준 / 값 표시 형식 |
| 갱신 | 원본 수정 후 반드시 새로 고침 |

처음에는 내 업무 데이터 하나로 **행에 기준 하나, 값에 숫자 하나** 만 넣어 보세요. 그것만으로도 함수 수십 개를 쓰던 집계가 한 번에 끝나는 경험을 하게 됩니다.
