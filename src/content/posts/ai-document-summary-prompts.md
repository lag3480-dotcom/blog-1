긴 보고서, 1시간짜리 회의록, 수십 쪽 PDF를 AI에게 맡기면 몇 초 만에 요약이 나옵니다. 그런데 막상 받아 보면 "그래서 뭘 하라는 거지?" 싶은 밋밋한 요약일 때가 많습니다.

요약의 품질을 가르는 것은 **"누가, 무엇을 위해 읽을 요약인가"** 를 알려주는지입니다. 이 글에서는 상황별로 바로 복사해 쓸 수 있는 프롬프트 8가지를 정리했습니다.

## 요약 프롬프트의 기본 공식

```text
[누가 읽나] + [무엇에 쓰나] + [분량·형식] + [지켜야 할 것] + [자료]
```

- "요약해 줘" → 평범한 줄거리 요약
- "팀장님께 오늘 회의 결과를 보고할 3줄 요약, 결정 사항 위주로" → 바로 쓸 수 있는 보고문

Google의 Gemini 프롬프트 가이드도 **응답 형식과 제약 조건(분량 등)을 분명히 정하고, 일반 지식이 아니라 내가 준 자료를 바탕으로 답하게 하라** 고 권합니다.

## 1. 상사에게 보고할 3줄 요약

```text
아래 문서를 팀장님께 보고하려고 해.
- 3문장 이내
- 첫 문장은 결론, 둘째는 근거, 셋째는 필요한 결정이나 다음 단계
- 문서에 없는 내용은 추가하지 마

[문서 붙여넣기]
```

## 2. 회의록에서 할 일 뽑기

```text
아래 회의록에서 '누가, 무엇을, 언제까지' 하기로 했는지 표로 정리해 줘.
열은 담당자 | 할 일 | 기한 | 비고.
담당자나 기한이 명확하지 않은 항목은 비워 두고 비고에 '확인 필요'라고 적어 줘.

[회의록 붙여넣기]
```

담당자나 기한을 AI가 **추측해서 채우지 않도록** 하는 마지막 줄이 중요합니다.

## 3. 결정 사항과 미결 사항 나누기

```text
아래 회의 내용을 세 부분으로 나눠 정리해 줘.
1) 확정된 결정
2) 논의했지만 결론이 안 난 쟁점 (각 쟁점마다 나온 의견 요약)
3) 다음 회의 전까지 확인할 것

[회의록 붙여넣기]
```

## 4. 긴 보고서를 목차별로 요약

수십 쪽짜리 문서는 한 번에 요약하면 앞부분은 자세하고 뒷부분은 대충 처리되기 쉽습니다. Google 가이드가 권하는 대로 **작업을 단계로 나누면** 결과가 안정적입니다.

```text
(1단계) 이 문서의 목차와 각 장의 핵심 주장을 한 줄씩 정리해 줘.
(2단계) 좋아, 이제 3장만 자세히 요약해 줘. 수치와 근거는 빠짐없이.
```

## 5. 계약서·약관의 핵심 조항 정리

```text
아래 계약서에서 나에게 불리하거나 주의해야 할 조항을 찾아 줘.
각 항목마다: 조항 번호 | 원문 인용 | 쉬운 말 설명 | 확인할 점.
특히 해지 조건, 위약금, 자동 갱신, 책임 범위를 꼭 확인해 줘.

[계약서 붙여넣기]
```

> 이 결과는 **검토를 돕는 참고 자료** 일 뿐 법률 자문이 아닙니다. 금액이 크거나 중요한 계약은 반드시 전문가에게 확인하세요.

원문을 **인용** 하게 하면 AI가 없는 내용을 지어냈는지 바로 대조할 수 있습니다.

## 6. 영어 자료를 한국어로 요약

```text
아래 영어 기사를 한국어로 요약해 줘.
- 핵심 내용 5개 글머리표
- 고유명사와 전문 용어는 처음 나올 때 영어를 괄호로 병기
- 마지막에 '우리 회사에 시사하는 점' 2줄 (우리 회사는 국내 중소 온라인 쇼핑몰)

[기사 붙여넣기]
```

## 7. 비교표로 요약

```text
아래 견적서 3개를 비교표로 정리해 줘.
행: 업체명 / 열: 총액, 포함 항목, 제외 항목, 납기, 유지보수 조건, 특이사항.
표 아래에 가격 대비 조건이 가장 좋은 곳과 그 이유를 3줄로.

[견적서 1]
[견적서 2]
[견적서 3]
```

## 8. 읽는 대상에 맞춰 쉽게 풀기

```text
아래 기술 문서를 IT를 잘 모르는 경영진이 읽는다고 생각하고 다시 써 줘.
- 전문 용어는 일상 비유로 설명
- 비용과 위험, 일정에 미치는 영향 위주로
- 1쪽 분량

[문서 붙여넣기]
```

## 요약을 받은 뒤 꼭 할 일

AI 요약은 빠르지만 완벽하지 않습니다. 특히 아래는 원문과 대조해 보세요.

- **숫자와 날짜**: 금액, 비율, 기한이 원문과 같은지
- **부정문**: "~하지 않기로 했다"가 "~하기로 했다"로 바뀌지 않았는지
- **누락**: 중요한 반대 의견이나 예외 조건이 빠지지 않았는지
- **추가**: 원문에 없는 내용이 들어가지 않았는지

마지막 확인을 AI에게 다시 맡기는 방법도 있습니다.

```text
방금 요약에서 원문에 근거가 없는 내용이 있는지 확인하고,
각 문장마다 근거가 되는 원문 부분을 인용해 줘.
```

## 회사 문서를 넣기 전에

- **개인정보**: 고객 이름, 연락처, 주민등록번호는 지우거나 가린 뒤 넣으세요.
- **기밀 자료**: 공개되지 않은 실적, 인사 정보, 계약 조건은 회사의 AI 사용 지침을 먼저 확인하세요. 업무용 요금제(기업 계정)는 입력 데이터를 학습에 쓰지 않는 등 조건이 다를 수 있습니다.
- **파일 첨부 한도**: 서비스와 요금제마다 한 번에 넣을 수 있는 분량이 다릅니다. 너무 길면 장별로 나눠 넣으세요.

## 정리

| 상황 | 프롬프트 핵심 |
|---|---|
| 보고 | 결론 → 근거 → 다음 단계, 3문장 |
| 회의록 | 담당자·할 일·기한 표, 추측 금지 |
| 긴 문서 | 목차 먼저, 장별로 나눠서 |
| 계약서 | 원문 인용 + 쉬운 설명 |
| 외국어 자료 | 요약 + 시사점 |
| 비교 | 기준을 열로 지정한 표 |

"요약해 줘" 한마디 대신 **누가 읽고 어디에 쓸지** 한 줄만 더해도 요약의 쓸모가 완전히 달라집니다.
