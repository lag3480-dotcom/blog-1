광고 메일, 카드 명세서, 회사 공지, 쇼핑 알림이 한 받은편지함에 섞이면 정작 중요한 메일을 놓치게 됩니다. 지메일의 **필터** 를 만들어 두면 조건에 맞는 메일이 들어올 때마다 라벨을 붙이거나, 받은편지함에서 빼거나, 다른 주소로 전달하는 일을 자동으로 처리합니다.

이 글은 Gmail 고객센터의 공식 도움말을 바탕으로 **컴퓨터(웹 브라우저)** 기준으로 정리했습니다. (작성일 2026년 10월 29일)

## 필터와 라벨, 먼저 이해하기

| 구분 | 역할 |
|---|---|
| **라벨** | 메일에 붙이는 이름표. 한 메일에 여러 개를 붙일 수 있음 |
| **필터** | "이런 조건의 메일이 오면 이렇게 처리하라"는 자동 규칙 |

공식 도움말은 **라벨은 폴더와 다르다** 고 설명합니다. 라벨은 나만 볼 수 있고, 메일을 주고받는 상대방에게는 표시되지 않습니다. 또 메일을 삭제하면 그 메일은 모든 라벨과 받은편지함에서 함께 삭제됩니다.

필터가 할 수 있는 일은 공식 도움말 기준으로 다음과 같습니다.

| 동작 | 쓰임 |
|---|---|
| 라벨 지정 | "카드명세서", "회사공지"처럼 분류 |
| 보관처리 | 받은편지함에서 빼고 라벨·전체보관함에만 남기기 |
| 삭제 | 받기 싫은 메일 자동 삭제 |
| 별표 | 중요한 사람의 메일 강조 |
| 자동 전달 | 특정 메일만 다른 주소로 보내기 |

## 1단계: 라벨 만들기

1. 지메일 왼쪽 메뉴의 라벨 영역에서 **라벨 만들기** 를 엽니다.
2. 라벨 이름을 입력합니다. 예: `카드명세서`
3. 다른 라벨 아래에 넣으려면 **상위 라벨 선택** 옆 체크박스를 선택하고 상위 라벨을 고릅니다. 예: `금융` 아래에 `카드명세서`
4. 저장합니다.

라벨은 필터를 만들면서 새로 만들 수도 있습니다.

## 2단계: 필터 만들기

### 방법 A. 검색 조건으로 만들기

1. 지메일 위쪽 검색창 오른쪽의 **검색옵션 표시** 아이콘을 클릭합니다.
2. 보낸사람, 받는사람, 제목, 포함하는 단어 등 조건을 입력합니다.
3. 먼저 **검색** 을 눌러 원하는 메일만 걸리는지 확인합니다.
4. 다시 검색옵션을 열고 아래쪽 **필터 만들기** 를 클릭합니다.
5. 라벨 지정, 보관처리 같은 동작을 고릅니다.
6. **필터 만들기** 를 클릭해 저장합니다.

### 방법 B. 받은 메일에서 바로 만들기

1. 분류하고 싶은 메일 옆 체크박스를 선택합니다.
2. 위쪽 **더보기** → **유사한 메일 필터링** 을 클릭합니다.
3. 보낸 사람 등 조건이 자동으로 채워집니다. 필요하면 고친 뒤 **필터 만들기** 를 클릭합니다.
4. 동작을 고르고 **필터 만들기** 로 저장합니다.

## 자주 쓰는 필터 조건 예시

검색옵션의 **포함하는 단어** 칸에는 검색 연산자를 쓸 수 있습니다. 아래 연산자는 모두 Gmail 고객센터의 검색 연산자 목록에 있는 형식입니다.

| 목적 | 조건 예시 | 추천 동작 |
|---|---|---|
| 카드 명세서 모으기 | 보낸사람: 카드사 메일 주소 | 라벨 `금융/카드명세서` |
| 쇼핑몰 광고 정리 | `category:프로모션` 또는 보낸사람 주소 | 보관처리 |
| 큰 첨부파일 메일 표시 | `larger:10M` | 라벨 `대용량` |
| PDF 청구서 | `filename:pdf` + 제목에 "청구서" | 라벨 `청구서`, 별표 |
| 상사 메일 놓치지 않기 | 보낸사람: 상사 주소 | 별표 |

> 처음부터 **삭제** 동작을 걸기보다는, 라벨 지정과 보관처리로 며칠 지켜본 뒤 원하는 메일만 걸리는지 확인하고 바꾸는 편이 안전합니다.

## 특정 메일만 다른 주소로 전달하기

자동 전달을 그냥 켜면 **스팸을 제외한 모든 새 메일** 이 전달됩니다. 특정 메일만 보내려면 필터를 씁니다.

1. **설정** → **모든 설정 보기** → **전달 및 POP/IMAP** 탭에서 **전달 주소 추가** 를 클릭하고 받을 주소를 입력합니다.
2. 그 주소로 확인 메일이 갑니다. 받는 쪽 계정에서 메일 속 **확인 링크** 를 클릭합니다.
3. 지메일 설정 페이지로 돌아와 브라우저를 새로고침합니다. 전체 메일을 전달하지 않을 것이므로 자동 전달은 켜지 않습니다.
4. 앞의 방법으로 필터를 만들고, 동작에서 **전달** 을 선택한 뒤 등록한 주소를 고릅니다.

여러 주소로 보내려면 주소마다 필터를 하나씩 만듭니다. 또 전달 필터는 **새로 들어오는 메일에만** 적용되고, 이미 받은 메일은 전달되지 않습니다.

> 직접 설정하지 않았는데 전달 안내가 보인다면, 공식 도움말은 다른 사람이 계정에 접근했을 수 있으니 **즉시 비밀번호를 바꾸고** 전달을 끄라고 안내합니다.

## 필터 수정·삭제·백업

1. **설정** → **모든 설정 보기** 를 클릭합니다.
2. **필터 및 차단된 주소** 탭을 엽니다.
3. 필터 옆 **수정** 또는 **삭제** 를 클릭합니다.
4. 수정했다면 **계속** → **필터 업데이트** 를 클릭합니다.

| 하고 싶은 일 | 방법 |
|---|---|
| 필터 백업 | 필터 체크박스 선택 → 아래쪽 **내보내기** (.xml 파일 저장) |
| 다른 계정에 옮기기 | 아래쪽 **필터 가져오기** → 파일 선택 → **파일 열기** → **필터 만들기** |

새 계정으로 옮기거나 회사 계정과 개인 계정에 같은 규칙을 쓸 때 내보내기·가져오기가 편합니다.

## 라벨 정리 팁

- 라벨이 많아지면 **설정** → **모든 설정 보기** → **라벨** 에서 왼쪽 목록에 보일지 숨길지 정할 수 있습니다.
- 라벨 색은 맞춤 색상을 **최대 100개** 까지 만들 수 있습니다.
- `금융/카드`, `금융/보험`처럼 상위 라벨로 묶으면 목록이 짧아집니다.

## 안 될 때: 자주 나는 문제와 해결법

| 증상 | 원인 | 해결 |
|---|---|---|
| 예전 메일에는 라벨이 안 붙음 | 필터는 기본적으로 새 메일 기준 | 필터를 만들 때 기존 메일에도 적용하는 옵션이 있는지 확인하거나, 검색 결과를 전체 선택해 직접 라벨 지정 |
| 엉뚱한 메일까지 걸림 | 조건이 너무 넓음 | 먼저 **검색** 으로 결과를 확인한 뒤 조건을 좁힘 |
| 답장 메일이 분류 안 됨 | 답장은 같은 조건에 맞을 때만 필터링 | 조건을 보낸사람 대신 제목 등으로 조정 |
| 전달이 안 됨 | 전달 주소 확인을 안 했거나, 이미 받은 메일임 | **확인 링크** 클릭 여부 확인. 전달은 새 메일만 |
| 필터를 지웠는데 라벨은 그대로 | 이미 붙은 라벨은 남음 | 필요하면 라벨을 직접 정리 |
| 메일이 받은편지함에서 사라짐 | 보관처리 동작이 걸린 필터 | 왼쪽 라벨이나 전체보관함에서 확인, 필터 수정 |

메일함 용량이 부족하다면 [구글 저장용량 정리하는 법](/posts/google-storage-cleanup/)에서 대용량 메일을 찾는 검색어를 함께 참고하세요.

## 정리

- 라벨은 이름표, 필터는 자동 규칙입니다. 라벨은 상대방에게 보이지 않습니다.
- **검색옵션 표시 → 필터 만들기**, 또는 메일 선택 후 **더보기 → 유사한 메일 필터링** 으로 만듭니다.
- 특정 메일만 전달하려면 **전달 주소 추가 → 확인 링크 → 필터에서 전달** 순서로 설정합니다.
