여러 사람이 함께 쓰는 엑셀 파일에서 "진행 상태" 칸을 열어 보면 `완료`, `완료됨`, `끝`, `O`가 뒤섞여 있는 경우가 많습니다. 이렇게 되면 필터나 COUNTIF로 집계할 때 값이 제각각이라 숫자가 맞지 않습니다.

**드롭다운 목록** 을 만들어 두면 정해진 항목 중에서 클릭으로 고르게 할 수 있어 이런 문제가 사라집니다. 엑셀에서는 **데이터 유효성 검사** 기능으로 만듭니다. 이 글은 Microsoft 공식 도움말을 바탕으로 Windows용 Excel 기준으로 정리했습니다.

## 먼저 정할 것: 항목을 어디에 둘까

드롭다운의 항목(원본)은 두 가지 방식으로 넣을 수 있습니다.

| 방식 | 예 | 좋은 경우 |
|---|---|---|
| 직접 입력 | `대기,진행,완료` | 항목이 3~5개로 적고 거의 안 바뀔 때 |
| 셀 범위·표 참조 | 다른 시트의 A2:A10 | 항목이 많거나 자주 추가될 때 |

항목이 앞으로 늘어날 수 있다면 **엑셀 표로 만든 목록을 참조** 하는 방식을 권합니다. Microsoft도 표를 쓰면 항목을 추가하거나 지울 때 드롭다운이 자동으로 바뀐다고 안내합니다.

## 방법 1. 항목을 직접 입력해서 만들기

가장 빠른 방법입니다.

1. 드롭다운을 넣을 셀(또는 범위)을 선택합니다.
2. **데이터** 탭에서 **데이터 유효성 검사** 를 클릭합니다.
3. **설정** 탭의 **제한 대상** 에서 **목록** 을 고릅니다. (도움말 번역본에서는 '허용'으로 표기되기도 합니다.)
4. **원본** 칸에 항목을 쉼표로 구분해 입력합니다. 예: `대기,진행,완료`
5. **드롭다운 표시** 가 체크되어 있는지 확인하고 **확인** 을 누릅니다.

Microsoft 도움말은 항목 사이를 **쉼표로 구분하고 공백은 넣지 않는 형식**(`Yes,No,Maybe`)을 예로 듭니다. 쉼표 뒤에 공백을 넣으면 항목 앞에 공백이 붙어 나중에 비교할 때 헷갈릴 수 있으니 붙여 쓰는 편이 안전합니다.

## 방법 2. 표로 만든 목록을 참조하기 (항목 자동 추가)

항목이 계속 늘어나는 부서명, 담당자, 거래처 목록에 알맞습니다.

1. 새 시트(예: `목록`)에 항목을 한 열로 입력합니다. 첫 행에는 `부서` 같은 제목을 씁니다.
2. 목록 안의 아무 셀을 클릭하고 **Ctrl+T** 를 눌러 **표** 로 만듭니다.
3. 드롭다운을 넣을 시트로 돌아가 셀을 선택합니다.
4. **데이터** → **데이터 유효성 검사** → **설정** 탭에서 **목록** 을 고릅니다.
5. **원본** 칸을 클릭한 뒤 `목록` 시트로 가서 **제목을 뺀 항목 범위** 만 드래그합니다.
6. **확인** 을 누릅니다.

이제 `목록` 시트의 표 맨 아래에 새 부서를 입력하면, 드롭다운에도 자동으로 나타납니다.

> 제목 행까지 선택하면 "부서"라는 글자도 선택 항목으로 나옵니다. 항목만 선택하세요.

## 입력 안내와 오류 메시지 설정 (선택)

같은 **데이터 유효성 검사** 창에는 탭이 더 있습니다.

### 설명 메시지 탭

셀을 클릭했을 때 작은 안내 상자를 띄웁니다. "목록에서 진행 상태를 고르세요"처럼 쓰면 처음 보는 사람도 헷갈리지 않습니다. Microsoft 도움말 기준으로 메시지는 **최대 225자** 까지 넣을 수 있습니다.

### 오류 메시지 탭

목록에 없는 값을 직접 입력했을 때의 반응을 정합니다. **스타일** 에 따라 동작이 다릅니다.

| 스타일 | 목록에 없는 값 입력 시 |
|---|---|
| **중지** | 입력을 막습니다 |
| **경고** | 경고를 보여 주지만 입력은 허용합니다 |
| **정보** | 안내만 하고 입력을 허용합니다 |

값을 반드시 통일해야 한다면 **중지** 를 고르세요. 제목과 메시지를 비워 두면 엑셀 기본 문구가 표시됩니다.

## 항목 추가·수정하기

| 원본 방식 | 항목 바꾸는 법 |
|---|---|
| 표 참조 | 표 맨 아래에 입력하면 자동 추가. 중간 항목은 셀을 오른쪽 클릭 → **삭제** → 셀을 위로 밀기 |
| 일반 범위 참조 | 목록을 고친 뒤, 드롭다운 셀에서 **데이터 유효성 검사** 를 열고 **원본** 범위를 다시 선택 |
| 직접 입력 | **데이터 유효성 검사** 를 열고 **원본** 칸의 글자를 직접 수정 |

드롭다운이 들어간 셀이 여러 개라면, 수정할 때 **"설정이 같은 모든 셀에 변경 내용 적용"** 에 체크하면 한 번에 바뀝니다.

## 드롭다운 없애기

1. 드롭다운이 있는 셀을 선택합니다. 여러 셀은 **Ctrl** 을 누른 채 클릭합니다.
2. **데이터** → **데이터 유효성 검사** 를 엽니다.
3. **설정** 탭에서 **모두 지우기** 를 누르고 **확인** 합니다.

어느 셀에 드롭다운이 있는지 모를 때는 **Ctrl+G** → **옵션** 을 눌러 **이동 옵션** 창에서 **데이터 유효성 검사** 를 고르면 해당 셀이 모두 선택됩니다.

## 안 될 때: 자주 나는 문제와 해결법

| 증상 | 원인 | 해결 |
|---|---|---|
| **데이터 유효성 검사** 메뉴가 회색으로 비활성 | 시트가 보호되었거나 공유 중 | 시트 보호 해제 또는 공유 중지 후 다시 시도 |
| 셀을 눌러도 화살표가 안 보임 | **드롭다운 표시** 체크 해제 | 유효성 검사 창에서 다시 체크 |
| 목록에 제목이 섞여 나옴 | 원본에 제목 행까지 포함 | 원본 범위를 항목만 다시 선택 |
| 새 항목을 추가했는데 안 나옴 | 표가 아닌 일반 범위를 참조 | 목록을 **Ctrl+T** 로 표로 만들거나 원본 범위를 다시 지정 |
| 목록에 없는 값이 입력됨 | 오류 스타일이 경고·정보이거나 오류 메시지 꺼짐 | **오류 메시지** 탭에서 스타일을 **중지** 로 |
| 항목 글자가 잘려 보임 | 열 너비가 좁음 | 열 너비를 넓히기 |

## 활용 팁

- 목록 시트는 **숨기고 시트 보호** 를 걸어 두면 다른 사람이 항목을 실수로 바꾸지 않습니다. (Microsoft 도움말 권장 사항)
- 드롭다운으로 값이 통일되면 COUNTIFS로 상태별 건수를 세거나 피벗 테이블로 집계하기가 훨씬 쉬워집니다.
- 항목을 가나다순으로 정렬해 두면 고르기 편합니다.

## 정리

- 드롭다운은 **데이터 → 데이터 유효성 검사 → 목록** 으로 만듭니다.
- 항목이 적으면 원본에 `대기,진행,완료`처럼 직접 입력하고, 늘어날 수 있으면 **표(Ctrl+T)** 를 참조합니다.
- 다른 값 입력을 막으려면 **오류 메시지** 탭의 스타일을 **중지** 로 둡니다.
- 지울 때는 같은 창의 **모두 지우기** 를 누릅니다.
