발표 화면은 16:9인데 받은 파일이 4:3이라 양옆이 비어 보이거나, 발표 자료를 A4로 인쇄해야 하는데 여백이 이상하게 남는 경우가 있습니다. 이럴 때는 **슬라이드 크기** 를 바꾸면 됩니다.

다만 내용이 이미 들어간 상태에서 크기를 바꾸면 도형과 글자가 늘어나거나 줄어들 수 있으므로, 순서와 옵션을 알고 바꾸는 것이 좋습니다. 이 글은 Microsoft 공식 도움말을 바탕으로 Windows용 PowerPoint 기준으로 정리했습니다.

## 먼저 알아 둘 것 3가지

| 규칙 | 내용 |
|---|---|
| 프레젠테이션 전체에 적용 | 슬라이드 하나만 크기를 다르게 할 수 없습니다 |
| 방향도 전체에 하나 | 가로·세로 방향도 모든 슬라이드가 같아야 합니다 |
| 현재 파일에만 적용 | 크기를 바꿔도 다른 파일이나 새 파일에는 영향이 없습니다 |

새 프레젠테이션의 기본 크기는 **와이드스크린(16:9)** 입니다.

## 16:9 ↔ 4:3 바꾸기

1. **디자인** 탭을 클릭합니다.
2. 리본 맨 오른쪽 **사용자 지정** 그룹에서 **슬라이드 크기** 를 클릭합니다.
3. **표준(4:3)** 또는 **와이드스크린(16:9)** 을 고릅니다.
4. 내용 크기를 자동으로 맞출 수 없으면 선택 창이 뜹니다. 아래 표를 보고 고릅니다.

| 옵션 | 동작 | 이럴 때 |
|---|---|---|
| **최대화** | 내용을 크게 유지 (슬라이드 밖으로 넘칠 수 있음) | 더 큰 크기로 바꾸고, 넘친 부분은 직접 정리할 때 |
| **맞춤 확인** | 내용을 줄여서 모두 슬라이드 안에 들어오게 함 | 더 작은 크기로 바꾸면서 잘리는 내용이 없어야 할 때 |

> 어느 쪽을 골라도 일부 슬라이드는 손볼 곳이 생길 수 있습니다. 바꾸기 전에 파일을 복사해 두고 작업하면 원래대로 돌아가기 쉽습니다.

## A4 등 정해진 용지 크기로 바꾸기

인쇄용 자료라면 용지 크기에 맞춰 두는 것이 좋습니다.

1. **디자인** → **슬라이드 크기** → **사용자 지정 슬라이드 크기** 를 클릭합니다.
2. **슬라이드 크기** 목록에서 원하는 크기를 고릅니다. (화면 슬라이드 쇼 4:3·16:9·16:10, 레터 용지, A3, A4, B4, B5, 35mm 슬라이드, 오버헤드, 배너, 와이드스크린 등)
3. **확인** 을 누르고, 물어보면 **최대화** 또는 **맞춤 확인** 을 고릅니다.

### 주요 크기 비교

Microsoft 도움말에 나온 인치 값을 센티미터로 환산했습니다(1인치 = 2.54cm, 소수 둘째 자리 반올림).

| 크기 | 인치 | 센티미터 |
|---|---|---|
| 와이드스크린 | 13.333 × 7.5 | 33.87 × 19.05 |
| 화면 슬라이드 쇼 (16:9) | 10 × 5.625 | 25.4 × 14.29 |
| A4 | 10.833 × 7.5 | 27.52 × 19.05 |
| A3 | 14 × 10.5 | 35.56 × 26.67 |

와이드스크린과 화면 슬라이드 쇼(16:9)는 **비율은 같고 크기만 다릅니다**(둘 다 약 1.78:1).

Microsoft 도움말은 와이드스크린 크기가 레터 용지(8.5 × 11인치)에 줄이지 않고는 들어가지 않는다고 안내합니다. 인쇄가 주목적이라면 처음부터 A4 같은 용지 크기로 시작하는 편이 깔끔합니다.

## 원하는 크기를 직접 입력하기 (세로 슬라이드 포함)

SNS 카드뉴스나 세로형 포스터처럼 특별한 크기가 필요할 때 씁니다.

1. **디자인** → **슬라이드 크기** → **사용자 지정 슬라이드 크기** 를 클릭합니다.
2. **방향** 에서 **세로** 또는 **가로** 를 고릅니다.
3. **너비** 와 **높이** 에 숫자, 공백, 단위를 입력합니다. 단위는 `in`(인치), `cm`, `px`(픽셀)을 쓸 수 있습니다. 예: `20 cm`
4. **확인** 을 누르고 크기 조정 옵션을 고릅니다.

| 제한 | 값 |
|---|---|
| 최소 | 1인치 (2.54cm, 120px) |
| 최대 | 56인치 (142.24cm, 720px) |

이 범위를 벗어나는 크기는 입력할 수 없습니다. 웹용 PowerPoint는 인치 단위만 받으며 1~56인치 범위입니다.

## 새 파일의 기본 크기를 바꾸기

매번 A4로 바꾸는 것이 번거롭다면 기본 테마를 만들어 둡니다.

1. 새 빈 프레젠테이션을 만듭니다.
2. 위 방법으로 원하는 슬라이드 크기를 설정합니다.
3. **디자인** 탭의 테마 목록 오른쪽 **자세히** 화살표를 눌러 **현재 테마 저장** 을 클릭하고 이름을 정해 저장합니다.
4. 다시 테마 목록을 열어 **사용자 지정** 아래 방금 저장한 테마를 오른쪽 클릭 → **기본 테마로 설정** 을 고릅니다.
5. PowerPoint를 닫습니다. 저장할지 물으면 저장하지 않아도 됩니다.

이후 새 프레젠테이션은 지정한 크기로 시작합니다. 테마 미리 보기가 와이드스크린처럼 보여도 실제 새 파일은 설정한 크기로 만들어진다고 Microsoft는 안내합니다.

## 안 될 때: 자주 나는 문제와 해결법

| 증상 | 원인 | 해결 |
|---|---|---|
| 슬라이드 한 장만 크기를 바꾸고 싶음 | 지원하지 않음 (전체 공통) | 그 슬라이드만 별도 파일로 만들어 크기 변경 |
| 크기를 바꿨더니 글자·도형이 슬라이드 밖으로 나감 | **최대화** 선택 | 실행 취소(**Ctrl+Z**) 후 **맞춤 확인** 으로 다시 |
| 크기를 바꿨더니 내용이 너무 작아짐 | **맞춤 확인** 선택 | 실행 취소 후 **최대화** 로 다시 하고 넘친 부분 정리 |
| 크기 입력이 안 받아짐 | 최소 1인치·최대 56인치 범위를 벗어남 | 범위 안의 값으로 입력 |
| 새 파일이 계속 16:9로 열림 | 기본 테마를 바꾸지 않음 | 위 **기본 크기 바꾸기** 절차 진행 |
| Mac에서 메뉴가 다름 | Mac은 **페이지 설정** 으로 표시 | 크기 조정 질문도 Scale / Don't Scale(크기 조정 여부)로 표시 |

## 정리

- 크기는 **디자인 → 슬라이드 크기** 에서 바꾸며, 파일 전체에 적용됩니다.
- 큰 쪽으로 바꿀 때 **최대화**, 작은 쪽으로 바꿀 때 **맞춤 확인** 을 기본으로 생각하면 됩니다.
- 인쇄용은 **사용자 지정 슬라이드 크기** 에서 A4를, 세로 자료는 **방향** 을 세로로 고릅니다.
- 매번 같은 크기를 쓴다면 테마로 저장해 **기본 테마로 설정** 해 두세요.
