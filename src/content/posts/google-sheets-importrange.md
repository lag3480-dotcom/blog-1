지점별 매출 파일, 팀별 일정 파일처럼 여러 구글 시트에 흩어진 데이터를 한 파일에서 모아 보고 싶을 때 쓰는 함수가 **IMPORTRANGE** 입니다. 원본 파일의 범위를 그대로 불러오고, 원본이 바뀌면 불러온 쪽도 따라 바뀝니다.

이 글은 Google Docs 편집기 고객센터의 IMPORTRANGE 공식 도움말을 바탕으로 정리했습니다. (작성일 2026년 10월 28일)

## 기본 문법

```text
=IMPORTRANGE(스프레드시트_URL, 범위_문자열)
```

| 인수 | 설명 | 예 |
|---|---|---|
| **스프레드시트_URL** | 불러올 원본 파일의 주소. 큰따옴표로 감싸거나, 주소가 든 셀을 참조 | `"https://docs.google.com/spreadsheets/d/abcd123abcd123"` |
| **범위_문자열** | `"시트이름!범위"` 형식의 문자열 | `"Sheet1!A2:B6"` 또는 `"A2:B6"` |

시트 이름은 생략할 수 있습니다. 생략하면 원본 파일의 **첫 번째 시트** 에서 해당 범위를 가져옵니다. 원본 시트 순서가 바뀌면 다른 시트를 읽게 되므로, 실무에서는 시트 이름을 적는 편이 안전합니다.

## 단계별: 처음 연결하기

예를 들어 `서울지점` 파일의 `매출` 시트 A1:D100을 `전체 집계` 파일로 가져오겠습니다.

1. 원본 파일(`서울지점`)을 열고 주소창의 URL을 복사합니다.
2. 대상 파일(`전체 집계`)에서 데이터를 넣을 빈 셀(예: A1)을 클릭합니다.
3. 아래처럼 입력합니다.

```text
=IMPORTRANGE("https://docs.google.com/spreadsheets/d/원본파일주소", "매출!A1:D100")
```

4. 처음에는 셀에 **#REF!** 오류가 보입니다. 셀에 마우스를 올리면 "이 시트를 연결해야 합니다"라는 안내와 함께 **액세스 허용** 버튼이 나옵니다.
5. **액세스 허용** 을 클릭하면 데이터가 채워집니다.

결과는 A1:D100 크기만큼 오른쪽·아래로 펼쳐지므로, 그만큼의 빈 공간이 있는 곳에 입력하세요.

### URL을 셀에 넣어 두는 방법

여러 범위를 같은 파일에서 불러온다면 URL을 한 셀(예: `설정!B1`)에 넣고 참조하면 수식이 짧아집니다.

```text
=IMPORTRANGE(설정!B1, "매출!A1:D100")
```

도움말의 예시 `IMPORTRANGE(A2,"B2")` 도 이런 방식입니다. 원본 파일이 바뀌어도 URL 셀만 고치면 됩니다.

## 액세스 권한, 이렇게 동작합니다

IMPORTRANGE는 원본 파일에 **명시적으로 권한을 부여해야** 동작합니다. 공식 도움말이 설명하는 규칙은 다음과 같습니다.

| 상황 | 동작 |
|---|---|
| 내가 원본 파일 소유자 | **#REF!** 표시 후 **액세스 허용** 클릭으로 연결 |
| 내가 원본 파일 소유자가 아님 | 원본 파일 접근 권한을 요청하고, 소유자가 허용할 때까지 기다림 |
| 한 번 허용한 뒤 | 허용한 사용자가 원본 파일에서 제거되기 전까지 유지 |
| 대상 파일의 다른 편집자 | 허용 후에는 **원본 파일의 어느 부분이든** IMPORTRANGE로 가져올 수 있음 |

마지막 줄이 중요합니다. 연결을 한 번 허용하면, **대상 파일의 편집자 누구나** 원본 파일의 다른 시트와 범위까지 불러올 수 있습니다. 원본에 급여·연락처처럼 민감한 시트가 있다면 대상 파일의 편집자를 확인한 뒤 허용하세요.

또 대상 시트에 부여된 액세스 권한은 원본 파일의 **사용자 공유 한도 600명** 에 포함됩니다.

## 데이터는 언제 새로 고쳐지나

IMPORTRANGE는 실시간으로 바로 바뀌지 않고, 정해진 조건에서 새로 고쳐집니다.

| 경우 | 새로고침 |
|---|---|
| 원본 파일이 바뀜 | 열려 있는 대상 파일이 새로고침되며, 바뀌기까지 지연이 있을 수 있음 |
| 대상 파일이 열려 있는 동안 | 변경이 없어도 **매시간** 업데이트 확인 |
| 문서를 처음 열 때, 또는 5분 이내에 열었을 때 | 새로고침 |
| 셀을 지우거나 같은 수식으로 다시 입력 | 새로고침 |
| 브라우저에서 문서를 새로고침 | 새로고침되지 **않음** |

원본을 고쳤는데 값이 그대로라면, 잠시 기다리거나 IMPORTRANGE 셀을 지운 뒤 같은 수식을 다시 입력하면 됩니다.

## 활용 예: 여러 지점 파일을 한 곳에

세 지점 파일의 같은 범위를 아래로 이어 붙이려면 각 결과를 다른 위치에 둡니다.

| 셀 | 수식 |
|---|---|
| A2 | `=IMPORTRANGE(설정!B1, "매출!A2:D100")` (서울) |
| A102 | `=IMPORTRANGE(설정!B2, "매출!A2:D100")` (부산) |
| A202 | `=IMPORTRANGE(설정!B3, "매출!A2:D100")` (대구) |

범위가 A2:D100으로 99행이므로 각 결과가 99행씩 차지합니다. A2에서 시작한 결과는 A100에서 끝나므로 다음 수식은 A101 이후에 두어야 겹치지 않습니다. 위 표처럼 100행 간격으로 두면 한 줄씩 여유가 생깁니다.

합계만 필요하다면 원본에서 미리 계산해 두고 **요약 셀만** 불러오는 편이 빠릅니다. 공식 도움말도 원본에서 데이터를 미리 집계해 필요한 부분만 가져오라고 권합니다.

## 안 될 때: 자주 나는 문제와 해결법

| 증상 | 원인 | 해결 |
|---|---|---|
| **#REF!** + "이 시트를 연결해야 합니다" | 아직 연결을 허용하지 않음 | 셀에 마우스를 올려 **액세스 허용** |
| **#REF!**, 허용 버튼이 없음 | 원본 파일에 내 접근 권한이 없음 | 원본 소유자에게 공유 요청 |
| 새 IMPORTRANGE가 동작하지 않음 | 원본에서 **다운로드, 인쇄, 복사 옵션 사용 중지** 가 켜져 있음 | 원본 소유자에게 설정 확인 요청 |
| 셀에 "로드 중…"이 오래 표시 | 요청이 많거나 범위가 큼 | 불러오는 범위와 IMPORTRANGE 개수 줄이기 |
| NOW·RAND 관련 오류 | 원본 범위에 NOW, RAND, RANDBETWEEN이 있는 셀이 포함 | 원본에서 해당 값을 **값만 붙여넣기** 로 고정한 셀을 참조 |
| 결과가 계속 비어 있음 | 두 파일이 서로를 IMPORTRANGE로 참조(순환) | 한쪽 방향으로만 불러오도록 구조 변경 |
| 엉뚱한 시트 데이터가 나옴 | 시트 이름을 생략해 첫 번째 시트를 읽음 | `"시트이름!범위"` 로 지정 |
| 큰 범위가 안 불러와짐 | 요청당 수신 용량 **10MB** 제한 | 범위를 나누거나 필요한 열만 지정 |

참고로 TODAY 함수는 NOW·RAND와 달리 예외로 취급됩니다. 공식 도움말에 따르면 TODAY는 하루에 두 번 이상 업데이트되지 않기 때문입니다.

### 속도가 느릴 때 점검할 것

IMPORTRANGE는 IMPORTXML, GOOGLEFINANCE와 같은 **외부 데이터 함수** 라서, 원본 범위 전체를 내려받아야 하고 네트워크 속도의 영향을 받습니다. 공식 도움말이 권하는 방법을 정리하면 다음과 같습니다.

1. 파일 A → B → C처럼 여러 단계로 이어지는 **IMPORTRANGE 연결 고리를 줄입니다.**
2. 같은 원본을 여러 번 불러오지 말고 한 번 불러온 결과를 시트 안에서 참조합니다.
3. 원본에서 집계를 끝내고 결과만 가져옵니다.

## 정리

- 문법은 `=IMPORTRANGE("원본 URL", "시트이름!범위")` 이고, 처음 한 번 **액세스 허용** 이 필요합니다.
- 허용 후에는 대상 파일 편집자 누구나 원본 파일의 다른 범위도 가져올 수 있으니 민감한 원본은 주의합니다.
- 값이 안 바뀌면 새로고침 조건을 확인하고, 느리면 범위와 연결 단계를 줄입니다.

같은 파일 안에서 목록을 관리하는 방법은 [구글 스프레드시트 드롭다운 만들기](/posts/google-sheets-dropdown/)에 정리했습니다.
