모니터를 하나 더 연결하면 한쪽에는 자료를, 다른 쪽에는 작업 문서를 띄워 놓을 수 있어 업무 효율이 크게 올라갑니다. 그런데 막상 연결하면 두 화면에 같은 내용이 나오거나, 마우스가 엉뚱한 방향으로 넘어가는 경우가 많습니다.

이 글은 Microsoft 공식 도움말 "Windows에서 여러 모니터를 사용하는 방법"을 바탕으로 **윈도우 11** 기준으로 정리했습니다. (작성일 2026년 11월 6일)

## 한눈에 보기

| 하고 싶은 일 | 방법 |
|---|---|
| 화면 확장·복제 바꾸기 | **Windows 키 + P** |
| 몇 번 모니터인지 확인 | **설정** → **시스템** → **디스플레이** → **식별** |
| 모니터 위치(좌우·위아래) 맞추기 | **디스플레이** 화면에서 모니터 그림을 끌어 옮긴 뒤 **적용** |
| 연결했는데 안 잡힐 때 | **디스플레이** → **여러 디스플레이** → **검색** |
| 무선 모니터·TV 연결 | **디스플레이** → **여러 디스플레이** → **연결** |

## 1. 연결하기 전에 확인할 것

- 모니터 케이블(HDMI, DisplayPort, USB-C 등)이 PC와 모니터 양쪽에 단단히 꽂혀 있는지 확인합니다.
- 모니터 전원이 켜져 있고, 모니터의 **입력 소스** 가 연결한 포트와 맞는지 확인합니다.
- 공식 도움말은 먼저 **설정** → **Windows 업데이트** → **업데이트 확인** 으로 최신 업데이트를 설치하라고 안내합니다.

## 2. 확장·복제 바꾸기: Windows 키 + P

**Windows 키 + P** 를 누르면 화면 오른쪽에 표시 방식 목록이 나옵니다.

| 선택 | 동작 | 이럴 때 |
|---|---|---|
| **PC 화면만** | 한 화면(주로 노트북 화면)에만 표시 | 외부 모니터를 잠시 끄고 싶을 때 |
| **복제** | 모든 화면에 같은 내용 표시 | 회의실 TV·프로젝터로 발표할 때 |
| **확장** | 바탕 화면을 여러 화면으로 넓혀 씀. 창을 화면 사이로 옮길 수 있음 | **일반적인 듀얼 모니터 작업** |
| **두 번째 화면만** | 두 번째 화면에만 표시 | 노트북을 덮고 큰 모니터만 쓸 때 |

두 화면에 같은 내용이 나온다면 **복제** 로 되어 있는 것입니다. **확장** 을 고르면 모니터 두 대를 하나의 넓은 바탕 화면처럼 쓸 수 있습니다.

## 3. 모니터 번호 확인하고 위치 맞추기

확장으로 쓰는데 마우스를 오른쪽으로 옮겼더니 왼쪽 모니터로 넘어간다면, 윈도우가 알고 있는 모니터 배치가 실제와 다른 것입니다.

### 모니터 식별

1. **설정** → **시스템** → **디스플레이** 로 이동합니다.
2. **식별** 을 선택하면 각 모니터 화면에 번호가 잠시 표시됩니다.

### 모니터 재정렬

1. 같은 **디스플레이** 화면 위쪽에 모니터 그림(1, 2)이 보입니다. 모니터가 두 대 이상 감지되었을 때만 나타납니다.
2. 그림을 마우스로 끌어 **책상 위 실제 배치와 같게** 놓습니다. 예를 들어 2번 모니터가 실제로 왼쪽에 있다면 2번 그림을 1번 왼쪽으로 옮깁니다.
3. **적용** 을 누릅니다.
4. 마우스 포인터를 화면 사이로 움직여 자연스럽게 넘어가는지 확인합니다.

> 모니터 높이가 다르다면 그림의 위아래 위치도 맞춰 주세요. 그러면 마우스가 화면 경계를 넘을 때 덜 걸립니다.

## 4. 노트북을 모니터에 연결했다 뺄 때: 창 위치 기억

노트북을 외부 모니터에 꽂아 쓰다가 빼고 나갔다 오면 창이 모두 노트북 화면에 몰려 있어 다시 정리해야 합니다. 윈도우 11에는 이를 위한 옵션이 있습니다.

1. **설정** → **시스템** → **디스플레이** 로 이동합니다.
2. **여러 디스플레이** 를 펼칩니다.
3. 다음 두 항목을 켭니다.

| 옵션 | 동작 |
|---|---|
| **모니터 연결을 기준으로 창 위치 기억** | 모니터를 다시 연결하면 창을 이전 위치로 되돌림 |
| **모니터 연결이 끊어지면 창을 최소화합니다** | 연결을 뺐을 때 외부 모니터에 있던 창을 최소화 |

공식 도움말에 따르면 도킹을 해제하면 외부 모니터의 창이 최소화되고, 다시 연결하면 윈도우가 모든 항목을 이전 위치로 되돌립니다.

## 5. 두 화면을 더 잘 쓰는 팁

- **창 이동**: 확장 모드에서는 창 제목 표시줄을 끌어 다른 모니터로 옮길 수 있습니다.
- **화면 분할**: 각 모니터 안에서도 창을 반씩 나눠 쓸 수 있습니다. 방법은 [윈도우 11 화면 분할(스냅) 사용법](/posts/windows-11-snap-split-screen/)에 정리했습니다.
- **밝기**: 외부 모니터는 윈도우에서 밝기가 안 바뀌는 경우가 많습니다. [야간 모드와 화면 밝기 설정](/posts/windows-11-night-light-brightness/)을 참고하세요.

## 안 될 때: 자주 겪는 문제와 해결법

| 증상 | 확인할 것 |
|---|---|
| 두 번째 모니터가 아예 안 잡힘 | 케이블·전원·입력 소스 확인 → **디스플레이** → **여러 디스플레이** → **검색** |
| 두 화면에 같은 내용이 나옴 | **Windows 키 + P** → **확장** |
| 마우스가 반대쪽으로 넘어감 | **식별** 로 번호 확인 → 그림을 실제 배치대로 끌어 놓고 **적용** |
| 모니터 그림이 하나만 보임 | 두 번째 모니터가 감지되지 않은 상태. 위의 검색부터 다시 |
| 노트북을 연결할 때마다 창이 흩어짐 | **여러 디스플레이** 에서 **창 위치 기억** 켜기 |
| 업데이트 후 갑자기 안 됨 | **Windows 업데이트** 에서 추가 업데이트 확인 |

케이블과 포트를 바꿔도 안 된다면 다른 PC에 그 모니터를 연결해 보세요. 다른 PC에서도 안 나오면 모니터나 케이블 문제일 가능성이 높습니다.

## 자주 묻는 질문

**Q. 노트북 화면을 끄고 큰 모니터만 쓰고 싶어요.**
**Windows 키 + P** 에서 **두 번째 화면만** 을 고르면 됩니다.

**Q. 무선으로 TV에 화면을 띄울 수 있나요?**
TV나 디스플레이가 무선 연결을 지원하면 **설정** → **시스템** → **디스플레이** → **여러 디스플레이** → **연결** 에서 찾아 연결할 수 있습니다.

**Q. 듀얼 모니터와 화면 분할은 다른가요?**
듀얼 모니터는 물리적인 화면을 하나 더 쓰는 것이고, 화면 분할(스냅)은 한 화면 안에서 창을 나눠 배치하는 기능입니다. 두 가지를 함께 쓰면 동시에 4개 이상의 창을 보기 좋게 띄울 수 있습니다.

## 정리

- 모니터를 연결한 뒤 **Windows 키 + P** → **확장** 을 고르면 듀얼 모니터로 쓸 수 있습니다.
- 마우스 이동 방향이 어색하면 **설정** → **시스템** → **디스플레이** 에서 **식별** 후 그림을 실제 배치대로 옮기고 **적용** 합니다.
- 노트북이라면 **여러 디스플레이** 에서 **창 위치 기억** 을 켜 두면 다시 연결할 때 창이 제자리로 돌아옵니다.
