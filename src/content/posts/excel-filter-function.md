엑셀의 **자동 필터** 는 편리하지만, 조건을 바꿀 때마다 메뉴를 다시 눌러야 하고 원본 표의 모양이 바뀝니다. "서울 지역 판매만 따로 보고 싶다", "담당자를 고르면 그 사람 실적만 나오게 하고 싶다" 같은 경우에는 **FILTER 함수** 가 더 편합니다.

FILTER는 조건에 맞는 행을 **다른 위치에 수식으로 뽑아** 줍니다. 원본이 바뀌면 결과도 자동으로 바뀝니다. 이 글은 Microsoft 공식 도움말을 바탕으로 정리했습니다.

## 사용 가능한 버전

| 사용 가능 | 사용 불가 |
|---|---|
| Microsoft 365용 Excel, Excel 2024, Excel 2021 (Windows·Mac), 모바일 Excel | Excel 2019 및 이전 버전 |

사용할 수 없는 버전에서 열면 `#NAME?` 오류가 납니다. 이전 버전 사용자와 파일을 주고받는다면 자동 필터나 피벗 테이블을 쓰는 편이 안전합니다.

## 기본 문법

```text
=FILTER(array, include, [if_empty])
```

| 인수 | 필수 | 뜻 |
|---|---|---|
| array | ○ | 뽑아낼 원본 범위 (표 전체) |
| include | ○ | 조건. 원본과 **행 수가 같은** 참/거짓 배열 |
| if_empty | | 조건에 맞는 행이 하나도 없을 때 표시할 값 |

결과는 수식을 입력한 셀부터 오른쪽·아래로 **자동으로 펼쳐집니다**(스필). 그래서 수식은 맨 왼쪽 위 한 칸에만 입력합니다.

## 예제 데이터

아래 표가 A1:D9에 있다고 하겠습니다. (1행은 제목)

| 지역 (A) | 담당자 (B) | 제품 (C) | 수량 (D) |
|---|---|---|---|
| 서울 | 김민수 | 노트북 | 12 |
| 부산 | 이서연 | 모니터 | 7 |
| 서울 | 박지훈 | 모니터 | 15 |
| 대구 | 최유진 | 노트북 | 4 |
| 서울 | 김민수 | 모니터 | 9 |
| 부산 | 정하늘 | 노트북 | 11 |
| 대구 | 이서연 | 키보드 | 20 |
| 서울 | 최유진 | 키보드 | 6 |

## 예제 1. 조건 하나: 서울 지역만

```text
=FILTER(A2:D9, A2:A9="서울", "없음")
```

| 결과 | | | |
|---|---|---|---|
| 서울 | 김민수 | 노트북 | 12 |
| 서울 | 박지훈 | 모니터 | 15 |
| 서울 | 김민수 | 모니터 | 9 |
| 서울 | 최유진 | 키보드 | 6 |

조건 값을 수식에 직접 쓰지 않고 셀(예: G1)에 두면 `=FILTER(A2:D9, A2:A9=G1, "없음")` 처럼 쓸 수 있습니다. G1에 [드롭다운 목록](/posts/excel-drop-down-list/)을 만들어 두면 지역을 고를 때마다 결과가 바뀌는 조회 화면이 됩니다.

## 예제 2. 조건 여러 개: AND는 곱하기(*)

"서울 지역**이고** 제품이 모니터"처럼 모든 조건을 만족해야 하면 조건을 괄호로 묶어 **곱합니다**.

```text
=FILTER(A2:D9, (A2:A9="서울")*(C2:C9="모니터"), "없음")
```

결과: `서울 | 박지훈 | 모니터 | 15`, `서울 | 김민수 | 모니터 | 9` 두 행.

참은 1, 거짓은 0으로 계산되므로, 곱한 값이 1인 행(두 조건 모두 참)만 남는 원리입니다.

## 예제 3. 조건 중 하나만: OR는 더하기(+)

"부산 지역**이거나** 수량이 15 이상"이면 조건을 **더합니다**.

```text
=FILTER(A2:D9, (A2:A9="부산")+(D2:D9>=15), "없음")
```

| 결과 | | | |
|---|---|---|---|
| 부산 | 이서연 | 모니터 | 7 |
| 서울 | 박지훈 | 모니터 | 15 |
| 부산 | 정하늘 | 노트북 | 11 |
| 대구 | 이서연 | 키보드 | 20 |

더한 값이 1 이상이면 참으로 보므로, 조건 중 하나라도 맞으면 남습니다.

## 예제 4. 뽑은 결과를 정렬하기: SORT와 함께

FILTER 결과를 수량이 많은 순으로 보고 싶다면 **SORT** 로 감쌉니다.

```text
=SORT(FILTER(A2:D9, A2:A9="서울", "없음"), 4, -1)
```

`4`는 결과의 4번째 열(수량), `-1`은 내림차순입니다. 결과는 박지훈 15 → 김민수 12 → 김민수 9 → 최유진 6 순서입니다.

## 예제 5. 원본에 행이 계속 추가될 때

원본을 **엑셀 표**(**Ctrl+T**)로 만들어 두고 표 이름으로 참조하면, 행이 늘어나도 FILTER 결과가 자동으로 따라옵니다. Microsoft 도움말도 표와 구조적 참조를 쓰면 데이터가 바뀔 때 결과 크기가 함께 바뀐다고 안내합니다.

```text
=FILTER(판매표, 판매표[지역]="서울", "없음")
```

단, FILTER 수식 자체는 **표 바깥** 에 입력해야 합니다. 표 안에서는 펼쳐지는 수식을 지원하지 않습니다.

## 안 될 때: 자주 나는 오류와 해결법

| 오류 | 원인 | 해결 |
|---|---|---|
| `#CALC!` | 조건에 맞는 행이 없음 (엑셀은 빈 배열을 지원하지 않음) | 세 번째 인수에 `"없음"` 이나 `""` 지정 |
| `#SPILL!` | 결과가 펼쳐질 칸에 이미 값이 있음 | 오류 셀의 경고 아이콘 → **방해하는 셀 선택** 으로 찾아 비우기 |
| `#SPILL!` | 수식을 표 안에 입력함 | 표 바깥으로 옮기거나 표를 범위로 변환 |
| `#SPILL!` | 펼쳐질 자리에 병합된 셀이 있음 | 병합 해제 또는 다른 위치로 이동 |
| `#VALUE!` | 원본과 조건 범위의 행 수가 다름 (예: A2:D9와 A2:A10) | 두 범위의 시작·끝 행을 똑같이 맞추기 |
| `#NAME?` | FILTER를 지원하지 않는 버전 또는 오타 | 버전 확인, 글자는 `"서울"`처럼 따옴표로 |
| 다른 파일 참조 결과가 `#REF!` | 참조하는 통합 문서가 닫혀 있음 | 두 파일을 모두 연 상태에서 사용 |

## 자동 필터와 무엇이 다른가

| 비교 | 자동 필터 | FILTER 함수 |
|---|---|---|
| 결과 위치 | 원본 표에서 행을 숨김 | 다른 위치에 복사본처럼 표시 |
| 조건 변경 | 메뉴에서 다시 선택 | 조건 셀 값만 바꾸면 됨 |
| 원본 수정 시 | 필터를 다시 적용해야 할 수 있음 | 자동 반영 |
| 사용 가능 버전 | 대부분 | Microsoft 365, 2024, 2021 |

## 정리

- `=FILTER(범위, 조건, "없음")` 세 칸으로 조건에 맞는 행을 뽑습니다.
- 여러 조건은 **AND = 곱하기(*)**, **OR = 더하기(+)** 로 묶습니다.
- 결과가 없을 때를 대비해 세 번째 인수를 꼭 넣고, 펼쳐질 자리는 비워 둡니다.
