엑셀에서 가장 많이 쓰는 함수를 하나만 꼽으라면 **IF** 입니다. "합격이면 O, 아니면 X", "목표를 넘으면 달성"처럼 조건에 따라 다른 값을 보여 줄 때 씁니다.

문제는 조건이 늘어날 때입니다. IF 안에 IF를 넣고, 그 안에 또 IF를 넣다 보면 괄호가 끝없이 이어지고, 조건 하나만 바꿔도 수식 전체를 다시 읽어야 합니다. 이 글에서는 IF의 기본부터 시작해 **중첩 IF를 짧게 줄이는 3가지 방법** 을 예제로 정리했습니다.

## IF 함수 기본 문법

```text
=IF(조건, 참일때값, [거짓일때값])
```

| 인수 | 필수 | 설명 |
|---|---|---|
| 조건 (logical_test) | ○ | 참(TRUE) 또는 거짓(FALSE)으로 판단할 식 |
| 참일때값 (value_if_true) | ○ | 조건이 참이면 표시할 값 |
| 거짓일때값 (value_if_false) | | 조건이 거짓이면 표시할 값 |

예를 들어 실적(B2)이 목표(C2) 이상이면 "달성", 아니면 "미달"을 표시하려면 이렇게 씁니다.

```text
=IF(B2>=C2, "달성", "미달")
```

결과로 글자 대신 계산값을 돌려줄 수도 있습니다. 목표를 넘은 만큼만 표시하고, 못 넘었으면 0을 표시하는 식입니다.

```text
=IF(B2>C2, B2-C2, 0)
```

> 수식 안의 글자는 반드시 큰따옴표(`"`)로 감쌉니다. 단, `TRUE`와 `FALSE`는 따옴표 없이 씁니다.

### 자주 쓰는 비교 연산자

| 연산자 | 뜻 | 예 |
|---|---|---|
| `=` | 같다 | `A2="완료"` |
| `<>` | 같지 않다 | `A2<>""` (비어 있지 않음) |
| `>` / `<` | 크다 / 작다 | `B2>100` |
| `>=` / `<=` | 크거나 같다 / 작거나 같다 | `B2>=60` |

## 조건이 두 개 이상일 때: AND, OR, NOT

"점수가 60점 이상**이고** 출석률이 80% 이상"처럼 조건을 묶어야 할 때는 IF 안에 **AND** 나 **OR** 를 넣습니다.

| 함수 | 의미 | 예시 |
|---|---|---|
| AND | 모든 조건이 참이어야 참 | `=IF(AND(B2>=60, C2>=0.8), "수료", "미수료")` |
| OR | 조건 중 하나만 참이어도 참 | `=IF(OR(B2="VIP", C2>=1000000), "할인", "")` |
| NOT | 조건을 반대로 뒤집음 | `=IF(NOT(D2="퇴사"), "재직", "퇴사")` |

Microsoft 문서에 따르면 AND와 OR에는 조건을 최대 255개까지 넣을 수 있고, NOT은 조건 하나만 받습니다.

## 중첩 IF: 조건이 3개 이상일 때

점수에 따라 A~F 등급을 매긴다고 해 보겠습니다. IF만으로 만들면 이렇게 됩니다.

```text
=IF(B2>89,"A",IF(B2>79,"B",IF(B2>69,"C",IF(B2>59,"D","F"))))
```

동작은 하지만 문제가 있습니다.

- **괄호가 많아 읽기 어렵습니다.** 마지막의 `))))`가 몇 개인지 세다가 실수하기 쉽습니다.
- **조건 순서가 틀리면 조용히 틀린 값이 나옵니다.** 위 수식을 작은 점수부터 `B2>59`로 시작하면 90점도 "D"가 됩니다. 오류 표시 없이 틀리기 때문에 알아채기 어렵습니다.
- **기준이 바뀌면 수식을 다시 써야 합니다.**

Microsoft는 IF를 최대 64개까지 중첩할 수 있다고 안내하면서도, 그렇게 많이 쓰는 것은 권하지 않는다고 설명합니다. 아래 3가지 방법으로 줄여 보세요.

## 방법 1. IFS 함수로 바꾸기

**IFS** 는 "조건, 값" 쌍을 차례로 나열하고, **처음으로 참이 되는 조건의 값** 을 돌려줍니다.

```text
=IFS(조건1, 값1, [조건2, 값2], ...)
```

위의 등급 수식을 IFS로 바꾸면 괄호가 하나로 줄어듭니다.

```text
=IFS(B2>89,"A", B2>79,"B", B2>69,"C", B2>59,"D", TRUE,"F")
```

| 점수 (B2) | 결과 | 이유 |
|---|---|---|
| 95 | A | 첫 조건 `B2>89`가 참 |
| 82 | B | 두 번째 조건 `B2>79`에서 처음 참 |
| 70 | C | `B2>69`에서 처음 참 |
| 59 | F | 59는 `B2>59`도 거짓이라 마지막 `TRUE`로 감 |

핵심은 마지막의 **`TRUE, "F"`** 입니다. IFS는 참인 조건이 하나도 없으면 `#N/A` 오류를 냅니다. 마지막에 `TRUE`를 넣어 두면 "나머지 전부"를 처리하는 기본값 역할을 합니다.

**IFS를 쓸 수 있는 버전** (Microsoft 문서 기준):

| 사용 가능 | 사용 불가 |
|---|---|
| Microsoft 365용 Excel, Excel 2024, Excel 2021, Excel 2019 | Excel 2016 및 이전 버전 |

조건은 최대 127개까지 넣을 수 있습니다.

## 방법 2. 기준표를 만들고 XLOOKUP·VLOOKUP으로 찾기

등급이나 수수료율처럼 **구간별로 값이 정해진 경우** 에는 기준을 수식 안에 넣지 말고 표로 따로 빼는 것이 가장 관리하기 쉽습니다. Microsoft도 중첩 IF 대신 조회 표를 쓰는 방법을 권합니다.

| | E | F |
|---|---|---|
| 1 | 기준점수 | 등급 |
| 2 | 0 | F |
| 3 | 60 | D |
| 4 | 70 | C |
| 5 | 80 | B |
| 6 | 90 | A |

```text
=XLOOKUP(B2, E2:E6, F2:F6, , -1)
```

마지막 인수 `-1`은 "같은 값이 없으면 바로 아래 값"을 찾으라는 뜻입니다. 82점은 80의 등급인 **B** 가 됩니다. XLOOKUP을 쓸 수 없는 버전이라면 기준표를 오름차순으로 정렬한 뒤 `=VLOOKUP(B2, E2:F6, 2, TRUE)`로 같은 결과를 얻습니다.

이 방법은 기준이 바뀌어도 **수식은 그대로 두고 표의 숫자만 고치면 됩니다.** XLOOKUP의 자세한 사용법은 [XLOOKUP 함수 사용법](/posts/excel-xlookup-guide/)에 정리했습니다.

> 위 표는 IFS 예제와 기준이 같습니다. IFS 예제의 `B2>89`는 "90 이상"과 같은 뜻입니다(점수가 정수일 때).

## 방법 3. 조건을 AND·OR로 묶어 단계를 줄이기

중첩 IF 중에는 사실 조건 하나로 합칠 수 있는 경우가 많습니다.

```text
=IF(B2>=60, IF(C2>=0.8, "수료", "미수료"), "미수료")
```

위 수식은 "점수 60 이상이고 출석률 80% 이상이면 수료"라는 뜻이므로 AND 하나로 바꿀 수 있습니다.

```text
=IF(AND(B2>=60, C2>=0.8), "수료", "미수료")
```

결과가 같은 가지("미수료")가 여러 번 나온다면 AND나 OR로 합칠 수 있는지 먼저 확인해 보세요.

## 어떤 방법을 고를까

| 상황 | 추천 |
|---|---|
| 조건 1~2개 | IF (필요하면 AND·OR) |
| 조건 3개 이상, 기준이 자주 안 바뀜 | IFS |
| 구간·등급·요율처럼 기준표가 있는 경우 | 기준표 + XLOOKUP(또는 VLOOKUP) |
| Excel 2016 이하와 파일을 공유 | 중첩 IF 또는 VLOOKUP (IFS·XLOOKUP 사용 불가) |

## 안 될 때: 자주 나는 문제와 해결법

| 증상 | 원인 | 해결 |
|---|---|---|
| 결과가 `0`으로 나옴 | 참일때값이나 거짓일때값을 비워 둠 | 두 인수를 모두 채우기. 빈칸으로 보이게 하려면 `""` 입력 |
| `#NAME?` | 함수 이름 오타, 글자에 따옴표 누락, 또는 IFS를 지원하지 않는 버전 | 철자·따옴표 확인, 버전 확인 |
| IFS 결과가 `#N/A` | 참인 조건이 하나도 없음 | 마지막에 `TRUE, 기본값` 추가 |
| IFS에서 "인수가 너무 적습니다" | 조건만 있고 짝이 되는 값이 빠짐 | 조건과 값을 반드시 쌍으로 입력 |
| 오류 없이 엉뚱한 등급이 나옴 | 조건 순서가 거꾸로 | 큰 기준부터(또는 작은 기준부터) 한 방향으로 정렬 |
| 숫자를 비교했는데 계속 거짓 | 숫자가 텍스트로 저장됨 | 셀 왼쪽 위 초록 삼각형 확인 후 숫자로 변환 |

## 정리

- IF는 `=IF(조건, 참일때값, 거짓일때값)` 세 칸만 기억하면 됩니다.
- 조건이 여러 개면 **AND·OR** 로 묶을 수 있는지 먼저 봅니다.
- 조건이 3개를 넘으면 **IFS** 로 바꾸고, 마지막에 `TRUE`로 기본값을 넣습니다.
- 구간별 기준이 있다면 **기준표 + XLOOKUP** 이 가장 고치기 쉽습니다.
