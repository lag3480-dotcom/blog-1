다른 시스템에서 내려받은 엑셀 파일을 열면 `홍길동,영업팀,서울`처럼 여러 정보가 한 칸에 쉼표로 붙어 있는 경우가 많습니다. 반대로 성과 이름, 시·구·동처럼 여러 칸에 나뉜 값을 한 칸으로 합쳐야 할 때도 있습니다.

엑셀에는 이런 작업을 위한 방법이 여러 가지 있고, 상황에 따라 알맞은 방법이 다릅니다. 이 글은 Microsoft 공식 도움말을 바탕으로 **나누기 3가지, 합치기 2가지** 를 예제로 정리했습니다.

## 어떤 방법을 고를까

| 하고 싶은 일 | 방법 | 원본이 바뀌면 | 사용 가능 버전 |
|---|---|---|---|
| 한 번만 나누면 됨 | **텍스트 나누기** 마법사 | 다시 실행해야 함 | 대부분의 버전 |
| 원본이 계속 바뀜 | **TEXTSPLIT** 함수 | 자동 반영 | Microsoft 365, Excel 2024 |
| 규칙이 일정치 않은 일부만 뽑기 | **빠른 채우기** (Ctrl+E) | 다시 실행해야 함 | 대부분의 버전 |
| 두세 칸 붙이기 | `&` 연산자 | 자동 반영 | 모든 버전 |
| 범위 전체를 구분 기호로 붙이기 | **TEXTJOIN** 함수 | 자동 반영 | Microsoft 365, Excel 2024·2021·2019 |

## 나누기 1. 텍스트 나누기 마법사

가장 오래되고 널리 쓰이는 방법입니다. 결과가 **값** 으로 들어가므로, 원본을 지워도 결과가 남습니다.

1. 나눌 셀이나 열을 선택합니다.
2. **데이터** 탭에서 **텍스트 나누기** 를 클릭합니다.
3. 마법사 첫 화면에서 **구분 기호로 분리됨** 을 고르고 **다음** 을 누릅니다.
4. 데이터에 맞는 구분 기호를 체크합니다. 예: **쉼표**, **공백**. 아래 **데이터 미리 보기** 에서 나뉘는 모양을 확인할 수 있습니다.
5. **다음** 을 누릅니다.
6. **대상** 칸에서 결과가 들어갈 첫 셀을 지정합니다.
7. **마침** 을 누릅니다.

> 결과는 지정한 셀부터 오른쪽으로 채워집니다. 오른쪽 열에 이미 데이터가 있다면 **대상** 을 빈 열로 바꾸거나 빈 열을 먼저 넣어 두세요.

## 나누기 2. TEXTSPLIT 함수

```text
=TEXTSPLIT(텍스트, 열_구분기호, [행_구분기호], [빈값_무시], [대소문자_구분], [채울_값])
```

수식이라서 원본 셀을 고치면 결과도 바로 바뀝니다. 결과는 오른쪽(또는 아래) 칸으로 자동으로 **펼쳐집니다(스필)**.

### 예제 1. 쉼표로 나누기

A2에 `홍길동,영업팀,서울` 이 있을 때

```text
=TEXTSPLIT(A2, ",")
```

| B2 | C2 | D2 |
|---|---|---|
| 홍길동 | 영업팀 | 서울 |

### 예제 2. 구분 기호가 여러 개일 때

A2에 `서울시 강남구, 역삼동` 처럼 공백과 쉼표가 섞여 있다면, 구분 기호를 중괄호 `{ }`로 묶어 한꺼번에 지정합니다.

```text
=TEXTSPLIT(A2, {" ",","}, , TRUE)
```

결과는 `서울시` | `강남구` | `역삼동` 입니다.

네 번째 인수 `TRUE`가 중요합니다. `강남구,` 뒤에 쉼표와 공백이 **연달아** 있어서, 이 값이 `FALSE`(기본값)이면 그 사이에 빈 칸이 하나 생깁니다. `TRUE`로 두면 연속된 구분 기호를 하나로 보고 빈 칸을 만들지 않습니다.

### 예제 3. 행과 열로 동시에 나누기

A2에 `1,2,3;4,5,6` 이 있을 때 `=TEXTSPLIT(A2, ",", ";")` 는 쉼표로 열을, 세미콜론으로 행을 나눠 2행 3열 표를 만듭니다.

| 1 | 2 | 3 |
|---|---|---|
| 4 | 5 | 6 |

## 나누기 3. 빠른 채우기 (Ctrl+E)

규칙을 수식으로 쓰기 애매할 때 편리합니다. 엑셀이 **입력한 예시의 패턴** 을 알아채서 나머지를 채웁니다.

1. 원본 옆 열 첫 칸에 원하는 결과를 직접 입력합니다. 예: A2가 `홍길동 (영업팀)` 이면 B2에 `영업팀`.
2. 아래 칸에서 **Ctrl+E** 를 누르거나 **데이터** → **빠른 채우기** 를 클릭합니다.
3. 결과를 훑어보고 틀린 행이 있으면 그 행을 직접 고친 뒤 다시 실행합니다.

빠른 채우기는 결과를 값으로 넣으므로, 원본이 바뀌면 다시 실행해야 합니다. 패턴을 추측하는 기능이라 **결과를 반드시 눈으로 확인** 하세요.

## 합치기 1. & 연산자

가장 간단한 방법입니다. 성(A2)과 이름(B2)을 붙이려면

```text
=A2&B2          → 홍길동
=A2&" "&B2      → 홍 길동 (가운데 공백)
```

### 숫자 서식이 사라질 때: TEXT 함수

`&`로 숫자를 붙이면 화면에 보이는 서식이 아니라 **실제 값** 이 붙습니다. 예를 들어 B2에 `1,234,567`로 보이는 숫자가 있어도 `=A2&" 매출 "&B2` 는 `1234567`로 붙습니다. 서식을 유지하려면 **TEXT** 함수로 감쌉니다.

```text
=A2&" 매출 "&TEXT(B2, "#,##0")&"원"
```

A2가 `서울지점` 이면 결과는 `서울지점 매출 1,234,567원` 입니다. 40%로 보이는 비율(실제 값 0.4)이라면 `TEXT(C2, "0%")` 를 씁니다.

## 합치기 2. TEXTJOIN 함수

```text
=TEXTJOIN(구분기호, 빈칸_무시, 텍스트1, [텍스트2], ...)
```

범위 전체를 한 번에, 사이에 구분 기호를 넣어 붙일 수 있습니다.

### 예제. 빈칸 무시 여부에 따른 차이

| 셀 | 값 |
|---|---|
| A2 | 사과 |
| A3 | (빈칸) |
| A4 | 배 |
| A5 | 귤 |

| 수식 | 결과 |
|---|---|
| `=TEXTJOIN(", ", TRUE, A2:A5)` | 사과, 배, 귤 |
| `=TEXTJOIN(", ", FALSE, A2:A5)` | 사과, , 배, 귤 |

두 번째 인수를 `TRUE`로 두면 빈칸을 건너뛰어 쉼표가 겹치지 않습니다. 텍스트 인수는 최대 252개까지 넣을 수 있고, 결과가 한 셀의 최대 글자 수인 **32,767자** 를 넘으면 `#VALUE!` 오류가 납니다.

## 안 될 때: 자주 나는 문제와 해결법

| 증상 | 원인 | 해결 |
|---|---|---|
| `#NAME?` (TEXTSPLIT·TEXTJOIN) | 함수를 지원하지 않는 버전 | 텍스트 나누기 마법사, 빠른 채우기, `&` 사용 |
| `#SPILL!` | TEXTSPLIT 결과가 펼쳐질 칸에 이미 값이 있음 | 오른쪽(아래) 칸을 비우기 |
| TEXTSPLIT 결과 일부가 `#N/A` | 행마다 나뉜 개수가 달라 빈 자리가 생김 | 마지막 인수에 `""` 지정, 또는 IFNA로 감싸기 |
| 사이에 빈 칸이 생김 | 구분 기호가 연달아 있음 | TEXTSPLIT 네 번째 인수를 `TRUE`로 |
| 합친 숫자의 쉼표·%가 사라짐 | `&`는 실제 값을 붙임 | `TEXT(셀, "#,##0")` 처럼 서식 지정 |
| 합친 결과로 계산이 안 됨 | 합친 결과는 텍스트 | 계산은 원본 숫자 셀로 하기 |
| Ctrl+E가 반응 없음 | 빠른 채우기 자동 실행이 꺼짐 | **파일** → **옵션** → **고급** 에서 빠른 채우기 자동 실행 옵션 확인 후 Excel 다시 시작 |

## 정리

- 한 번만 나누면 **데이터 → 텍스트 나누기**, 원본이 자주 바뀌면 **TEXTSPLIT**, 규칙이 애매하면 **Ctrl+E** 입니다.
- 두세 칸은 `&`로 붙이고, 숫자 서식은 **TEXT** 로 지정합니다.
- 범위를 구분 기호로 이어 붙일 때는 **TEXTJOIN** 에 빈칸 무시 `TRUE`를 씁니다.
