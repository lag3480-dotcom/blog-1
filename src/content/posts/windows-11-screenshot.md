윈도우 11에는 별도 프로그램을 깔지 않아도 화면을 캡처하는 방법이 여러 가지 있습니다. 상황에 맞는 단축키 몇 개만 알아 두면 업무 속도가 확 달라집니다.

## 단축키 한눈에 보기

| 단축키 | 동작 | 저장 방식 |
|---|---|---|
| **Win + Shift + S** | 영역을 골라서 캡처 (사각형·창·전체·자유형) | 클립보드 + 스크린샷 폴더 |
| **PrtSc** (Print Screen) | 전체 화면 캡처, 또는 캡처 도구 열기 (설정에 따라 다름) | 클립보드 |
| **Win + PrtSc** | 전체 화면을 바로 파일로 저장 | 스크린샷 폴더 |
| **Alt + PrtSc** | 지금 선택된 창만 캡처 | 클립보드 |
| **Win + Shift + R** | 화면 녹화 (동영상) | 캡처 도구에서 저장 |

가장 많이 쓰는 것은 **Win + Shift + S** 입니다. 이것 하나만 기억해도 대부분 해결됩니다.

## 1. Win + Shift + S: 원하는 부분만 캡처

1. **Win + Shift + S** 를 누르면 화면이 어두워지고 위쪽에 도구 막대가 나타납니다.
2. 캡처 방식을 고릅니다.
   - **사각형**: 마우스로 드래그한 영역
   - **창**: 클릭한 창 하나
   - **전체 화면**: 모니터 전체
   - **자유형**: 마우스로 그린 모양 그대로
3. 캡처가 끝나면 이미지가 **클립보드에 복사** 되고, 오른쪽 아래에 알림이 뜹니다.
4. 바로 붙여넣기(**Ctrl + V**) 하거나, 알림을 눌러 캡처 도구에서 펜으로 표시하고 저장할 수 있습니다.

Microsoft 안내에 따르면 캡처 도구로 찍은 이미지는 기본적으로 **스크린샷 폴더에도 자동 저장** 됩니다. 이 동작은 캡처 도구의 **더 보기(…) → 설정** 에서 끄거나 저장 폴더를 바꿀 수 있습니다.

## 2. PrtSc 키: 설정에 따라 동작이 다릅니다

PrtSc 키는 원래 **전체 화면을 클립보드로 복사** 하는 키입니다. 그런데 최근 윈도우 11에서는 PrtSc를 누르면 **Win + Shift + S와 같은 캡처 도구가 열리도록** 기본 설정이 바뀐 경우가 많습니다.

예전처럼 바로 전체 화면을 복사하고 싶다면:

1. **설정** → **접근성** → **키보드** 로 갑니다.
2. **'Print Screen 키를 사용하여 화면 캡처 열기'** 를 끕니다.

노트북은 PrtSc가 다른 키와 함께 있어 **Fn** 키를 같이 눌러야 하는 경우도 있습니다.

## 3. Win + PrtSc: 누르는 즉시 파일로 저장

화면이 잠깐 깜빡이면서 전체 화면이 바로 이미지 파일로 저장됩니다. 붙여넣기 할 필요 없이 여러 장을 연달아 찍을 때 편합니다.

- 저장 위치: **사진(Pictures) → 스크린샷(Screenshots)** 폴더
- 빠르게 여는 법: **Win + E** 로 파일 탐색기를 열고 왼쪽 '사진' 폴더로 이동

OneDrive 백업을 켜 두었다면 이 폴더가 OneDrive 안에 있을 수 있습니다.

## 4. Alt + PrtSc: 지금 쓰는 창만

모니터에 여러 창이 떠 있을 때 **현재 선택된 창 하나만** 클립보드로 복사합니다. 메신저나 문서에 바로 붙여넣을 때 유용합니다.

## 5. 화면 녹화: Win + Shift + R

캡처 도구는 동영상 녹화도 됩니다.

1. **Win + Shift + R** 을 누르거나, 캡처 도구에서 **녹화** 를 고르고 **새로 만들기** 를 누릅니다.
2. 녹화할 영역을 드래그로 지정합니다.
3. **시작** 을 누르면 녹화가 시작되고, **중지** 를 누르면 끝납니다.
4. 그대로 저장하거나 **Clipchamp에서 편집** 을 눌러 자르기 같은 편집을 할 수 있습니다.

## 알아 두면 좋은 캡처 도구 기능

### 캡처한 이미지에서 글자 뽑기

캡처 도구에서 이미지를 연 뒤 **텍스트 작업** 을 누르면 이미지 속 글자를 인식해서 복사할 수 있습니다. 사진으로 받은 문서나 복사가 막힌 화면의 글자를 옮길 때 편합니다. Microsoft는 이 글자 인식이 **기기 안에서 처리** 된다고 안내합니다.

같은 메뉴의 **빠른 수정(Quick redact)** 을 쓰면 이미지 속 이메일 주소와 전화번호를 자동으로 가려 줍니다. 캡처를 공유하기 전에 개인정보를 지우는 데 유용합니다.

### 몇 초 뒤에 캡처하기 (타이머)

마우스를 올려야 나타나는 메뉴처럼, 캡처하는 순간 사라지는 화면을 찍을 때 씁니다.

1. 캡처 도구 앱을 엽니다. (시작 메뉴에서 '캡처 도구' 검색)
2. **지연** 에서 3초, 5초, 10초 중 하나를 고릅니다.
3. **새로 만들기** 를 누르고 시간 안에 원하는 화면을 띄워 둡니다.

## 상황별 추천

| 상황 | 추천 방법 |
|---|---|
| 메신저에 화면 일부를 바로 보낼 때 | Win + Shift + S → Ctrl + V |
| 여러 화면을 연달아 파일로 남길 때 | Win + PrtSc |
| 특정 프로그램 창만 깔끔하게 | Alt + PrtSc 또는 Win + Shift + S의 '창' 모드 |
| 사용 방법을 영상으로 보여줄 때 | Win + Shift + R |
| 이미지 속 글자를 복사할 때 | 캡처 도구의 텍스트 작업 |

## 캡처가 안 될 때

- **PrtSc를 눌러도 아무 일이 없다**: 노트북이라면 Fn 키를 함께 눌러 보세요. 위 2번의 설정도 확인하세요.
- **Win + Shift + S가 안 먹힌다**: 캡처 도구가 삭제되었을 수 있습니다. Microsoft Store에서 '캡처 도구(Snipping Tool)'를 검색해 다시 설치하세요.
- **넷플릭스 같은 영상이 검게 찍힌다**: 저작권 보호(DRM)가 걸린 콘텐츠는 캡처가 막혀 있는 것이 정상입니다.
- **회사 PC에서 캡처가 막혀 있다**: 보안 정책으로 차단된 경우이므로 IT 담당 부서에 문의하세요.
