업무 이메일은 내용보다 **말투와 수위** 를 정하는 데 시간이 더 걸립니다. 거절은 정중하게, 독촉은 불편하지 않게, 사과는 변명처럼 들리지 않게 써야 하기 때문입니다. 이럴 때 AI에게 초안을 맡기면 시간을 크게 줄일 수 있습니다.

다만 "거절 메일 써 줘"처럼 짧게 요청하면 누구에게나 보낼 수 있는 뻔한 문장이 나옵니다. 이 글은 OpenAI, Google, Anthropic의 공식 프롬프트 가이드가 공통으로 강조하는 원칙(구체적 지시, 맥락 제공, 형식 지정)을 이메일 상황에 적용한 프롬프트 예시를 정리했습니다. ChatGPT, Claude, Gemini 어디에서나 그대로 쓸 수 있습니다.

## 이메일 프롬프트의 기본 공식

좋은 이메일 프롬프트에는 다섯 가지가 들어갑니다.

| 요소 | 알려줄 내용 | 예 |
|---|---|---|
| **받는 사람** | 관계, 직급, 친밀도 | 거래처 과장, 처음 연락함 |
| **목적** | 이 메일로 얻고 싶은 결과 | 견적서를 이번 주 금요일까지 받기 |
| **사실** | 날짜, 금액, 건명 등 구체 정보 | 10월 28일 요청한 견적, 아직 회신 없음 |
| **말투** | 정중함 정도, 길이 | 정중하지만 짧게, 5문장 이내 |
| **형식** | 제목 포함 여부, 구성 | 제목 + 본문, 마지막에 요청 사항 한 줄 |

공식 가이드들이 말하는 원칙은 결국 "AI는 내 사정을 모른다"는 것입니다. 빠진 정보는 AI가 가장 평범한 쪽으로 채우기 때문에, 위 다섯 가지를 적을수록 바로 보낼 수 있는 초안에 가까워집니다. 프롬프트 원칙 전반은 [AI 프롬프트 잘 쓰는 법](/posts/ai-prompt-writing-guide/)에 정리했습니다.

### 바로 쓰는 틀

```text
아래 상황에 맞는 업무 이메일을 써 줘.
- 받는 사람: (관계, 직급)
- 목적: (이 메일로 얻을 결과)
- 상황: (날짜, 금액, 건명 등 사실)
- 말투: (정중함 정도, 길이)
- 형식: 제목 1개 + 본문. 본문 마지막 줄에 요청 사항과 기한을 적어 줘.
```

## 상황별 프롬프트 예시

### 1. 요청 메일

```text
거래처 담당자(처음 연락하는 과장님)에게 보낼 견적 요청 메일을 써 줘.
- 품목: 사무용 의자 30개, 납품 희망일 12월 첫째 주
- 필요한 것: 단가, 배송비 포함 총액, 납기
- 회신 기한: 11월 6일(금)
- 말투: 정중하고 간결하게, 본문 6문장 이내
- 형식: 제목 + 본문 + 서명 자리
```

요청 메일의 핵심은 **무엇을, 언제까지** 받고 싶은지입니다. 이 두 가지가 빠지면 AI가 "검토 부탁드립니다" 같은 모호한 문장으로 끝내는 경우가 많습니다.

### 2. 거절 메일

```text
협력사에서 제안한 공동 프로모션을 이번에는 거절하는 메일을 써 줘.
- 거절 이유: 올해 마케팅 예산이 이미 확정됨 (내부 사정은 자세히 밝히지 않기)
- 관계: 앞으로도 함께 일하고 싶은 업체
- 포함할 것: 제안에 대한 감사, 명확한 거절, 내년 1분기에 다시 이야기하자는 제안
- 피할 것: "검토해 보겠다"처럼 여지를 두는 표현
- 말투: 따뜻하지만 분명하게
```

거절 메일은 **피할 표현** 을 함께 알려주는 것이 중요합니다. 그렇지 않으면 AI가 상대를 배려하려다 거절인지 아닌지 모호한 문장을 쓰기 쉽습니다.

### 3. 사과 메일

```text
고객에게 배송 지연을 사과하는 메일을 써 줘.
- 사실: 주문일 10월 25일, 원래 도착 예정 10월 28일, 실제 발송 10월 31일 예정
- 원인: 물류센터 재고 착오 (책임을 회피하는 표현은 쓰지 않기)
- 조치: 발송 즉시 운송장 번호 안내
- 말투: 진심 어린 사과, 변명처럼 들리지 않게
- 형식: 사과 → 원인 한 문장 → 앞으로의 조치 → 다시 사과 순서
```

사과 메일은 **구성 순서** 를 지정하면 결과가 안정적입니다. 보상 내용처럼 회사가 정하지 않은 약속을 AI가 임의로 넣지 않도록, 넣을 조치를 프롬프트에 직접 적으세요.

### 4. 독촉 메일

```text
11월 3일까지 받기로 한 디자인 시안이 아직 오지 않아 확인을 요청하는 메일을 써 줘.
- 받는 사람: 외주 디자이너 (지금까지 관계 좋음)
- 사정: 11월 10일 내부 보고가 있어 늦어도 11월 6일까지 필요
- 말투: 재촉하는 느낌은 줄이고, 일정이 급한 이유를 설명하는 방식
- 포함할 것: 혹시 문제가 있으면 알려 달라는 문장
- 길이: 4~5문장
```

독촉 메일은 **두 번째·세 번째 독촉** 일 때 수위를 단계적으로 올려 달라고 요청할 수도 있습니다.

```text
같은 내용으로, 이번이 두 번째 연락이라는 점을 밝히고 조금 더 분명한 말투로 다시 써 줘.
기한을 넘기면 일정 조정이 불가피하다는 점도 정중하게 덧붙여 줘.
```

### 5. 감사 메일

```text
프로젝트를 도와준 다른 팀 대리님께 감사 메일을 써 줘.
- 도움 받은 일: 고객 데이터 정리를 하루 만에 처리해 줌
- 결과: 그 덕분에 제안서를 기한 안에 제출함
- 말투: 진심이 느껴지되 과하지 않게, 팀장님을 참조로 넣을 예정
```

감사 메일은 **무엇이 어떻게 도움이 됐는지** 구체적인 사실을 넣어야 형식적인 인사로 끝나지 않습니다.

### 6. 일정 조율 메일

```text
다음 주 미팅 일정을 조율하는 메일을 써 줘.
- 참석자: 거래처 2명, 우리 팀 3명
- 후보: 11월 9일(월) 14시, 11월 10일(화) 10시, 11월 11일(수) 16시
- 장소: 우리 회사 3층 회의실 또는 화상회의
- 요청: 가능한 시간 모두 회신, 11월 5일(목)까지
- 형식: 후보 시간은 번호 목록으로
```

## 결과를 다듬는 후속 지시

첫 결과가 마음에 들지 않으면 처음부터 다시 쓰지 말고 고칠 점만 말하면 됩니다. 공식 가이드들도 한 번에 끝내려 하기보다 결과를 보고 지시를 다듬으라고 권합니다.

| 고치고 싶은 점 | 후속 지시 예시 |
|---|---|
| 너무 길다 | "핵심만 남겨서 3문장으로 줄여 줘" |
| 너무 딱딱하다 | "조금 더 부드럽게, 같은 내용으로 다시 써 줘" |
| 상투적이다 | "'항상 노고에 감사드립니다' 같은 인사말은 빼 줘" |
| 버전을 비교하고 싶다 | "정중한 버전과 간결한 버전 두 가지로 써 줘" |
| 영어로 보내야 한다 | "같은 내용을 비즈니스 영어로 바꿔 줘. 너무 격식 차리지 않게" |
| 제목이 약하다 | "열어 보고 싶게 하는 제목 후보를 3개 만들어 줘" |

## 보내기 전에 꼭 확인할 것

| 확인 항목 | 이유 |
|---|---|
| 날짜·요일·금액·이름 | AI가 프롬프트에 없는 값을 지어내거나 요일을 틀리게 쓸 수 있음 |
| 약속하지 않은 내용 | 보상, 할인, 일정 확정 같은 문장이 임의로 들어갔는지 |
| 회사 내부 정보 | 프롬프트에 넣은 내부 사정이 본문에 그대로 노출되지 않았는지 |
| 받는 사람 호칭 | 직급, 존칭이 맞는지 |
| 말투 일관성 | 회사나 팀에서 평소 쓰는 표현과 너무 다르지 않은지 |

특히 고객 이름, 연락처, 계약 금액 같은 정보를 AI에 넣기 전에는 회사 보안 규정을 먼저 확인하세요. 문서를 AI에 넣을 때의 주의점은 [AI로 문서 요약하기](/posts/ai-document-summary-prompts/)에도 정리했습니다.

## 안 될 때: 자주 겪는 문제와 해결법

| 증상 | 원인 | 해결 |
|---|---|---|
| 누구에게나 보낼 법한 문장만 나옴 | 상황 정보가 부족함 | 날짜, 건명, 관계 같은 사실을 추가 |
| 거절인지 아닌지 애매함 | 상대를 배려하려는 표현이 과함 | "명확하게 거절", "여지를 두는 표현 금지"를 명시 |
| 너무 길고 인사말이 많음 | 길이 지정이 없음 | "5문장 이내", "인사말은 한 줄"처럼 숫자로 지정 |
| 사실과 다른 내용이 들어감 | 빈 정보를 AI가 추측해 채움 | "프롬프트에 없는 정보는 넣지 말 것"을 추가하고 직접 검토 |
| 회사 말투와 다름 | 평소 문체를 모름 | 예전에 보낸 메일 한 통을 예시로 붙이고 "이 말투로" 요청 |

## 정리

- 이메일 프롬프트에는 **받는 사람, 목적, 사실, 말투, 형식** 다섯 가지를 넣습니다.
- 거절은 피할 표현을, 사과는 구성 순서를, 독촉은 급한 이유를 함께 알려주면 결과가 좋아집니다.
- AI 초안은 그대로 보내지 말고 **날짜·금액·이름과 약속하지 않은 내용** 을 반드시 확인합니다.
