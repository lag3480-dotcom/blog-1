**Ctrl + C** 로 복사하고 **Ctrl + V** 로 붙여 넣으면 마지막에 복사한 것 하나만 쓸 수 있습니다. 여러 곳에서 문장을 모아 붙이거나, 주소·계좌번호처럼 같은 문구를 자주 쓴다면 번거롭습니다.

윈도우 11의 **클립보드 기록** 을 켜면 복사한 항목이 차례로 쌓이고, **Windows 키 + V** 로 목록을 열어 원하는 것을 골라 붙여 넣을 수 있습니다. 이 글은 Microsoft 공식 도움말 "클립보드 사용"을 바탕으로 정리했습니다. (작성일 2026년 11월 3일)

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 여는 단축키 | **Windows 키 + V** |
| 켜는 곳 | Win+V 창의 **켜기**, 또는 **설정 → 시스템 → 클립보드** |
| 저장 개수 | 최대 **25개** (넘으면 오래된 항목부터 자동 삭제, 고정 항목 제외) |
| 항목당 크기 | **4MB** 까지 |
| 지원 형식 | 텍스트, HTML, 비트맵(이미지) |
| PC 다시 시작 | **고정 항목만 남고** 나머지는 지워짐 |

## 1단계. 클립보드 기록 켜기

### 방법 A. 단축키로

1. **Windows 키 + V** 를 누릅니다.
2. 클립보드 기록이 꺼져 있으면 안내 창이 나옵니다. **켜기** 를 선택합니다.

### 방법 B. 설정에서

1. **시작** → **설정** → **시스템** → **클립보드** 로 이동합니다.
2. 클립보드 기록을 켭니다.

켠 뒤부터 복사하는 항목이 기록됩니다. 켜기 전에 복사한 것은 목록에 나오지 않습니다.

## 2단계. 골라서 붙여넣기

1. 평소처럼 **Ctrl + C** 로 여러 번 복사합니다.
2. 붙여 넣을 위치에 커서를 둡니다.
3. **Windows 키 + V** 를 눌러 목록을 엽니다.
4. 원하는 항목을 클릭하면 그 자리에 붙여 넣어집니다.

### 이렇게 쓰면 편합니다

| 상황 | 활용 |
|---|---|
| 여러 웹페이지에서 문장 모으기 | 차례로 복사한 뒤 문서에서 Win+V로 하나씩 붙여넣기 |
| 표의 여러 값을 다른 곳에 옮기기 | 값마다 복사해 두고 순서대로 붙여넣기 |
| 실수로 다른 걸 복사해 원래 내용이 사라짐 | Win+V에서 이전 항목 찾기 |
| 스크린샷을 문서에 붙이기 | 이미지(비트맵)도 기록에 남으므로 목록에서 선택 |

## 3단계. 자주 쓰는 문구는 고정하기

회사 주소, 이메일 서명, 자주 보내는 안내 문구처럼 반복해서 쓰는 텍스트는 **고정** 해 두세요.

- 고정한 항목은 25개 한도를 넘어도 **자동으로 지워지지 않습니다**.
- **PC를 다시 시작해도 남아 있습니다.** 고정하지 않은 항목은 재시작하면 지워집니다.

Win+V 목록에서 해당 항목의 메뉴를 열면 고정할 수 있습니다.

## 4단계. 지우기

| 하고 싶은 일 | 방법 |
|---|---|
| 항목 하나 지우기 | 항목 옆 **더 보기(...)** → **삭제** |
| 고정 항목 빼고 모두 지우기 | **설정 → 시스템 → 클립보드** 의 클립보드 데이터 지우기 영역에서 **지우기** |
| Win+V 창에서 한꺼번에 지우기 | 창 위쪽의 **모두 지우기** |

> 비밀번호, 주민등록번호, 카드 번호처럼 민감한 정보를 복사했다면 쓰고 난 뒤 바로 지우는 것이 안전합니다. 공용 PC에서는 특히 주의하세요.

## 다른 PC와 클립보드 동기화

같은 계정으로 쓰는 여러 PC 사이에서 복사한 텍스트를 주고받을 수도 있습니다.

1. **설정 → 시스템 → 클립보드** 에서 디바이스 전체에서 클립보드 기록(장치 간 동기화) 항목을 켭니다.
2. 동기화 방식을 고릅니다.

| 방식 | 동작 |
|---|---|
| 복사하는 텍스트를 자동으로 동기화 | 복사할 때마다 자동으로 다른 장치에 전달 |
| 복사한 텍스트를 수동으로 동기화 | 기록 창에서 동기화 단추를 눌러야 전달 |

모든 장치에서 **같은 Microsoft 계정 또는 회사 계정** 으로 로그인해야 합니다. 민감한 정보를 자주 다룬다면 수동 동기화를 고르는 편이 안전합니다.

## 안 될 때: 자주 겪는 문제와 해결법

| 증상 | 원인 | 해결 |
|---|---|---|
| Win+V를 눌러도 기록이 비어 있음 | 기록을 켜기 전에 복사함, 또는 재시작으로 지워짐 | 켠 뒤 다시 복사, 자주 쓰는 항목은 고정 |
| 어떤 항목이 기록에 안 남음 | 항목이 4MB보다 크거나 지원하지 않는 형식 | 텍스트·이미지로 나눠 복사 |
| 오래된 항목이 사라짐 | 25개 한도 초과로 자동 삭제 | 필요한 항목은 고정 |
| 다른 PC로 동기화가 안 됨 | 계정이 다르거나 동기화 꺼짐, 수동 동기화 방식 | 같은 계정 로그인, 동기화 켜기, 수동이면 동기화 단추 누르기 |
| 재부팅 후 목록이 없어짐 | 정상 동작 (고정 항목만 유지) | 계속 쓸 항목은 고정 |

## 정리

- **Windows 키 + V** 로 클립보드 기록을 열고, 처음에는 **켜기** 를 누릅니다.
- 최대 **25개**, 항목당 **4MB** 까지 저장되며, 재시작하면 **고정 항목만** 남습니다.
- 자주 쓰는 문구는 고정하고, 민감한 정보는 쓰고 나서 바로 지웁니다.
