고객 명단을 합치거나 여러 사람이 입력한 시트를 정리하다 보면 같은 데이터가 두 번, 세 번 들어가 있는 경우가 많습니다. 엑셀에는 중복을 다루는 방법이 여러 가지 있는데, **무엇을 하고 싶은지에 따라 골라야** 합니다.

| 하고 싶은 일 | 방법 | 원본 변경 |
|---|---|---|
| 중복이 어디 있는지 눈으로 확인 | ① 조건부 서식 | 없음 |
| 중복 행을 한 번에 삭제 | ② 중복된 항목 제거 | **삭제됨** |
| 원본은 두고 고유값만 다른 곳에 복사 | ③ 고급 필터 | 없음 |
| 원본이 바뀌면 자동으로 갱신되는 고유값 목록 | ④ UNIQUE 함수 | 없음 |

> **먼저 기억할 것**: ②번 '중복된 항목 제거'는 데이터를 **영구 삭제** 합니다. Microsoft도 실행 전에 원본을 다른 시트에 복사해 두고, ①번이나 ③번으로 결과를 먼저 확인하라고 권합니다.

## ① 조건부 서식으로 중복값 색칠하기

데이터는 그대로 두고 중복된 셀만 색으로 표시합니다. 가장 안전한 첫 단계입니다.

1. 중복을 확인할 범위를 선택합니다. (예: 이메일 열 전체)
2. **홈** 탭 → **조건부 서식** → **셀 강조 규칙** → **중복 값** 을 누릅니다.
3. 왼쪽 목록이 '중복'인지 확인하고, 표시할 서식(예: 연한 빨강 채우기)을 고른 뒤 **확인** 을 누릅니다.

같은 메뉴에서 '중복' 대신 **'고유'** 를 고르면 반대로 한 번만 나온 값이 표시됩니다.

**팁**: 색칠한 뒤 **데이터 → 필터** 를 켜고 '색 기준 필터'를 쓰면 중복된 행만 모아 볼 수 있습니다.

## ② '중복된 항목 제거'로 한 번에 삭제하기

1. 표 안의 아무 셀이나 클릭하거나 범위를 선택합니다.
2. **데이터** 탭 → **데이터 도구** 그룹 → **중복된 항목 제거** 를 누릅니다.
3. **어떤 열을 기준으로 중복을 판단할지** 체크합니다.
4. **확인** 을 누르면 "○개의 중복 값이 제거되었습니다" 메시지가 나옵니다.

실수했다면 바로 **Ctrl+Z** 로 되돌릴 수 있습니다. 하지만 저장하고 닫은 뒤에는 되돌릴 수 없습니다.

### 기준 열 선택이 가장 중요합니다

여기서 많이 하는 실수가 있습니다. 체크한 열만 비교하지만, **삭제는 행 전체** 가 됩니다. 그리고 **처음 나온 행이 남고** 뒤에 나온 행이 지워집니다.

| 이름 | 이메일 | 가입일 |
|---|---|---|
| 김민준 | minjun@example.com | 2026-01-05 |
| 김민준 | minjun@example.com | 2026-09-12 |

- '이메일'만 체크하면 → 둘 중 **위쪽(1월 가입) 행만 남습니다.**
- 세 열을 모두 체크하면 → 가입일이 다르므로 **둘 다 남습니다.**

최신 기록을 남기고 싶다면 먼저 가입일 기준 **내림차순 정렬** 을 한 뒤 중복 제거를 실행하세요.

### 이럴 때는 실행이 안 됩니다

- 부분합이나 그룹(윤곽)이 적용된 데이터: 먼저 부분합과 윤곽을 해제해야 합니다.

## ③ 고급 필터로 고유값만 다른 곳에 복사하기

원본은 그대로 두고 중복을 뺀 목록을 따로 만들 때 씁니다.

1. 범위 안의 셀을 클릭합니다.
2. **데이터** 탭 → **정렬 및 필터** 그룹 → **고급** 을 누릅니다.
3. **다른 장소에 복사** 를 고르고, **복사 위치** 에 결과를 놓을 빈 셀을 지정합니다.
4. **동일한 레코드는 하나만** 에 체크하고 **확인** 을 누릅니다.

'현재 위치에 필터'를 고르면 중복 행이 삭제되지 않고 **숨겨지기만** 합니다.

## ④ UNIQUE 함수로 자동 갱신되는 목록 만들기

Microsoft 365, Excel 2021·2024를 쓴다면 함수 하나로 끝납니다. 원본 데이터가 바뀌면 결과도 자동으로 바뀌는 것이 장점입니다.

```text
=UNIQUE(범위, [열 기준 비교], [한 번만 나온 값만])
```

| 수식 | 결과 |
|---|---|
| `=UNIQUE(A2:A100)` | A열에서 중복을 뺀 목록 |
| `=SORT(UNIQUE(A2:A100))` | 중복을 뺀 목록을 가나다순으로 |
| `=UNIQUE(A2:A100, FALSE, TRUE)` | **딱 한 번만** 나온 값만 (재구매하지 않은 고객 찾기 등) |
| `=UNIQUE(A2:C100)` | 세 열이 모두 같은 행만 중복으로 보고 제거 |
| `=COUNTA(UNIQUE(A2:A100))` | 고유값이 몇 개인지 개수 세기 |

결과는 아래 칸으로 자동으로 펼쳐지므로, 결과가 들어갈 자리를 비워 두세요. 자리에 값이 있으면 `#SPILL!` 오류가 납니다. Excel 2019 이하에서는 이 함수를 쓸 수 없으니 ①~③번을 쓰세요.

## 중복인데 중복으로 안 잡힐 때

| 증상 | 원인 | 해결 |
|---|---|---|
| 똑같아 보이는데 다르다고 나옴 | 앞뒤 공백, 눈에 안 보이는 문자 | 옆 열에 `=TRIM(CLEAN(A2))` 로 정리한 뒤 비교 |
| 숫자가 같은데 다르다고 나옴 | 한쪽은 숫자, 한쪽은 텍스트 | 셀 서식 통일, 초록 삼각형 경고에서 '숫자로 변환' |
| 날짜가 같은데 다르다고 나옴 | 표시 형식이 다름 | 중복 판단은 **화면에 보이는 값** 기준이므로 날짜 서식을 통일 |
| 대소문자만 다른 값 | 엑셀은 대소문자를 구분하지 않음 | 구분해야 한다면 EXACT 함수로 따로 비교 |

마지막 항목처럼 엑셀은 `Apple`과 `apple`을 같은 값으로 봅니다. 대부분은 이게 편하지만, 상품 코드처럼 대소문자가 의미 있는 데이터라면 주의하세요.

## 정리

- **확인만** 하려면 조건부 서식, **지우려면** 중복된 항목 제거, **원본을 지키려면** 고급 필터나 UNIQUE 함수.
- 중복 제거는 **선택한 열로 판단하고 행 전체를 삭제하며, 위쪽 행이 남습니다.** 남길 행이 위로 오도록 먼저 정렬하세요.
- 삭제 전에는 원본을 복사해 두는 습관이 가장 확실한 안전장치입니다.
