VLOOKUP은 편하지만 **찾는 값이 표의 가장 왼쪽 열에 있어야** 한다는 제약이 있습니다. 사번으로 이름을 찾는 것은 되지만, 이름으로 그보다 왼쪽에 있는 사번을 찾는 것은 안 됩니다.

Microsoft 공식 도움말도 표가 그렇게 만들어져 있지 않다면 VLOOKUP 대신 **INDEX 함수와 MATCH 함수를 조합해** 쓰라고 안내합니다. 이 글은 두 함수를 하나씩 이해한 뒤 함께 쓰는 방법을 예제로 정리했습니다. (작성일 2026년 11월 5일)

## 한눈에 보기

| 함수 | 하는 일 | 형식 |
|---|---|---|
| **MATCH** | 범위에서 값을 찾아 **몇 번째인지(위치)** 를 돌려줌 | =MATCH(찾을 값, 찾을 범위, [일치 유형]) |
| **INDEX** | 범위에서 **몇 번째 행·열의 값** 을 돌려줌 | =INDEX(범위, 행 번호, [열 번호]) |
| **INDEX + MATCH** | MATCH로 위치를 찾고, INDEX로 그 위치의 값을 꺼냄 | =INDEX(가져올 열, MATCH(찾을 값, 찾을 열, 0)) |

## 예제 표

아래 표가 A1:D6에 있다고 가정하겠습니다.

| | A | B | C | D |
|---|---|---|---|---|
| 1 | 사번 | 이름 | 부서 | 내선 |
| 2 | 1001 | 김하나 | 영업 | 201 |
| 3 | 1002 | 이두리 | 인사 | 305 |
| 4 | 1003 | 박세진 | 영업 | 207 |
| 5 | 1004 | 최네모 | 회계 | 410 |
| 6 | 1005 | 정다섯 | 인사 | 312 |

## 1. MATCH 함수: 몇 번째인지 찾기

MATCH는 값 자체가 아니라 **범위 안에서의 상대 위치** 를 돌려줍니다.

```
=MATCH("박세진", B2:B6, 0)
```

B2:B6에서 "박세진"은 세 번째에 있으므로 결과는 **3** 입니다.

### 일치 유형: 0을 기본으로 쓰세요

| 일치 유형 | 찾는 값 | 범위 정렬 조건 |
|---|---|---|
| **0** | 찾을 값과 **정확히 같은** 첫 번째 값 | 정렬 필요 없음 |
| **1** 또는 생략 | 찾을 값보다 **작거나 같은 값 중 가장 큰 값** | **오름차순** 정렬 필요 |
| **-1** | 찾을 값보다 **크거나 같은 값 중 가장 작은 값** | **내림차순** 정렬 필요 |

일치 유형을 생략하면 **1** 로 처리됩니다. 이름이나 코드처럼 정확히 같은 값을 찾을 때 0을 빠뜨리면, 범위가 정렬되어 있지 않아 엉뚱한 위치가 나올 수 있습니다. 정확한 값을 찾을 때는 **항상 0을 적는 습관** 을 들이세요.

MATCH는 **대소문자를 구분하지 않습니다.** "abc"와 "ABC"를 같은 값으로 봅니다.

## 2. INDEX 함수: 몇 번째 값 꺼내기

```
=INDEX(D2:D6, 3)
```

D2:D6에서 세 번째 값인 **207** 이 나옵니다. 범위가 여러 열이면 열 번호도 지정합니다.

```
=INDEX(A2:D6, 3, 2)
```

A2:D6의 3행 2열, 즉 **박세진** 이 나옵니다. 범위가 한 열이나 한 행뿐이면 열 번호(또는 행 번호)를 생략할 수 있습니다.

## 3. INDEX + MATCH: 함께 쓰기

MATCH로 찾은 위치를 INDEX의 행 번호 자리에 넣으면 됩니다.

### 예제 1. 이름으로 내선 번호 찾기

```
=INDEX(D2:D6, MATCH("박세진", B2:B6, 0))
```

1. MATCH("박세진", B2:B6, 0) → **3**
2. INDEX(D2:D6, 3) → **207**

### 예제 2. 이름으로 왼쪽 열의 사번 찾기 (VLOOKUP으로는 안 됨)

```
=INDEX(A2:A6, MATCH("최네모", B2:B6, 0))
```

1. MATCH("최네모", B2:B6, 0) → **4**
2. INDEX(A2:A6, 4) → **1004**

찾는 열(B)이 가져올 열(A)보다 오른쪽에 있어도 문제없습니다. 이것이 INDEX + MATCH를 쓰는 가장 큰 이유입니다.

### 예제 3. 셀 값을 기준으로 찾기

F2 셀에 이름을 입력하면 내선 번호가 나오게 하려면:

```
=INDEX($D$2:$D$6, MATCH(F2, $B$2:$B$6, 0))
```

범위를 **$** 로 고정해 두면 수식을 아래로 복사해도 범위가 밀리지 않습니다.

### 예제 4. 행과 열을 동시에 찾기 (2차원 조회)

MATCH를 두 번 써서 행 번호와 열 번호를 모두 찾을 수 있습니다. 이름(F2)과 항목명(G2, 예: "부서")으로 값을 찾는 수식입니다.

```
=INDEX($A$2:$D$6, MATCH(F2, $B$2:$B$6, 0), MATCH(G2, $A$1:$D$1, 0))
```

F2가 "이두리", G2가 "부서"라면:

1. 행: MATCH("이두리", B2:B6, 0) → **2**
2. 열: MATCH("부서", A1:D1, 0) → **3**
3. INDEX(A2:D6, 2, 3) → **인사**

G2를 "내선"으로 바꾸면 열 번호가 4가 되어 **305** 가 나옵니다. 가져올 항목을 바꿀 때 수식을 고칠 필요가 없습니다.

## VLOOKUP, XLOOKUP과 비교

| 구분 | VLOOKUP | INDEX + MATCH | XLOOKUP |
|---|---|---|---|
| 왼쪽 열 찾기 | 안 됨 | **됨** | 됨 |
| 열을 추가·삭제할 때 | 열 번호를 고쳐야 함 | 범위가 따라 바뀜 | 범위가 따라 바뀜 |
| 사용 가능한 버전 | 모든 버전 | **모든 버전** | Microsoft 365, Excel 2021·2024 등 (2019 이전 불가) |
| 수식 길이 | 짧음 | 김 | 짧음 |

XLOOKUP을 쓸 수 있는 환경이라면 XLOOKUP이 더 간단합니다. 하지만 회사에 오래된 엑셀 버전이 섞여 있거나 다른 사람과 파일을 주고받는다면 INDEX + MATCH가 가장 안전합니다. XLOOKUP 사용법은 [엑셀 XLOOKUP 함수 사용법](/posts/excel-xlookup-guide/)에 정리했습니다.

## 안 될 때: 오류별 해결법

Microsoft 도움말은 INDEX/MATCH에서 #N/A가 나는 가장 흔한 원인으로 **찾는 값이 범위에 없는 경우** 를 꼽습니다.

| 증상 | 원인 | 해결 |
|---|---|---|
| **#N/A** | 찾는 값이 범위에 없음 | 철자, 띄어쓰기 확인 |
| **#N/A** (값이 분명히 있는데) | 앞뒤 **공백** 이나 보이지 않는 문자 | TRIM, CLEAN 함수로 정리 |
| **#N/A** (숫자인데) | 한쪽은 숫자, 한쪽은 **텍스트로 저장된 숫자** | 두 범위의 데이터 형식을 맞춤 |
| 엉뚱한 값이 나옴 | 일치 유형을 생략(1)했는데 범위가 정렬되지 않음 | 일치 유형에 **0** 입력 |
| **#REF!** | 행·열 번호가 INDEX 범위 밖을 가리킴 | INDEX 범위와 MATCH 범위의 행 수를 맞춤 |
| 수식 복사 후 결과가 틀림 | 범위가 고정되지 않아 한 칸씩 밀림 | 범위에 **$** 붙이기 |

### #N/A를 다른 글자로 바꾸고 싶다면

```
=IFERROR(INDEX(D2:D6, MATCH(F2, B2:B6, 0)), "없음")
```

다만 Microsoft 도움말은 #N/A를 다른 값으로 바꾸는 것은 오류를 가릴 뿐 해결하지는 않는다고 설명합니다. 수식이 제대로 동작하는지 먼저 확인한 뒤에 IFERROR를 씌우세요.

## 자주 묻는 질문

**Q. INDEX 범위와 MATCH 범위는 꼭 같은 크기여야 하나요?**
같은 행에서 시작하고 행 수가 같아야 안전합니다. 예를 들어 MATCH는 B2:B6에서 찾는데 INDEX는 D3:D7에서 꺼내면, 한 칸씩 어긋난 값이 나옵니다.

**Q. 같은 이름이 두 번 있으면 어떻게 되나요?**
일치 유형 0은 **정확히 같은 첫 번째 값** 의 위치를 돌려주므로, 위쪽에 있는 행의 값만 나옵니다. 중복이 있는 데이터라면 먼저 [엑셀 중복 값 찾기·제거](/posts/excel-remove-duplicates/)로 정리하거나, 사번처럼 겹치지 않는 값으로 찾으세요.

**Q. 조건이 여러 개면요?**
조건을 합쳐서 찾는 방법도 있지만 수식이 복잡해집니다. 합계나 개수가 목적이라면 [SUMIFS·COUNTIFS](/posts/excel-sumifs-countifs/)가, 여러 행을 한꺼번에 뽑는 것이 목적이라면 [FILTER 함수](/posts/excel-filter-function/)가 더 간단합니다.

## 정리

- **MATCH** 는 위치를, **INDEX** 는 그 위치의 값을 돌려주며, 둘을 합치면 VLOOKUP처럼 값을 찾을 수 있습니다.
- 정확한 값을 찾을 때는 MATCH의 일치 유형에 **0** 을 꼭 넣습니다.
- 왼쪽 열 찾기, 2차원 조회가 필요하거나 오래된 엑셀 버전과 호환이 필요하면 INDEX + MATCH가 유용합니다.
