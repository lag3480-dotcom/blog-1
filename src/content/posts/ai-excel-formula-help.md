"조건이 두 개인 합계는 어떻게 구하지?", "왜 #N/A가 뜨지?" 같은 엑셀 고민은 AI 챗봇에게 물어보면 빠르게 해결되는 경우가 많습니다. 하지만 질문이 모호하면 **내 표와 맞지 않는 수식** 이나 **내 엑셀 버전에 없는 함수** 를 받기 쉽습니다.

이 글은 AI에게 엑셀 수식을 정확하게 받아 내는 프롬프트 작성법과, 받은 수식을 검증하는 방법을 정리했습니다. 오류의 의미와 검사 메뉴는 Microsoft 공식 도움말을 기준으로 했습니다.

## 왜 AI 수식이 틀리나

| 원인 | 결과 |
|---|---|
| 표의 열 위치를 알려주지 않음 | AI가 A열, B열을 임의로 가정해 내 표와 맞지 않음 |
| 엑셀 버전을 밝히지 않음 | XLOOKUP, FILTER처럼 내 버전에 없는 함수를 쓸 수 있음 |
| 데이터 형식을 말하지 않음 | 날짜가 텍스트로 저장된 경우 등을 고려하지 못함 |
| 원하는 결과를 말로만 설명 | 의도를 다르게 해석함 |

공식 프롬프트 가이드들이 강조하는 "구체적으로, 맥락과 예시를 함께" 원칙이 엑셀에서는 **표 구조, 버전, 예상 결과** 를 알려주는 것으로 바뀝니다.

## 수식 요청 프롬프트의 기본 공식

```text
엑셀 수식을 만들어 줘.
- 엑셀 버전: (예: Microsoft 365 / Excel 2016)
- 표 구조: A열 날짜, B열 담당자, C열 지역, D열 매출 (1행은 제목, 데이터는 2~200행)
- 하고 싶은 일: (예: 담당자별, 지역별 매출 합계)
- 결과를 넣을 셀: (예: G2)
- 예상 결과 예시: (예: 김민수·서울이면 3,200,000)
- 수식만 주지 말고 각 부분이 하는 일을 짧게 설명해 줘.
```

### 표 구조를 빠르게 알려주는 방법

열 설명을 타이핑하기 번거롭다면 표의 **제목 행과 데이터 3~5행** 을 복사해 붙여 넣으면 됩니다. 엑셀에서 범위를 복사해 챗봇 입력창에 붙이면 탭으로 구분된 텍스트로 들어갑니다. 다만 실제 고객 이름이나 금액이 들어 있다면 가짜 값으로 바꾼 뒤 붙이세요.

## 예제 1. 조건 두 개로 합계 구하기

```text
Microsoft 365 엑셀이야.
A열 날짜, B열 담당자, C열 지역, D열 매출이고 데이터는 2~200행이야.
F2에 담당자 이름, F3에 지역이 있을 때, 두 조건을 모두 만족하는 매출 합계를 G2에 구하는 수식을 알려줘.
```

이런 질문에는 보통 아래와 같은 SUMIFS 수식이 돌아옵니다.

```text
=SUMIFS(D2:D200, B2:B200, F2, C2:C200, F3)
```

SUMIFS는 **합계를 구할 범위가 맨 앞** 에 오는 것이 특징입니다. 함수 자세한 사용법은 [SUMIFS·COUNTIFS 함수 정리](/posts/excel-sumifs-countifs/)에 있습니다.

## 예제 2. 버전 때문에 함수가 달라지는 경우

같은 "다른 표에서 값 찾아오기"라도 버전을 밝히면 답이 달라집니다.

| 내가 알려준 버전 | AI가 줄 가능성이 높은 함수 |
|---|---|
| Microsoft 365, Excel 2021 이후 | XLOOKUP |
| Excel 2016 등 이전 버전 | VLOOKUP 또는 INDEX + MATCH |

버전을 밝히지 않았는데 받은 수식에서 **#NAME?** 오류가 난다면, 함수가 내 엑셀에 없는 경우를 의심해 볼 수 있습니다. 이때는 "Excel 2016에서도 되는 수식으로 바꿔 줘"라고 다시 요청하세요. XLOOKUP 사용법은 [엑셀 XLOOKUP 함수 사용법](/posts/excel-xlookup-guide/)에 정리했습니다.

## 예제 3. 오류가 난 수식 고치기

오류를 물어볼 때는 **수식, 오류 값, 셀에 든 값** 을 함께 알려줘야 합니다.

```text
아래 수식에서 #N/A 오류가 나. 원인과 고친 수식을 알려줘.
수식: =VLOOKUP(F2, A2:C100, 3, FALSE)
F2 값: "P-1001"
A열에는 P-1001이 있는 것처럼 보이는데 결과가 #N/A야.
A열 값은 다른 시스템에서 복사해 온 거야.
```

AI가 원인 후보(앞뒤 공백, 숫자와 텍스트 형식 차이 등)와 확인 방법을 제시하면, 하나씩 직접 확인해 보세요.

### 오류 값별 의미 (Microsoft 도움말 기준)

| 오류 | 의미 | AI에게 함께 알려줄 것 |
|---|---|---|
| **#N/A** | 함수나 수식에 필요한 값을 찾을 수 없음 | 찾는 값과 찾는 범위의 실제 값 |
| **#VALUE!** | 수식에 서로 다른 데이터 형식이 섞여 있을 수 있음 | 계산에 들어간 셀의 값과 형식 |
| **#NAME?** | 수식의 텍스트를 인식할 수 없음 | 수식 전체와 엑셀 버전 |
| **#REF!** | 셀 참조가 유효하지 않음 (예: 참조한 셀 삭제) | 최근에 지운 행·열이 있는지 |
| **#DIV/0!** | 0이나 값이 없는 셀로 나눔 | 나누는 값이 들어 있는 셀 |
| **#NUM!** | 잘못된 숫자 값이 있음 | 함수에 넣은 숫자 |
| **#NULL!** | 교차하지 않는 두 범위의 교차를 지정함 | 범위 사이에 쉼표·콜론이 빠졌는지 |
| **#####** | 열 너비가 좁거나 음수 날짜·시간 | 열 너비를 넓혀 보았는지 |

### #NAME?의 흔한 원인

Microsoft 도움말이 꼽는 #NAME? 오류의 주요 원인은 다음과 같습니다.

1. 함수 이름의 **오타**
2. 수식 안의 텍스트를 **큰따옴표로 감싸지 않음**
3. 통합 문서에 **정의되지 않은 이름** 을 참조
4. 특정 **추가 기능이 켜져 있어야** 동작하는 함수
5. 범위 참조에서 **콜론(:)이 빠짐**

AI가 만든 수식에서도 2번과 5번이 자주 보입니다. 예를 들어 `=COUNTIF(B2:B100, 완료)` 처럼 텍스트에 따옴표가 빠지면 #NAME?이 납니다. `=COUNTIF(B2:B100, "완료")` 로 고쳐야 합니다.

## 받은 수식, 이렇게 검증하세요

AI가 준 수식은 그럴듯해 보여도 **범위가 한 칸 어긋나거나 조건이 반대** 인 경우가 있습니다. 다음 순서로 확인하세요.

1. **작은 데이터로 손계산과 비교** 합니다. 결과를 직접 셀 수 있는 5~10행짜리 범위에서 먼저 시험해 봅니다.
2. **수식 계산** 기능으로 단계별 결과를 봅니다. Windows용 Excel에서 **수식** → **수식 감사** → **수식 계산** 을 클릭하면 수식이 어떤 순서로 계산되는지 한 단계씩 볼 수 있습니다.
3. **오류 검사** 를 실행합니다. **수식** → **수식 감사** → **오류 검사** 에서 시트의 오류 셀을 차례로 확인할 수 있습니다.
4. **범위 끝 행을 확인** 합니다. 데이터가 200행인데 수식이 `D2:D100` 이라면 일부가 빠집니다.
5. **조건이 비어 있을 때** 결과를 확인합니다. 조건 셀을 지웠을 때 0이 나오는지, 오류가 나는지 봅니다.

## 더 좋은 답을 받는 후속 질문

| 하고 싶은 일 | 후속 질문 예시 |
|---|---|
| 원리를 이해하고 싶음 | "이 수식을 부분별로 나눠서 무슨 일을 하는지 설명해 줘" |
| 오류 대신 빈칸 표시 | "값이 없을 때 오류 대신 빈칸이 나오게 바꿔 줘" |
| 다른 방법 비교 | "같은 결과를 내는 다른 함수 조합도 알려주고 장단점을 비교해 줘" |
| 행이 늘어나도 동작 | "데이터가 계속 추가돼도 범위를 고치지 않게 하려면?" |
| 구글 시트로 옮김 | "이 수식이 구글 스프레드시트에서도 그대로 되는지 알려줘" |

## 안 될 때: 자주 겪는 문제와 해결법

| 증상 | 원인 | 해결 |
|---|---|---|
| AI 수식을 붙였더니 #NAME? | 내 버전에 없는 함수, 따옴표 누락, 콜론 누락 | 버전을 밝히고 다시 요청, 따옴표·콜론 확인 |
| 결과가 0으로 나옴 | 조건 값의 공백·형식 차이, 범위 어긋남 | 조건 셀과 데이터 값을 직접 비교 |
| 수식이 너무 복잡함 | 한 번에 모든 것을 요청함 | 단계별로 나눠 도우미 열을 쓰는 방식 요청 |
| 수식이 셀에 글자로 보임 | 셀 서식이 텍스트이거나 = 앞에 공백 | 셀 서식을 일반으로 바꾸고 다시 입력 |
| 매번 다른 답이 나옴 | 질문에 표 구조 정보가 없음 | 기본 공식대로 표 구조·예상 결과를 명시 |

## 정리

- AI에게 수식을 물을 때는 **엑셀 버전, 표 구조, 결과 셀, 예상 결과** 를 함께 알려줍니다.
- 오류를 물을 때는 **수식, 오류 값, 셀의 실제 값** 을 붙여 넣습니다.
- 받은 수식은 작은 데이터로 손계산과 비교하고, **수식 → 수식 감사 → 수식 계산** 으로 단계별로 확인합니다.
