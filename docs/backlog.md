# 글 주제 후보

검색 수요가 꾸준하고 공식 문서로 사실 확인이 가능한 주제 위주. 위에서부터 쓴다.

## 엑셀·오피스
- 엑셀 IF·IFS 함수와 중첩 IF 줄이는 법
- 엑셀 드롭다운 목록(데이터 유효성 검사) 만들기
- 엑셀 틀 고정과 인쇄 제목 반복
- 엑셀 날짜 함수 정리 (TODAY, DATEDIF, EDATE, NETWORKDAYS)
- 엑셀 텍스트 나누기·합치기 (TEXTSPLIT, TEXTJOIN, 텍스트 나누기 마법사)
- 워드 목차 자동으로 만들기
- 파워포인트 슬라이드 크기·비율 바꾸기
- 엑셀 FILTER 함수로 조건에 맞는 행 뽑기
- 엑셀 조건부 서식으로 행 전체 색칠하기

## 구글 서비스
- 구글 스프레드시트 드롭다운 만들기
- 구글 스프레드시트 IMPORTRANGE로 다른 시트 불러오기
- 구글 드라이브 용량 정리하는 법
- 구글 폼으로 설문 만들고 결과 시트로 받기
- 지메일 필터와 자동 분류 설정

## AI 활용법
- AI로 이메일 쓰기: 상황별 프롬프트 (요청, 거절, 사과, 독촉)
- AI로 엑셀 수식 만들기와 오류 고치기
- ChatGPT 맞춤 지침(Custom Instructions) 설정법
- Claude 프로젝트 기능 사용법
- Gemini를 Gmail·구글 문서에서 쓰는 법
- AI 이미지 생성 프롬프트 작성법
- AI 답변의 환각(거짓 정보) 줄이는 법과 사실 확인 방법

- 윈도우 11 기본 앱(브라우저, PDF) 바꾸기
- 윈도우 11 화면 분할과 듀얼 모니터 설정
